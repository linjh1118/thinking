与其用人为的 N/A 猜测偏置，不如直接用无标签目标 batch 的平均输出估计 contextual bias，并平移决策边界。

01 · 问题

为什么重要

Contextual Calibration 会受 content-free token 影响，Domain Calibration 成本高，GMM 型方法又可能过拟合。需要一个不增加模型 forward、能覆盖多句和多类任务的统一方案。

02 · 方法

1. 收集一个无标签目标输入 batch。
2. 计算 batch 内模型输出的边缘均值。
3. 从每个样本输出中减去该均值；BCL 再学习一个强度参数。

结果怎么读

BC 对示例选择、顺序、模板和 verbalizer 更稳健，并在多句任务上避免多种 content-free calibration 的严重失败。

04 · 研究判断

对 FinJev 的启发

BC 会改变 decision boundary，temperature scaling 只改 confidence。Jev 论文不能用一个“calibration”标签混报两者。

05 · 边界

  • 依赖 batch 代表目标分布。
  • 类别比例漂移时可能消掉真实 prior。
  • 在线单样本需要 running estimate，存在冷启动与非平稳问题。
