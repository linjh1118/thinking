JEV vs. LLM Rubric Judge：便宜、快速，却错在相同位置

JEV vs. LLMs as Rubric Judges
Delip Rao, Chris Callison-Burch
arXiv 2026 · 2609.29769
96%LLM 重复 Jev 高置信错误
📚 专题导航：返回 Jev 专题调研与论文海报索引

Jev 的优势是成本与延迟，但它和 LLM judge 的错误高度重合。置信度级联常能省钱，却不自动带来更高准确率。

01 · 问题

为什么重要

“低置信升级”隐含一个前提：二级模型能纠正一级模型的错误。若错误来源相同，路由再精巧也只能改变费用结构。

02 · 方法

1. 9 个 rubric panels、5,003 个 pairwise judgments。
2. 统一比较准确率、成本、延迟和逐样本错误交集。
3. 使用 cross-fit threshold 评估 abstention/cascade，避免测试集调参。

03 · 关键证据

样本量

结果怎么读

最具警示性的结果不是平均分，而是强 LLM 会重复 Jev 最有把握的错误；因此 confidence 不能单独预测“升级后会获救”。

04 · 研究判断

对 FinJev 的启发

路由前先画 error-overlap matrix，并估计二级模型在一级错误条件下的增益。FinJev 应加入 oracle router，量化级联理论上限。

05 · 边界

  • 结论依赖所选 rubric panels 与 judge。
  • 价格和延迟会随服务变化。
  • 相关错误机制仍需因果分析。
