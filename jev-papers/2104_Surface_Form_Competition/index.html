生成模型给字符串分配概率，决策任务却关心概念。同义答案争夺有限概率质量，会让罕见但正确的候选输给常见表述。

01 · 问题

为什么重要

“bathtub”“a bathtub”“whirlpool bath”表达相近概念，却分食概率质量。多选题只列一种表述时，直接比较 P(answer|question) 会系统性惩罚罕见表述。

02 · 方法

1. 估计候选在任务域中的先验 P(y|domain)。
2. 计算 PMI_DC = log P(y|x,domain) − log P(y|domain)。
3. 选择被问题提升最多的候选，而不是本身最常见的字符串。

结果怎么读

PMI_DC 在绝大多数 zero-shot 设置中获胜或并列最佳；COPA Flipped 实验进一步支持性能差距主要来自 surface-form competition。

04 · 研究判断

对 FinJev 的启发

Jev 既有 option-ID prior，也有候选定义的 surface-form prior。必须分别测试 ID invariance 与 definition paraphrase invariance。

05 · 边界

  • domain premise 由人设计，会引入新偏置。
  • 依赖候选序列概率，黑盒 label API 难直接使用。
  • 修正表面形式不等于补足知识或推理能力。
