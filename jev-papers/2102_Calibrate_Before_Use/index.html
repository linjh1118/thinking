ICML 2021 · arXiv:2102.09690

📚 专题导航：返回 Jev 专题调研与论文海报索引

Few-shot prompt 会把模型推向某些标签；用 content-free input 测出上下文偏置，再做对角缩放，可在不训练模型的情况下提高准确率并降低方差。

01 · 问题

为什么重要

仅改变 prompt 格式、示例或顺序，GPT-3 的表现就可能从接近随机变到接近 SOTA。根因包括多数标签偏置、近因偏置和常见 token 偏置。

02 · 方法

1. 把测试输入替换为 N/A、[MASK] 或空串。
2. 读取当前 prompt 下各标签的 content-free 概率。
3. 用对角缩放令 content-free 分布均匀，再处理真实输入。

结果怎么读

在分类、事实检索和信息抽取任务上，平均与 worst-case accuracy 普遍改善；多数设置下跨 prompt 方差下降。

04 · 研究判断

对 FinJev 的启发

FinJev 的 LoRA 必须先击败 frozen logits + contextual/temperature calibration。否则所谓训练收益可能只是纠正标签 token prior。

05 · 边界

  • content-free string 未必真正中性。
  • 修正平均标签偏置，不保证逐样本概率校准。
  • 无法修复 name–definition 绑定被忽略造成的排序翻转。
