在高频、候选明确的边缘路由中，Jev 可显著降低决策延迟与成本；但缓存和 OCR 等系统组件会决定这些收益能否落到端到端。

01 · 问题

为什么重要

云端 LLM 的生成与网络开销不适合高频 edge orchestration。论文比较 Jev 与 LLM 在路由选择、真实 OCR 输入和缓存条件下的系统表现。

02 · 方法

1. 把服务编排转为有限候选 decision。
2. 分别测纯决策、真实 OCR 与端到端路径。
3. 加入缓存消融，区分模型收益与系统收益。

结果怎么读

纯决策层和无缓存路径有稳定收益；缓存会消除大部分延迟差异，真实 OCR 噪声也会限制模型侧改进。

04 · 研究判断

对 FinJev 的启发

FinJev 不能只测模型 forward。财报解析、检索缓存与工具调用可能占主导，应做端到端 latency decomposition。

05 · 边界

  • Jev 严格语义指标略弱。
  • 缓存条件下延迟优势消失。
  • OCR 与输入管线误差可能掩盖决策器差异。
