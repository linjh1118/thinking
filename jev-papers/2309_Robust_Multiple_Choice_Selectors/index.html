LLM 不是稳健的多选题选择器

LLMs Are Not Robust Multiple Choice Selectors
Chujie Zheng, Hao Zhou, Fandong Meng, Jie Zhou, Minlie Huang
ICLR 2024 · arXiv:2309.03882
20 LLMs跨 3 个 MCQ benchmark
📚 专题导航：返回 Jev 专题调研与论文海报索引

A/B/C/D 不是无害输出编码：模型对 option ID 有稳定先验。仅移动正确答案的位置，就能显著改变准确率和模型排名。

01 · 问题

为什么重要

LLaMA-30B 在平衡 MMLU 子集上选择 A/B/C/D 的比例为 34.6/27.3/22.3/15.8%；把正确答案移动到不同位置，准确率从 41.2% 到 68.2%。

02 · 方法

1. 在少量无标签样本上循环置换候选。
2. 估计模型对每个 option ID 的全局 prior。
3. 其余样本只前向一次，用观测概率除以 prior：PriDe。

结果怎么读

Token bias 是主要来源，position bias 次之；CoT 与简单 prompt engineering 无法稳定消除。PriDe 在低成本设置优于循环/全排列。

04 · 研究判断

对 FinJev 的启发

FinJev 应分开随机化“候选内容位置”和“输出 ID/名称”，逆映射后报告 flip rate、accuracy 与概率漂移。

05 · 边界

  • 依赖 option-token 概率，黑盒 API 需采样近似。
  • 内容信念与 ID prior 的独立性只是近似。
  • 跨大领域迁移时 prior 会退化。
