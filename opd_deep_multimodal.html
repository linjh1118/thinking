🖼️ 多模态 OPD（5 篇深度解读）

本节 TLDR

多模态 OPD 将"在学生自身轨迹上获得教师密集监督"的框架扩展到图像生成（扩散模型）、VLM、视频定位、音频推理、跨模态语音 LLM。核心挑战：非文本模态的"token"定义不同（扩散 timestep、视觉 patch、音频帧），OPD 损失需要适配到对应空间。

π-Flow: On-Policy Distillation for Flow-Based Image Generation

ICLR 2026 Multi-institution2025.10
扩散模型的 OPD 是什么？

扩散/flow 模型的"rollout"是去噪轨迹：从噪声 x_T 出发，学生模型一步步预测去噪方向，最终生成图像 x_0。π-Flow 将这条完整的去噪轨迹视为学生的"on-policy rollout"，在每个 denoising timestep 上用教师模型提供密集监督。

核心设计：沿学生轨迹的 L2 模仿蒸馏
标准 flow-matching 蒸馏（off-policy）：
在固定的 (x_0, x_T) 对上训练，学生学习从 x_T 到 x_0 的映射

π-Flow（on-policy）：
Step 1：学生从 x_T 开始生成完整轨迹 {x̂_T, x̂_{T-1}, ..., x̂_0}
Step 2：在学生生成的每个中间状态 x̂_t 上，教师计算最优方向 v_T(x̂_t)
Step 3：
L = Σ_{t=0}^{T} ‖v_S(x̂_t) - v_T(x̂_t)‖²  （学生预测方向 vs 教师最优方向的 L2）
→ 关键：监督点 x̂_t 来自学生轨迹（on-policy），而非固定数据集（off-policy）
为什么 on-policy 对扩散模型重要？

扩散模型的 distribution shift 问题比 LLM 更严重：off-policy 训练在 (x_0, t) 的随机组合上学习，但推理时每个 x_t 是前一步学生预测的结果，不是随机添加噪声的干净图像。积累的误差会导致生成图像质量显著下降。π-Flow 通过在学生真实推理轨迹上监督，消除了这种 train-test mismatch。

实验
方法FID↓（COCO）CLIP Score↑推理步数
原始教师（256步）8.10.312256
一致性蒸馏（off-policy）14.30.2984
π-Flow（on-policy）9.80.3094

4步推理的 FID 从 14.3 降到 9.8，接近 256 步教师的质量，但速度快 64 倍。

扩展意义

π-Flow 证明了 OPD 的核心思想（在学生自身生成轨迹上做监督）适用于连续空间的生成模型，不仅限于离散 token。这为扩散模型的知识蒸馏开辟了一条新路，也提示视频生成、3D 生成等领域有类似的 on-policy 蒸馏机会。

VOLD: Vision-Language OPD from Text-Only LLM

ICLR 2026 INRIA / Goethe University2025.10
跨模态蒸馏：LLM → VLM

VOLD 解决的是：一个强大的纯文本 LLM（如 LLaMA-3.1-70B）能否将其语言能力蒸馏给一个视觉语言模型（VLM）学生，使后者在多模态任务上达到更高性能？难点在于教师（纯文本 LLM）无法直接处理图像输入。

两阶段解决方案
阶段 1：冷启动 SFT 对齐（让 VLM 先有基础能力）
在多模态数据集（图文对）上做标准 SFT
目的：让 VLM 学生能生成连贯的多模态 rollout

阶段 2：统一 RL + OPD 训练
VLM 学生输入：(图像, 文本问题)
VLM 学生生成：y ~ π_VLM(·|图像, 问题)  （on-policy rollout）

OPD 监督：
将图像转换为 caption：img → caption（用另一个 VLM 描述图像）
纯文本 LLM 教师输入：(caption, 问题)
L_KD = D_KL(π_VLM(·|图像,问题,y_<t) ‖ π_LLM(·|caption,问题,y_<t))
同时加入 GRPO 规则奖励（如 VQA 准确率）
Caption 桥接的设计选择

图像 → caption 的转换是 VOLD 的关键工程决策。论文测试了多种方案：

桥接方案VQA 准确率成本
无桥接（LLM 跳过图像）无法计算最低
简短 caption（<50 词）72.1%低
详细 caption（<200 词）76.8%中
结构化 caption（区域描述）75.2%高
为什么用文本 LLM 教视觉 LLM 有效？

视觉理解的核心能力（逻辑推理、常识知识、语言理解）实际上是语言能力，不是视觉能力。强文本 LLM 在这些方面远超普通 VLM。VOLD 通过 caption 桥接，将文本 LLM 的语言推理能力转移到 VLM，弥补了 VLM 在纯推理方面的短板。

Video-OPD: Temporal Video Grounding via OPD

工业界（机构未完全公开）2026.02
时序视频定位任务

时序视频定位（Temporal Video Grounding）：给定视频 + 文本查询（"找到 X 发生的时刻"），模型需要输出时间戳区间。Video-OPD 将 LLM 教师（仅处理视频的文字描述）的时序推理能力蒸馏给 MLLM（Multimodal LLM）学生（直接处理视频帧）。

OPD 适配：时序输出的 token 级 KL
MLLM 学生输出格式：
"时间戳开始于 [<t_start>] 秒，结束于 [<t_end>] 秒"
→ 时间戳被 tokenize 为数字 token 序列

教师（纯文本 LLM + 视频文字描述）：
输入：视频帧的密集文字描述（每帧 1 句话）
输出：相同格式的时间戳预测

OPD 损失：
在 MLLM 学生的 rollout 上，逐 token KL（特别是时间戳 token 位置权重更高）
关键挑战：视频帧的 token 爆炸

视频每秒 24 帧，每帧作为视觉 patch 展开可能有 256-576 个 token。10 秒视频 = 60K-140K 视觉 token，超出大多数模型上下文窗口。Video-OPD 用帧采样（每秒 1-4 帧）+ 视觉 token 压缩（平均池化）减少到可处理范围，是工程上的重要权衡。

X-OPD: Cross-Modal Speech LLM Distillation

Tencent Hunyuan / ZJU2026.03
跨模态 token 级 KL

X-OPD 将强大的文本 LLM 的能力蒸馏到语音 LLM（Speech LLM）。关键挑战：文本 token 和语音 token（通常是 codec token，如 EnCodec）是完全不同的表示空间，无法直接对齐 logit。

跨空间对齐方案
Step 1：文本-语音投影层
训练一个轻量级投影层 P: 文本 logit 空间 → 语音 logit 空间

Step 2：在对齐空间计算 KL
教师文本 logits → P → 语音空间
L = D_KL(P(π_T_text) ‖ π_S_speech)  在学生语音 rollout 上

Step 3：投影层 P 与学生 π_S_speech 联合训练
P 不是固定的，随训练动态调整以保持最优对齐

方法ASR WER↓SQA 准确率↑语音翻译 BLEU↑
语音 LLM 基线（无蒸馏）8.2%61.3%28.4

Step-Audio-R1: Audio Reasoning via Iterative Self-Distillation

StepFun2025.11
音频推理的迭代自蒸馏

Step-Audio-R1 是面向音频问答（如"这段音频说了什么意思？""这个声音属于什么乐器？"）的推理能力提升方案。采用"SFT → 自蒸馏 → PPO/RLVR"的三阶段 pipeline。

音频 OPD 的特殊设计
  • 只对音频相关问题自蒸馏：对纯文本问题不触发自蒸馏循环（避免过拟合音频域特征）
  • 音频 token 的特殊权重：在包含音频内容描述的 token 位置上，给 KL 损失加更高权重
  • 迭代自举：每轮用上轮模型的高质量输出（验证正确的）作为新的训练数据，循环 3-5 轮
多模态 OPD 的共同难题

本节 5 篇论文面临的核心共同挑战：(1) 多模态 token 与文本 token 的对齐问题；(2) 视觉/音频序列远比文本序列长（token 爆炸）；(3) 多模态教师（能理解视觉/音频）通常弱于文本教师。未来方向：随着原生多模态 LLM（如 GPT-5o、Gemini 2.0）能力提升，直接用多模态教师做 OPD 将成为主流。
