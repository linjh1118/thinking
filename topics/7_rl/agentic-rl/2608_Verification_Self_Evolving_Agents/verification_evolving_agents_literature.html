分级标准

（1）强相关验证机制与自更新/持续演化在同一方法闭环中发挥核心作用；已人工复核标题与摘要。
（2）弱相关主要研究 verification 或 evolving agent 一侧，或两者仅有间接连接。
（3）基础文献支撑验证器、评测可信性、自纠错、持续学习、安全监督等基础问题。

筛选方法

  1. 对 80,625 篇标题与摘要做高召回概念检索，而非只匹配 “verification”。
  2. 排除事实核验、人脸/说话人验证、传统控制器与神经网络形式验证等同词异义论文。
  3. 分别计算 evolution、verification、agent context 与 foundation 信号。
  4. 强相关集合人工复核；其余为规则辅助复核，建议引用前精读原文。

“强相关”强调方法闭环，不等同于论文质量排序；相关度分数只用于本报告内部排序。

初步研究信号

双轴交叉论文仅占入选集的 10.3%，说明“如何改进”与“如何可信地接受改进”仍常被分开研究。

入选论文中，2024 / 2025 / 2026 年分别为 32 / 106 / 182 篇；2026 年集中出现 self-evolving agent、meta-verifier 与 agentic oversight 交叉工作。

最密集的基础方向是验证器/奖励模型、LLM 裁判可靠性、自纠错，以及奖励破解与评测污染。
