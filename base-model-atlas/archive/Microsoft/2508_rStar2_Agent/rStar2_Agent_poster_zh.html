01 问题与动机
Agentic RL Self-play GRPO Code Tool

Agentic RL 面临三大核心挑战：高 Rollout 计算成本、Coding Tool 环境噪声、有限资源下的训练效率。

Agentic RL 三大挑战
  • High Rollout Costs：Agent 任务需多次环境交互，GPU 消耗巨大
  • Environment Noises：Coding Tool 固有噪声影响训练稳定性
  • 训练效率：如何在有限资源下高效 RL

关键发现

从 Non-reasoning SFT（非思维模型）起步，通过 Multi-RL Stages（多阶段强化学习），以最少计算成本获得高级认知能力。

02 核心方法
GRPO-RoC Resample-on-Correct Multi-turn Self-play
GRPO-RoC 算法核心

Resample-on-Correct Rollout Strategy：当 Rollout 产生正确结果时，重新采样多个轨迹，增加正样本多样性，提高训练稳定性。

  • 解决 Coding Tool 环境固有噪声问题
  • 扩大正确轨迹的多样性信号
  • 提升 RL 训练稳定性
训练流程
  • Step 1：Non-reasoning SFT（不用 Thinking Model）
  • Step 2：GRPO-RoC 多阶段强化学习
  • Step 3：Cognitive Behaviors 涌现
