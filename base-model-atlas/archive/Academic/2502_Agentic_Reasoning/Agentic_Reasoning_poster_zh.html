推理的局限性

  • 结构化领域（数学/代码）：outcome 可验证，RL 效果好
  • 非结构化领域（社会科学、伦理、经验性）：形式化推理不适用，需要事实验证

Deep Research 核心需求

  • 广泛研究（Extensive research）
  • 重复验证（Repeated verification）
  • 信息检索（Information retrieval）
  • 计算分析（Computational analysis）
  • 组织复杂逻辑关系

Web-Search Agent

四组件 pipeline：

  • Query Breakdown：原始 query + Mind-Map context 重写为搜索优化 query
  • Search Service：Bing 搜索，返回 top 20 相关页面
  • Re-ranking：Cohere Rerank 3.5 按相关性排序
  • RAG：提取 insights，合成最终 snippet

Mind-Map Agent（关键创新）

知识图谱构建：LLM 从推理链提取实体 + 识别语义关系 + 社区聚类（Louvain）+ 摘要生成。

Mind-Map Agent 长推理链示例

两大功能：

  • Context Provision：为外部工具提供结构化推理上下文
  • Memory Retrieval：长推理链中不确定时查询 Mind-Map

Coding Agent

设计决策：不用 reasoning model 直接生成代码，而是委托给 specialized coding LLM（Claude-3.5-sonnet）。

  • Reasoning model 保持专注于核心推理
  • 更长的连贯推理链
  • Claude 更擅长 coding tasks
