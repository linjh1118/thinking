Model Family & Motivation

Core Vision

Gemini 2.5 将 RL 训练的 Thinking 能力与原生多模态、1M+ token 长上下文深度融合，覆盖从日常任务到复杂编码的全 Pareto 前沿。

Gemini 1.5 奠定了长上下文和多模态基础，但推理能力有限。Gemini 2.5 的核心目标：在推理时通过额外计算换取更高准确率。

Model Architecture

  • Sparse MoE — Sparse Mixture-of-Experts Transformer
  • Native Multimodal — text, visual, audio 输入统一处理
  • Long Context — 1M token 上下文窗口
  • Distillation — k-sparse 近似用于 Flash 及以下模型

Thinking Mechanism

使用强化学习训练，在回答前花费数万步 forward pass 进行"思考"。

  • Dynamic Thinking Budget — 用户可控思考 token 分配
  • Consistent Scaling — 更多思考 → 更高准确率
  • Multimodal Integration — Thinking 跨图像、视频、音频工作
  • Agentic — Thinking 与 Google Search 工具调用交织
