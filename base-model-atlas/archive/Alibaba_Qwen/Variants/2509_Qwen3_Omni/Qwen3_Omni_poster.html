1Problem & Motivation
Qwen3-Omni Thinker-Talker Architecture

Core Problem

Traditional LLM-centric multimodal models often suffer from modality trade-off: enhancing one modality leads to performance degradation in others.

Research Goal

Achieve joint multimodal training under the LLM paradigm, proving that all modalities can improve without degradation while significantly enhancing cross-modal reasoning (e.g., video understanding).

Core Insight: Modality Preservation is the key challenge in multimodal learning

2Method Core

Thinker-Talker Architecture

  • Thinker: Responsible for understanding and reasoning, outputs text tokens and high-level representations
  • Talker: Receives multimodal features, generates streaming speech tokens

Five Major Upgrades (vs Qwen2.5-Omni)

  • MoE Design: Both Thinker and Talker use MoE architecture
  • AuT Audio Encoder: Audio Transformer trained from scratch, 20M hours supervised data, 12.5Hz token rate
  • Multi-codebook Representation: RVQ codec supports 12.5 Hz output, single-frame instant speech synthesis
  • MTP Module: Multi-Token Prediction generates residual codebooks
  • Low Latency: End-to-end latency as low as 234ms (audio input)

Key Technologies

  • TM-RoPE: Time-aligned multimodal rotary position encoding, supports arbitrary-duration streaming input
  • Chunked Prefilling: Asynchronous prefilling, Thinker and Talker work in parallel
  • Decoupled Design: Talker no longer consumes Thinker's high-level text representations

Core Findings

  • After adding audio modality, text capability actually improves
  • Visual understanding capability remains unchanged
  • Video understanding capability significantly enhanced

Research Implications

  • Modality preservation is important for GUI Agents
  • Thinker-Talker separation has reference value for real-time interaction
  • Streaming speech generation is key for voice interaction Agents
