Qwen3-VL — 最强视觉-语言模型

arXiv:2511.21631 · 2025 · 阿里通义实验室

基于 Qwen3 纯文本骨干的 VLM，支持 Dual-mode（Thinking + Instruct）、256K 超长上下文、39 语言 OCR，在文档理解、Math、Agent 等多个维度达到 SOTA，235B MoE 模型可与 Gemini 2.5 Pro 竞争。

问题与动机

核心挑战

现有 VLM 在纯文本任务上弱于纯文本骨干；长上下文视觉理解能力不足；多语言 OCR 与 GUI Agent 能力有限

核心贡献

1. Dual-mode：同一个模型支持 Thinking（慢思考）和 Instruct（快速响应）两种模式

2. 超长上下文：原生 256K token，支持文本+图像+视频交错输入

3. 39 语言 OCR：覆盖中英日韩等 39 种语言的文档理解

4. GUI Agent：OSWorldG 68.3，ScreenSpot Pro 62.0，开源最高

模型规格（5 款）

密集模型：2B / 4B / 8B / 32B

MoE 模型：30B-A3B / 235B-A22B

骨干：Qwen3 15B / 3B / 7B / 57B-A14B

视觉：SigLIP-2 SO400M / 400M / 14B

✦ 三大架构升级

Interleaved MRoPE：时空建模增强，处理视频和交错的图像-文本

DeepStack：多级 ViT 特征注入 LLM 前三层，增强视觉感知

Text Timestamp：<3.0s> 格式文本时间戳，支持视频时序定位

39 语言 OCR 覆盖

拉丁、西里尔、希腊、阿拉伯、梵文、中日韩等文字体系

OCRBench_v2_zh: 61.8   CC-OCR: 82.2

核心方法

Figure: Qwen3-VL 架构 — SigLIP-2 视觉编码器 + Qwen3 LLM + DeepStack 特征融合
预训练四阶段

S0: Merger 对齐 (67B tokens) → S1: 多模态预训练 (~1T tokens) → S2: 长上下文 (32K, ~1T tokens) → S3: 超长上下文 (256K, 100B tokens)

后训练三阶段

SFT (长 CoT 数据) → 强到弱蒸馏 (将大模型能力迁移到小模型) → RL (推理 RL + 通用 RL)

✦ 关键训练技术

Dual-mode：Thinking 模式使用长 CoT 数据进行 SFT；Instruct 模式是标准快速响应

强到弱蒸馏：将 235B MoE 的 thinking 能力蒸馏到 30B/32B 密集模型

密集 + MoE 统一：235B MoE 与 32B 密集模型共享相同的架构设计

Video 理解关键设计

Interleaved MRoPE：t/h/w 三维均匀分布在高低频带，平衡频谱表征

Text Timestamp：每个视频帧附时间戳 <X.X seconds>，支持时序推理

密集时序标注：大规模密集视频 caption 数据用于训练
