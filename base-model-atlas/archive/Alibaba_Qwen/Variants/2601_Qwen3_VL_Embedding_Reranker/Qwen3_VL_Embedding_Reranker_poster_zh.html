问题与动机

核心能力

将多模态内容（文本、图像、文档图像、视频）映射到统一表示空间，实现端到端的高精度多模态搜索。

关键技术

Embedding 模型：多阶段训练 + Matryoshka 表示学习 + 量化感知训练

Reranker 模型：交叉编码器架构 + 交叉注意力机制

模型规格

Embedding: 2B 和 8B

Reranker: 2B 和 8B

✦ 核心创新

1. 多模态对比预训练 + 重排序模型蒸馏

2. 支持 Matryoshka 表示学习，可灵活选择嵌入维度

架构与训练

Figure: Qwen3-VL-Embedding 架构 — 双编码器 + 交叉编码器
Figure: 多阶段训练流程 — 对比预训练 → 多任务微调 → 蒸馏与合并
✦ 训练策略

Stage 1: 大规模对比预训练

Stage 2: 多任务对比学习 + SFT

Stage 3: 重排序蒸馏 + 模型合并
