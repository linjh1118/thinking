01 — Problem & Motivation

Background

Traditional ASR systems struggle with:

  • Long-form audio (minutes to tens of minutes)
  • Noisy environments
  • Multilingual/dialectal coverage
  • Timestamp prediction accuracy

LALM Paradigm: Leverages LLM language modeling and world knowledge to solve these challenges naturally

Core Contributions

  • First to introduce LLM into Forced Alignment
  • Flexible timestamp prediction at any granularity
  • Unified alignment for 11 languages
Key Capabilities

Features

  • 52 languages/dialects: 30 languages + 22 Chinese dialects
  • Long audio: Up to 20 minutes per utterance
  • Streaming/offline: Unified inference framework
  • Singing recognition: Full songs with background music
  • Contextual Biasing: Free-form context injection
02 — Core Method

Model Architecture

Built on Qwen3-Omni base model:

  • AuT Audio Encoder: AED architecture, 8x downsampling, 12.5Hz token rate
  • Dynamic Attention Window: 1-8 seconds adjustable
  • Qwen3-ASR-1.7B: Qwen3-1.7B + 300M AuT encoder
  • Qwen3-ASR-0.6B: Qwen3-0.6B + 180M AuT encoder

Training Strategy

  • AuT Pretraining: ~40M hours pseudo-labeled ASR data
  • Omni Pretraining: Multimodal training, 3T tokens
  • ASR SFT: Style transfer, unified format
  • ASR RL (GSPO): 50k utterances

ForcedAligner Innovation

  • Slot-filling: Insert [time] tokens into transcript
  • Causal Training: No shift, ensures timestamp slot alignment
  • NAR Decoding: Non-autoregressive, predict all timestamps simultaneously
  • MFA Distillation: Distilled from Montreal Forced Aligner
