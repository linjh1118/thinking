🎵 ARIA: Adaptive Rate Interleave Alignment

ARIA solves the instability caused by mismatched tokenization rates between text and speech tokens, which previously caused skipped words, wrong pronunciations, and number rendering errors.

$$\forall \text{prefix } p: \quad \frac{\text{cumul. speech tokens in } p}{\text{cumul. text tokens in } p} \leq r_{\text{global}}$$

Where \(r_{\text{global}}\) is the item-level global speech-to-text ratio. This adaptive rate constraint enforces monotonic interleaving without MFA alignment or fixed rates.

💡 Research Insights
For GUI Agent Research
Audio-Visual Vibe Coding shows multimodal agents can jump directly from AV perception to executable code — implies GUI agents may eventually accept voice+screen input and output actions without intermediate text reasoning.
ARIA for Multi-modal Generation
The adaptive rate constraint technique is applicable wherever two parallel generation streams (e.g., text+action tokens in agents) need synchronized but differently-paced outputs.
