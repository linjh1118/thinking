问题与动机

现有模型的五大瓶颈
① 超长文本渲染脆弱：字符数增加时出现字形扭曲、字符遗漏、排版崩溃
② 多语言排版不足：大多数系统仅在英文或中文字形上训练
③ 高分辨率写真退化：2K 及以上分辨率出现重复纹理、光照不一致
④ 复杂指令遵循差：多实体、空间约束、组合逻辑导致概念遗漏
⑤ 统一架构缺失：生成和编辑需要分离流水线
Qwen-Image-2.0 的定位
统一 T2I（文本到图像）和 TI2I（图像编辑）在单一框架内，支持幻灯片、海报、信息图、漫画等文本密集型内容。
2

架构设计

核心架构：Qwen3-VL + MMDiT
Qwen3-VL：条件编码器，提取用户输入的语义特征
VAE：16× 空间下采样率编码图像到潜空间
MMDiT：多模态 Diffusion Transformer，联合建模文本和图像 Token
高压缩 VAE 设计
• 16× 空间压缩比（vs 传统 8×）
• 残差自编码器架构
• 64 通道潜维度（f16c64）
• 语义对齐损失优化潜空间可扩散性
关键技术
MSRoPE：跨模态位置编码
RMSNorm QK：稳定联合文本-图像训练
SwiGLU：MLP 非线性激活，提升表达能力

Prompt Enhancer 模块
将用户的简短/模糊查询重写为结构化、细节丰富的提示词，适配复杂图像生成任务。通过逆工程管道构建训练数据（CoT 推理链），结合 GRPO 强化学习优化。
