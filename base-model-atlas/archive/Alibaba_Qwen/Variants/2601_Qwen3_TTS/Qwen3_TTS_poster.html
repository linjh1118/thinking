Problem & Motivation
Core Challenges
Modern TTS systems must simultaneously excel across four dimensions:
Stability (text alignment) Controllability (voice attributes) Naturalness (human-like speech) Low Latency (streaming)
Qwen3-TTS Goal
Build a unified multilingual TTS model that satisfies all four requirements simultaneously, based on the Qwen3 LM backbone — the first Qwen-series speech synthesis capability.
Key Capabilities
3-second voice cloning: reference audio enables instant voice replication

Voice Design: create and control voices via natural language

10+ languages: consistent cross-lingual generation

10+ minutes: fluent long-form speech synthesis

97ms first-packet latency: real-time interaction-grade experience
Qwen3-TTS — Alibaba Qwen Team
Core Method
Model Architecture
Based on Qwen3 LM backbone, with dual-rate dual-architecture design:
25Hz: Single codebook + chunk-wise DiT decoder 12Hz: RVQ multi-codebook + MTP + ConvNet Code2Wav
MTP (Multi-Codebook Prediction): predicts all RVQ codebook tokens at each time step simultaneously, enabling low-latency streaming speech synthesis from the first codec frame.
Three-Stage Training Pipeline
S1 General: 5M+ hours multilingual speech, establishing text→speech monotonic mapping

S2 High-Quality: curated high-quality subset, effectively mitigating hallucinations from noisy data

S3 Long-Context: max length scaled from 8K to 32K, supporting ultra-long speech synthesis
Post-Training Alignment
DPO: human preference alignment for naturalness and expressiveness

GSPO: rule-based reward signals improving stability and task consistency

Speaker Fine-tuning: custom voice cloning adaptation per speaker
Voice Design Capability
Create new voices or control existing voice attributes (speed, pitch, emotion) via natural language descriptions — no manual parameter tuning needed. Directly applicable to personalized Agent scenarios.
