Problem & Motivation

Core Problem

LLM inference is expensive. While longer Chain-of-Thought improves performance, it increases output tokens and thus inference cost.

Key Insight

"Think More, Means Less": Deeper thinking by the model produces more concise, precise final answers, reducing total output tokens.

Research Goal

Use test-time compute scaling and strong-to-weak distillation to achieve near-large-model reasoning with a small 8B model at significantly lower cost.

✦ Core Innovation

Think/Non-Think dual-mode architecture: the model adaptively switches reasoning depth based on task complexity, balancing performance and cost.

Architecture & Method

Four-Stage Training Pipeline

Qwen3 uses four-stage progressive training, expanding from basic reasoning to general capabilities.

Stage 1: Cold Start

Establish basic reasoning with long CoT data and format following.

Stage 2: Reasoning RL

Rule-based reward training for math, code, STEM reasoning.

Stage 3: Mode Fusion

Unify /think and /no_think modes with instruction-based switching.

Stage 4: General RL

20+ task coverage: Agent, tool calling, RAG, preference alignment.

✦ Strong-to-Weak Distillation

Off-policy → On-policy two-stage distillation:
• Off-policy: Mix teacher think/no_think outputs
• On-policy: Student generation + KL divergence alignment
→ 10x GPU hours saved
