With persistence:

Drop (ablation):
Ht+1(drop) = Ht ⊕ [assistant(at)] ⊕ [tool(ot)]
→ Dropping reasoning blocks causes cumulative state drift and degraded self-correction
Plan-Act-Reflect Loop: Plan → Act → Reflect (self-correct via unexpected observations)
Ablation: Reasoning State Persistence
Stripping thinking blocks before each model invocation → consistent gains across all agentic benchmarks.

Largest gains: deep search & software engineering (long-horizon multi-step tasks)
Minimal gains: short-horizon tasks
