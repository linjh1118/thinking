Paradigm: Beyond Concatenated Any-to-Any

The root issue with current multimodal systems is language-plus-auxiliary — vision/audio are bolted on as plug-ins and projected into LLM space via continuous embeddings. Three pain points: (1) architectural fragmentation (each modality has its own encoder + projection + modality-specific design); (2) understanding-vs-generation conflict (CLIP/SigLIP encoders vs VAE/VQ-VAE encoders cannot be reconciled); (3) infrastructure unfriendly (continuous features need modality-aware paths).

Fig 1: dNaViT architecture (SAE + 8-stage RVQ for any-resolution image tokenization)
DiNA: Discrete Native Autoregressive

Lexicalize text / vision / audio into discrete tokens, modeling all modalities on a single decoder-only MoE with one unified NTP objective. Architecture collapses to decoder-only + tokenizer/detokenizer pairs; understanding and generation become two conditionings of the same NTP.

No Modality-Specific Inductive Bias

Disables 3D RoPE, bidirectional attention, modality-aware MoE — all tokens share one modality-agnostic path. Per-expert avg tokens: 507 (text-only) → 584 (multi-modal, +15% capacity utilization); some experts self-specialize as "visual" or "audio".

2

dNaViT: Any-Resolution Discrete Vision

dNaViT = Discrete Native-resolution Vision Transformer — encodes arbitrary-resolution images into hierarchical discrete tokens, with a detokenizer for round-trip reconstruction. Vision discretization's core challenge is a dual bottleneck: encoder semantic capacity + continuous-to-discrete quantization loss.

Semantic Completeness Criterion
$$\mathcal{P}(A \mid z, \mathcal{Q}) \approx \mathcal{P}(A \mid I, \mathcal{Q})$$
Residual Accumulation Structure
$$\mathbf{z}_p = \mathbf{x}_0 + \sum_{l=1}^{L} \mathcal{F}_l(\mathbf{x}_{l-1})$$
SAE Encoder (Semantic-Aligned)

Picks Qwen2.5-ViT (28× spatial compression) as pre-quantization SAE — large-scale vision-language training already ensures semantic completeness. Direct reuse, no SAE-from-scratch cost.

8-Stage RVQ Discretization

Each level uses EMA-updated codebook (not gradient descent); Laplace smoothing for numerical stability; inactive entries ($N_k<1$) re-initialized from current batch to maintain codebook utilization.

Native Resolution + Variable-Length

Pack-n-Pack sequence-based modeling; different resolutions flattened into one sequence with variable-length FlashAttention. Max seq len 8192, max resolution 1736×1736.

De-tokenization (Decoupled Training)

400M ViT pixel decoder + Flow-matching refiner (init from OmniGen2) for high-frequency detail. Trained after codebook freeze; recovers spatial patch sequence via learnable MLP patch un-merger.

3

Audio Tokenizer: 12.5 Hz RVQ

Audio encoder uses Whisper-large-v3 (frozen init, then trained); 8-stage RVQ with codebook sizes 8k/4k/2k/1k/1k/1k/1k/1k at 12.5 Hz frame rate. Training data ~2.5M hours (20M hours web audio cleaned to 3.2M + 1.2M synthetic + 0.4M task-specific). Key design: borrow Qwen3-1.7B as frozen LLM supervisor to align with text space — then discard after distillation.

Fig 2: Audio Tokenizer (Whisper + 8-stage RVQ + LLM supervision)
Internal Linguistic Guidance

Following Moshi, audio generation is modeled as text-guided audio modality. Parallel (text/audio sync, audio delayed N steps) and Serial (text first, then audio, single-modality per step) become two extremes of a unified framework — each text-audio segment's delay sampled randomly from 1 to text length.

3-Stage Audio Training

decoder warm-up → semantic-acoustic joint (enable RVQ) → decoder fine-tune (DiT 24kHz).

Image Reconstruction: Residual Implicit Pathway

A surprising finding: SAE's residual architecture inherently preserves a low-level signal propagation pathway. Identity mappings prevent early-layer fine-grained signals from being overwritten by high-level semantics; signals accumulate progressively into $\mathbf{z}_p$. So even without explicit reconstruction supervision, SAE retains substantial reconstruction ability.

Fig 3: Image reconstruction comparison (different frozen encoders)
Quantization Loss
$$\mathcal{L}_{\text{quant}} = \lambda_c \mathcal{L}_{\text{commit}} + \lambda_s \mathcal{L}_{\text{semantic}}$$
Fig 4: Reconstruction quality (PSNR / SSIM / rFID)
Key Counter-Intuitive Finding

Random-initialized ViT-B/16 has the best reconstruction quality (PSNR 30.52), beating QwenViT (PSNR 18.16) and ResNet50 (20.88). This proves residual structure itself — not learned semantics — is the main source of recoverability.
