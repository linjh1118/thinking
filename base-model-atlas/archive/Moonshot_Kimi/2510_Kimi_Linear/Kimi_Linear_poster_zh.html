问题与动机

LLM 正演进为 Agent，RL test-time scaling 带来了注意力机制的效率瓶颈：soft-max attention 的二次时间复杂度、线性增长的 KV cache，在长 horizon 和 RL 场景下计算和内存开销巨大。

Linear Attention 的历史局限

Linear attention 虽有望降低复杂度，但历史上在语言建模任务上（即使短序列）性能不如 full attention，核心原因是有限状态的表达能力不足。

核心问题

如何构建一个在质量上 match 或超越 full attention、同时在速度和内存上实现 substantial efficiency gains 的注意力架构？

Hybrid 架构
少量 global attention + 大量 linear attention
3:1 比例
3 层 KDA + 1 层 Full MLA
NoPE for MLA Layers

将 positional encoding 责任完全委托给 KDA layers，使 MLA 可在推理时转换为高效 MQA。

Kimi Delta Attention (KDA)

Recurrent Formulation

\[ \mathbf{S}_t = (\mathbf{I} - \beta_t \bm{k}_t \bm{k}_t^\top) \operatorname{Diag}(\boldsymbol{\alpha}_t) \mathbf{S}_{t-1} + \beta_t \bm{k}_t \bm{v}_t^\top \]

per-channel（而非 per-head）的 decay gate，每个 feature dimension 拥有独立的 forgetting rate。

Per-Channel Gating

每个 feature dimension 有独立的 forgetting rate，实现更精确的 RNN memory 调控，比 Gated DeltaNet 的 coarse-grained gating 更有效。

Hardware-Efficient Chunkwise

使用 Diagonal-Plus-Low-Rank (DPLR) transition matrices，通过绑定参数将 second-level chunk matrix computations 从 4 个减少到 2 个。

Layerwise Hybrid

7:1 ratio 训练 loss 相近但验证 loss 差；1:1 ratio 验证 loss 相近但 inference overhead 高；3:1 是最优实践。

KDA 参数化

• $\bm{\alpha}_t \in [0,1]^{d_k}$：通过低秩投影参数化
• $\beta_t \in [0,1]$：通过 sigmoid 门控标量
• 输出门：RMSNorm + low-rank sigmoid gating

核心洞察

Kimi Linear 在 RL regime 下的优异表现为 long-horizon agentic tasks 的高效推理提供了 architecture 层面的支持，KV cache 减少 75% 对长序列 tool-use 场景尤为关键。

核心结论 1

KDA 超越 Full Attention：首次在公平比较下在 short-context、long-context 和 RL regimes 上全面超越 MLA。

核心结论 2

6× 解码加速：1M context 下达到 6× decoding throughput 提升，KV cache 减少 75%。

核心结论 3

3:1 Hybrid 最优：在 quality 和 efficiency 之间取得最佳平衡。

核心结论 4

RL Scaling 优势：在 RL algorithm 下收敛更快、更优，对 agentic tasks 尤为关键。
