Problem & Motivation
// CORE CHALLENGES
Data Efficiency High-quality voice cloning requires large-scale training data and long reference recordings
Emotional Expressiveness Most models rely on explicit emotion labels, limiting expressiveness
Pronunciation Accuracy Polyphone, rare characters, and dialect pronunciation errors (especially in Chinese)
RL Exploration RL in TTS suffers from difficult reward design and training instability
// KEY INSIGHT

Using only 100k hours of training data (vs CosyVoice3's 1M hours), GLM-TTS achieves SOTA on open-source benchmarks through a two-stage architecture and GRPO multi-reward RL. LoRA voice customization requires only 15% parameters + 1 hour of single-speaker audio.

Two-stage generation: Text-to-Token AR → Token-to-Waveform Diffusion
2
Core Methods
// SPEECH TOKENIZER (Whisper-VQ-based)
Token Rate Optimization
12.5Hz → 25Hz, vocab: 16k → 32k. Reduces high-speed articulation glitches, improves naturalness of laughter/breathing
Pitch Estimator (PE) Module
Improves pitch modeling precision and prosody alignment between cloned TTS and reference audio
Non-Causal Architecture
Removes block attention and causal convolutions, improving ASR and PE module accuracy
Speech Tokenizer + Text Tokenizer + AR Generation + Diffusion
// GRPO MULTI-REWARD RL
CER SIM Emotion Laughter
Multi-Dimensional Regularized Rewards
Hierarchical processing: individual reward regularization → weighted fusion → overall regularization
Dynamic Resampling
Auto resamples (up to 3 times) when batch reward homogenizes, preventing gradient vanishing
Adaptive Gradient Clipping (Clip-Higher)
ε_high and ε_low dynamically adjust — early strict prevention of reward hacking, later relaxation to encourage exploration
Phoneme-in Pronunciation Control

Standard characters replaced with phoneme at 20% probability; polyphone/rare chars retain original text but receive phoneme sequence via G2P. PER: 13.23% → 5.14%

Vocos2D Vocoder

2D convolution for frequency sub-bands; removes Multi-Period Discriminator; adds Discriminator Augmentation

01
GRPO Multi-Reward RL is viable for TTS: Clip-Higher + dynamic resampling + adaptive gradient clipping solve the core pain points of training instability and reward hacking
02
Data Efficiency: 100k hours vs 1M+ hours achieves equivalent quality, showing data cleaning/quality matters more than quantity
03
Phoneme-in Mechanism: Valuable for vertical scenarios requiring precise pronunciation control (education/medical/finance), implemented via 20% probability replacement + offline routing
04
Paralinguistic RL: Using ASR transcript emptiness as positive reward signal is an elegant approach for handling laughter/breathing/non-text content
