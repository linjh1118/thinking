问题与动机

多模态任务（STEM、视频、GUI Agent、OCR 等）对 VLM 推理能力要求已远超简单视觉感知，现有开源社区缺乏能在广泛场景一致超越同尺寸非-thinking 模型的多模态推理模型。

核心挑战

如何将 LLM 端 Scalable RL 的成功范式迁移到 VLM 端，实现跨领域推理能力的系统性提升？

任务覆盖

STEM 推理  |  视频理解  |  GUI Agent  |  OCR 文档解析  |  图表理解  |  视觉定位

核心洞察

RLCS（课程采样强化学习）根据模型当前能力动态筛选最 informative 样本，是 RL 在 VLM 端成功的核心工程 trick。

RLCS — 核心创新

离线+在线难度评估，pass@k 打分，优先采样中间难度样本；Ratio EMA 维持训练稳定性。

核心训练 Tricks

Force Answering（强制截断输出答案） |  去掉 KL Loss（VLM 的 KL 上升更快） |  Clip-Higher（防 entropy collapse） |  top-p=1（避免乱码） |  Per-sample loss（比 per-token 更稳定）

跨领域迁移

在一个领域训练会 boost 其他领域性能，GUI Agent 数据（OCR+视觉定位+逻辑推理）是最强跨领域 transfer 信号。

基础设施

Sequence Packing + Gradient Accumulation（32K context） |  Load Balancing across DP Ranks |  intra-rank 优化半减 F/B 时间。

核心结论 1

RLCS 课程采样是关键：不是简单混合多领域数据，而是根据模型当前能力动态筛选最 informative 样本。

核心结论 2

去 KL Loss：VLM 的 KL 散度上升更快，加 KL loss 会限制能力，与 LLM RL 不同。

核心结论 3

GUI 数据迁移强：OCR/STEM 数据可辅助 GUI Agent 训练，跨领域迁移比预期更广泛。

核心结论 4

9B 打 72B：GLM-4.1V-9B 在 29 个 benchmark 上超越 Qwen2.5-VL-72B，小模型でも 大效果。
