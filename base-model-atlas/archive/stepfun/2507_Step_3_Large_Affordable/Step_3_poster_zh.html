Problem & Motivation

解码效率瓶颈

LLM 在 decoding 阶段硬件效率极低。现有方法存在两大问题：

① Attention：过度压缩 KV cache 牺牲计算效率

② MoE FFN：过度稀疏但与硬件不匹配

核心洞察

参数量 ≠ 解码成本。Qwen3 MoE 比 Step-3 少 65% 总参，解码成本反而高 8%。

💡 关键发现

Attention 设计对解码成本的影响 > 参数总量。解码成本由 attention arithmetic intensity 和 memory bandwidth 决定。

2

Core Method

MFA Attention

Multi-Matrix Factorization Attention：对 Q-K 电路做低秩分解

• 64 Q-heads + 1 shared KV-head

• Q 投影：7168 → 2048（低秩）→ 64×256

• 减少 KV cache 同时保持计算密度

AFD 解耦推理

Attention-FFN Disaggregation：将 attention 和 FFN 部署到不同 GPU 集合

• 3-stage 流水线：A / F / comm

• 每阶段 16.6ms，总计 50ms TPOT

• FFN 批次大小与 context length 解耦

💡 AFD vs EP

AFD 仅需 32 GPU（vs DeepSeek 320 GPU），支持异构硬件和混合 TP-EP 策略，天然解决负载均衡问题。

💡 启示

Model-system co-design 才是正解。线性注意力/量化/MTP 都是好方向，但细节决定成败。

Takeaway 1
AF = 最优解码系统

Attention-FFN Disaggregation 支持独立并行策略、动态扩展、异构硬件，是比 EP 更优的解码架构

Takeaway 2
MFA 平衡 Cache 与算力

低秩 QK 分解在减少 KV cache 的同时保持足够计算密度，在弱硬件上也能高效运行

Takeaway 3
Decoding 决定智能上限

更低的解码成本 → 相同预算下更高的 intelligence → test-time scaling 的关键杠杆

Takeaway 4
Co-design 释放设计空间

AFD 让 attention 和 FFN 独立演进，MFA 与 AFD 联合优化实现新的 Pareto frontier
