问题与动机

TL;DR
PaCoRe 通过多轮并行协调推理，将测试时计算（TTC）从固定上下文窗口约束中解耦——并行扩展推理轨迹，将每轮完整轨迹压缩为结论消息（Message Compaction），实现 ~2M token 有效 TTC，8B 模型 HMMT 2025 达 94.5%，超越 GPT-5。
核心矛盾
标准链式推理（CoT）将所有中间状态压缩在单条扩展链中，推理量严格耦合上下文窗口容量——窗口填满，推理必须停止，TTC 无法继续 scaling。
推理孤立主义
Vanilla 模型即使收到并行分支的丰富信息，也会忽略上下文、从头独立解题——这被称为 Reasoning Solipsism，导致并行 TTC 被浪费。
传统方案局限
Self-Consistency（多数投票）在复杂解结构（代码/定理证明）上迅速饱和，@256 时 HMMT 仅 84.7%，Apex 恒为 0.0%。

PaCoRe 推理流程

问题 x → Round 1: K₁=32 并行轨迹 → 压缩为 M₁
M₁ 消息集 → Round 2: K₂=4 并行轨迹 → 压缩为 M₂
M₂ 消息集 → Final Round: K=1 → 答案 y
有效 TTC = Σ_r Σ_i |ω_r^(i)|，但每轮输入仅 |x| + |M_{r-1}|，上下文成本几乎恒定
消息压缩 (Message Compaction)
压缩函数 C(ω) = 最终结论段（丢弃中间推导步骤），确保输入长度始终 fits 上下文窗口，而有效 TTC 可 scaling 到数百万 token。
两阶段课程训练
Stage 1（250 iters）：筛选低消息集准确率样本，强迫模型学综合
Stage 2（450 iters）：筛选 0 < synthesis_acc < 1 的样本，聚焦综合能力
3

训练配方

SFT 数据
10.2M samples / 59.5B tokens，涵盖数学、代码、科学、软件工程、工具调用、逻辑推理、创意写作等领域。使用预定义规则过滤低质量数据 + N-gram 去污染（N=64）。
RLVR 训练
500k prompts，每步 sample 256 prompts × 16 responses。使用 off-policy PPO + GAE（γ=1, λ=1），actor lr=2e-6，critic lr=5e-6，Truncated IS ratio (C=8)，共 200 iterations。
推理配置三档
LowK=[4]~250k TTC
MediumK=[16]~900k TTC
HighK=[32,4]~2M TTC

核心设计洞察

Key Insights
并行协调推理比序贯 scaling 更高效：同等 TTC 时，PaCoRe 远优于 sequential reasoning
无消息压缩时，performance 在 TTC scaling 后退化并受限于上下文长度
Cross-checking 语言标记在训练中稳步增加，证明模型真正学会协调而非简单聚合
Emergent Correctness Rate（全部错误输入下仍生成正确答案）持续上升，说明元认知重建能力
消息集大小训练策略：|M|~U(8,16) 效果最佳（HMMT 85.2, LCB 65.1）
SWE-Verified 泛化
PaCoRe-8B (low) = 34.0% vs RLVR-8B = 29.8%，无需任务专项微调即实现跨领域迁移。
