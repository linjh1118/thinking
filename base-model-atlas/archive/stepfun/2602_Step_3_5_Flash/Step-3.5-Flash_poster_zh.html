问题与架构

核心问题
开源模型在复杂推理和 Agentic 任务上落后于闭源前沿，且长上下文部署面临严重效率瓶颈。如何在 11B 激活参数约束下实现前沿级推理能力？

Head-wise Gated Attention
引入输入依赖的 sink token 机制，将 SWA query heads 从 64 扩展到 96。几乎不增加延迟（IO-bound 区域），却显著弥合了 hybrid attention 与全注意力的性能差距。

训练与 RL 框架

Pretraining Stability
Muon 优化器：比 Adam 更准确稳定
激活裁剪：解决 SwiGLU + Muon 组合下的 logit 爆炸
17.2T tokens 训练，仅 1 次短暂 loss spike
Unified SFT Foundation
871k samples / 7.23B tokens，覆盖 Math、Code、STEM、Logic、Tool-use、Search Agent、Long Context 等领域。难度感知过滤 + 策略性平衡。
Expert Model Construction
领域特定 RL（Math/Code/Agent）生成专家轨迹
Self-Distillation
拒绝采样消除不良模式，集中专家知识到单一学生模型
Scalable RL (MIS-PO)
大规模 off-policy RL，梯度方差显著降低
MIS-PO: 离散过滤替代连续加权
在 token 级别和轨迹级别同时应用二元掩码（[0.5,2] / [0.996,1.001]），将离策略样本直接丢弃而非连续重加权。梯度噪声大幅降低，MoE 大规模 RL 训练稳定可扩展。
Reward System
RLVR：STEM 用 verifier model，Code 用沙箱执行
GenRM + MetaRM：Pairwise 偏好 + 虚假推理惩罚
Agent Reward：搜索实体匹配 + 研究报告 rubric judgment

Efficiency: 196B vs 671B+ Models
在 SimpleQA 上以 196B 总参数量（1/3 于 DeepSeek V3.2 的 671B）超越后者（31.6 vs 27.0）。在 BBH (88.2) 上与 1043B 的 Kimi K2 Base (88.7) 仅差 0.5。
Key Contribution 1
MIS-PO：将 Metropolis Independence Sampling 引入 RL，以离散二元掩码替代连续重要性加权，在 MoE 大规模 off-policy 训练中实现稳定收敛。
Key Contribution 2
S3F1 + Head-wise Gating：3:1 滑动窗口/全注意力混合布局 + 输入依赖 sink token，在几乎零额外延迟下弥合 hybrid attention 性能差距。
Key Contribution 3
效率边界重定义：11B 激活参数达到前沿级推理（IMO-AnswerBench 85.4%，LiveCodeBench 86.4%），OpenRouter 上 ~170 tokens/s 推理速度。
Key Contribution 4
PaCoRe Test-time Scaling：并行协调推理将 AIME 2025 从 97.3% 提升至 99.9%，HMMT 2025 Feb. 达到 100.0%。
