Problem & Environment

GUI 导航的核心挑战

当前瓶颈已从 grounding（选图标）转移到 screen navigation（理解导航图、点击正确图标到达目标页面）。

GE-Lab 仿真引擎

• 树状导航图：节点=页面，边=跳转

• 合成图标：随机命名防作弊

• 完全可观测：元数据支持低成本轨迹合成

💡 仿真 → 真实迁移

GE-Lab 训练的 agent 在真实世界 benchmark（ScreenSpot、AndroidWorld）上同样表现最优。

2

Method: Three-Stage RL

SFT — 记忆基础

Edge + Path 数据，ID: 98.89%，但 OOD: 55.45%

ST-RL — 单步纠正

GRPO + 4-component reward，OOD 提升至 63.06%

MT-RL — 多轮探索

A2B reward + 回溯机制，Pass@5 25.16%（最高）

Reward Hacking 对策

减少 action space 多样性，让模型专注于 click 动作而非 premature complete。

💡 SFT 过度损害 RL

早期 SFT epoch 初始化 RL 达到最高 reward。过多 SFT → plasticity 丧失。

💡 MT-RL ID 低但泛化强

MT-RL 在 ID 上低于 ST-RL，但在交互 benchmark 上最优。

Takeaway 1
三阶段范式标准

SFT 记忆基础 → ST-RL 泛化 → MT-RL 探索，可能成为 Agent 训练的标准范式

Takeaway 2
SFT 要适度

保留多样性避免 plasticity 丧失，early SFT epoch 初始化 RL 效果最佳

Takeaway 3
仿真设计决定研究质量

随机图标命名防止模型作弊，透明元数据使精确 reward 成为可能

Takeaway 4
MT-RL 最接近真实场景

交互训练比大量单轮 sampling 更高效，72.03% 真实世界平均分验证
