# Introducing GPT-5.2

GPT-5.2 is framed as OpenAI's advanced frontier model series for professional knowledge work and long-running agents.

## Key Points

- Stronger at spreadsheets, presentations, code, images, long contexts, tools, and multi-step projects.
- GPT-5.2 Thinking is reported as a new state of the art on GDPval and long-context reasoning evaluations.
- ChatGPT variants: GPT-5.2 Instant, Thinking, and Pro.
- API variants include `gpt-5.2`, `gpt-5.2-chat-latest`, and `gpt-5.2-pro`.
- Safety updates build on GPT-5 safe completions and targeted improvements for sensitive conversations.
