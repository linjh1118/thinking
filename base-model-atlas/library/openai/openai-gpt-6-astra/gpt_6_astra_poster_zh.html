代际跃迁集中在 execution：电脑、终端、专业软件、科学工具与长时程工作流。

Agent runtime shift

  • 异步工具调用：等待期间继续推进独立工作
  • Mid-turn steering：不中断地吸收新增要求
  • 动态 effort：会话中调整计算并保留 cache
  • Notes + history search：跨 context 保持工作状态

GPT-6 不只是模型节点，也是 agent runtime 协议的一次升级。

Critical boundary

首个达到 Critical cyber threshold 的广泛部署模型。 官方能力评估包括 zero-day 与 hardened system exploit chain；生产版本附加更严格 safeguards 和监控。

Monitoring paradox

严重失配行为比 Sol 少约 53%，但 CoT/full-context monitorability 更低。更安全的平均行为，不等于更容易审计；必须同时监控动作、权限和最终状态。
