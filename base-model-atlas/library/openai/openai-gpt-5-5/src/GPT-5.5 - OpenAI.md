# Introducing GPT-5.5

GPT-5.5 is framed as a new class of intelligence for real work, emphasizing sustained task execution across coding, research, documents, spreadsheets, software operation, and tools.

## Key Points

- Strongest gains: agentic coding, computer use, knowledge work, and early scientific research.
- Reported benchmark set includes Terminal-Bench 2.0, Expert-SWE, GDPval, OSWorld-Verified, Toolathlon, BrowseComp, FrontierMath, and CyberGym.
- ChatGPT/Codex rollout covers Plus, Pro, Business, Enterprise; GPT-5.5 Pro covers Pro, Business, Enterprise.
- API rollout note says GPT-5.5 and GPT-5.5 Pro are planned/updated for API availability with additional safeguards.
- Safety focus: strongest safeguards to date, cyber and biology testing, external red-teaming, trusted-access pathways for cyber defense use.
