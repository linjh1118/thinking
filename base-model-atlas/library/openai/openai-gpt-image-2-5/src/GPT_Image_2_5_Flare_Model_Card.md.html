Fast, high-quality everyday image generation

Model ID: gpt-image-2.5-flare

GPT Image 2.5 Flare is our fastest model for high-quality, everyday image generation. It accepts text and image inputs and produces image outputs. It supports low, medium, high, xhigh, max, and auto quality settings. Select it directly in the Image API or as the model of the Responses API image generation tool. Learn more in the image generation guide.

Model details

  • Default snapshot: gpt-image-2.5-flare-2026-09-08
  • Input modalities: text, image
  • Output modalities: image
