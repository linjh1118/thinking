# Introducing GPT-5.4

GPT-5.4 is positioned as a frontier model for professional work, combining reasoning, coding, computer use, and tool-heavy agent workflows.

## Key Points

- Released in ChatGPT as GPT-5.4 Thinking, in the API, and in Codex.
- First general-purpose OpenAI model with native state-of-the-art computer-use capabilities.
- Supports up to 1M context in Codex/API contexts described by the release.
- Introduces tool search so agents can look up tool definitions only when needed.
- Safety section treats GPT-5.4 as High cyber capability under the Preparedness Framework.
