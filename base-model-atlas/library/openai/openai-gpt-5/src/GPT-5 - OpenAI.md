# Introducing GPT-5

GPT-5 is described as OpenAI's unified system: a fast model for most questions, a deeper reasoning model for harder problems, and a real-time router that chooses between them based on task complexity, tool needs, and user intent.

## Key Points

- Built-in thinking for coding, math, writing, health, visual perception, and more.
- GPT-5 is OpenAI's strongest coding model at release, with improvements in front-end generation and debugging larger repositories.
- Reported benchmark highlights include SWE-bench Verified, Aider Polyglot, MMMU, HealthBench Hard, and GPQA for GPT-5 pro.
- Safety framing emphasizes safe completions, lower hallucination rates, more honest limit communication, reduced sycophancy, and biological/chemical preparedness safeguards.
- ChatGPT rollout made GPT-5 the default for signed-in users, replacing GPT-4o, OpenAI o3, OpenAI o4-mini, GPT-4.1, and GPT-4.5.
