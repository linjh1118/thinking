Structure from the proxy, appearance from the first frame 
A proxy sequence carries the layout, object classes and motion of a scene, at any level of detail. A reference first frame supplies its appearance. Each chapter below changes one input and holds the others fixed. Every clip on this page is model output, shown with the proxy that drove it.

Infra 
Real-time streaming 
The video is generated chunk by chunk, and the final pipeline delivers a chunk every 930 ms, 18.0 frames per second, 1.82× the 1770 ms baseline. Each chunk takes four denoising passes of the DiT on 8 GPUs (Ulysses8). The first pass is fused with the commit of clean history and proxy condition into the KV cache, which keeps a sink and a recent window and evicts the rest. Between DiT chunks, a lightweight TAE encodes the next proxy chunk while the decoder turns the current one into RGB, and a CPU worker delivers those frames while the DiT renders the next chunk.
