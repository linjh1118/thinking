        <h2 id="overview-title">Structure from the proxy, appearance from the first frame</h2>
        <p>A proxy sequence carries the layout, object classes and motion of a scene, at any level of detail. A reference first frame supplies its appearance. Each chapter below changes one input and holds the others fixed. Every clip on this page is model output, shown with the proxy that drove it.</p>

      <section class="infra page-width" id="infra" aria-labelledby="infra-title" tabindex="-1">
        <div class="chapter-text">
          <div>
            <p class="chapter-index mono">Infra</p>
            <h2 id="infra-title">Real-time streaming</h2>
          </div>
          <div>
            <p class="chapter-claim">The video is generated chunk by chunk, and the final pipeline delivers a chunk every 930 ms, 18.0 frames per second, 1.82× the 1770 ms baseline. Each chunk takes four denoising passes of the DiT on 8 GPUs (Ulysses8). The first pass is fused with the commit of clean history and proxy condition into the KV cache, which keeps a sink and a recent window and evicts the rest. Between DiT chunks, a lightweight TAE encodes the next proxy chunk while the decoder turns the current one into RGB, and a CPU worker delivers those frames while the DiT renders the next chunk.</p>
            <p class="chapter-variables mono"><span>8 GPUs · Ulysses8</span> <span>Fused pass 1 + KV commit</span> <span>Concurrent encode / decode</span> <span>Async delivery</span></p>
          </div>
        </div>
        <figure class="infra-figure">
          <div class="infra-diagram"><img src="./media/infra-v1/infra-io-package-v3.svg?rev=20261117" width="1080" height="625" loading="lazy" alt="Infra overview. A KV cache holds a sink, evicted slots, earlier chunks of clean history H and proxy condition C, and the newly committed KV. Two DiT blocks, each four passes on 8 GPUs with Ulysses8, read the cache; pass 1 is fused with the commit of H and C. Between them, a codec interval runs the encoder (×2) and decoder (×4) concurrently, taking proxy chunk n+1 in and putting RGB chunk n out."></div>
