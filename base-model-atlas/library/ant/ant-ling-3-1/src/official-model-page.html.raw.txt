<p class="x:not-first:mt-[1.25em] x:leading-7">Ling is a general-purpose large language model series independently developed and open-sourced by Ant Group. Built on the MoE (Mixture of Experts) architecture, it has been validated on domestic heterogeneous computing platforms, achieved breakthrough at the trillion-parameter scale, and continues to evolve with long context modeling, multimodal understanding, and AI Agent collaborative reasoning capabilities.</p>
<hr class="x:my-[2em] nextra-border">
<h2 id="why-choose-ling" class="x:tracking-tight x:text-slate-900 x:dark:text-slate-100 x:font-semibold x:target:animate-[fade-in_1.5s] x:mt-10 x:border-b x:pb-1 x:text-3xl nextra-border">Why Choose Ling?<a href="#why-choose-ling" class="x:focus-visible:nextra-focus subheading-anchor" aria-label="Permalink for this section"></a></h2>
<p class="x:not-first:mt-[1.25em] x:leading-7">Ling achieves key breakthroughs in 4 dimensions: inference efficiency, long context modeling, multimodal understanding, and training technology:</p>
<h3 id="inference-efficiency" class="x:tracking-tight x:text-slate-900 x:dark:text-slate-100 x:font-semibold x:target:animate-[fade-in_1.5s] x:mt-8 x:text-2xl">Inference Efficiency<a href="#inference-efficiency" class="x:focus-visible:nextra-focus subheading-anchor" aria-label="Permalink for this section"></a></h3>
<p class="x:not-first:mt-[1.25em] x:leading-7">Traditional Dense models require activating all parameters during inference, with computational overhead proportional to model size. Ling’s MoE architecture routes each token to activate only the most relevant expert subnetworks, compressing the actual computation to a minimal fraction while maintaining large-scale model capacity.</p>
<h3 id="long-context-support" class="x:tracking-tight x:text-slate-900 x:dark:text-slate-100 x:font-semibold x:target:animate-[fade-in_1.5s] x:mt-8 x:text-2xl">Long Context Support<a href="#long-context-support" class="x:focus-visible:nextra-focus subheading-anchor" aria-label="Permalink for this section"></a></h3>
<p class="x:not-first:mt-[1.25em] x:leading-7">Building on MoE’s efficient inference, the Ling series further advances long-sequence modeling.</p>
<ul class="x:[:is(ol,ul)_&amp;]:my-[.75em] x:not-first:mt-[1.25em] x:list-disc x:ms-[1.5em]">
<li class="x:my-[.5em]"><strong>Ling-3.1-flash</strong>: Context window up to <strong>1M</strong>; the official service currently exposes a <strong>256K</strong> context window.</li>
<li class="x:my-[.5em]"><strong>Ling-3.0-flash</strong>: Native <strong>256K</strong> context window, extendable up to <strong>1M</strong>.</li>
<li class="x:my-[.5em]">Long-range information retrieval without noticeable degradation: the model reliably retrieves information regardless of whether it appears at the beginning, middle, or end of the context.</li>
</ul>
<h3 id="native-multimodal-understanding" class="x:tracking-tight x:text-slate-900 x:dark:text-slate-100 x:font-semibold x:target:animate-[fade-in_1.5s] x:mt-8 x:text-2xl">Native Multimodal Understanding<a href="#native-multimodal-understanding" class="x:focus-visible:nextra-focus subheading-anchor" aria-label="Permalink for this section"></a></h3>
<p class="x:not-first:mt-[1.25em] x:leading-7">The first native multimodal model in the Ling series, <strong>Ling-3.0-flash-VL</strong>, is now released and open-sourced, deeply integrating visual understanding into the MoE architecture:</p>
<ul class="x:[:is(ol,ul)_&amp;]:my-[.75em] x:not-first:mt-[1.25em] x:list-disc x:ms-[1.5em]">
<li class="x:my-[.5em]"><strong>Native support for image, text, and video input</strong>: Goes beyond simple image captioning — multimodal information serves as a foundational input for reasoning, enabling deeper cross-modal understanding.</li>
<li class="x:my-[.5em]"><strong>Visual feedback closed-loop mechanism</strong>: Advances tasks through a continuous “Observe → Act → Verify → Correct” cycle, allowing the model to continuously refine execution results based on visual feedback in scenarios such as medical report interpretation, frontend code generation, and GUI automation.</li>
</ul>

<p class="x:not-first:mt-[1.25em] x:leading-7">Ling-3.0-flash-VL is the first native multimodal large model in the Ling series, extended from Ling-3.0-flash’s MoE (Mixture of Experts) architecture. It features 124B total parameters with 5.5B activated per inference, natively supports image, text, and video input, with a 256K token context window. The model is now open-sourced on Hugging Face and ModelScope.</p>
<p class="x:not-first:mt-[1.25em] x:leading-7"><strong>Advantages</strong>:</p>
<ul class="x:[:is(ol,ul)_&amp;]:my-[.75em] x:not-first:mt-[1.25em] x:list-disc x:ms-[1.5em]">

<li class="x:my-[.5em]"><strong>Visual feedback closed-loop mechanism</strong>: Introduces a continuous “Observe → Act → Verify → Correct” cycle, enabling the model to continuously refine execution results based on visual feedback, significantly improving task reliability and accuracy. Unlike one-shot image-to-output generation, this mechanism transforms the process into a dynamic, self-correcting workflow in scenarios such as medical report interpretation, frontend code generation, and GUI automation</li>
<li class="x:my-[.5em]"><strong>Arbitrary-resolution visual encoder</strong>: Introduces an arbitrary-resolution visual encoder and VideoRoPE, maintaining low-latency responses in real-time video conversations, multi-turn visual interactions, and long-duration tasks</li>
<li class="x:my-[.5em]"><strong>Deep architectural synergy</strong>: Language backbone retains the 42-layer hybrid architecture (KDA and Gated MLA alternating at a 5:1 ratio), activating only 5.5B parameters per inference from 124B total — balancing high performance with cost efficiency</li>
<li class="x:my-[.5em]"><strong>256K context window</strong>: Supports long document and long video analysis for demanding context scenarios</li>
</ul>
