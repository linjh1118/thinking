Problem & Background

Large reasoning models (LRMs) like o1 and DeepSeek-R1 achieve remarkable success through large-scale RL test-time compute scaling, but traditional Transformer softmax attention has a quadratic complexity bottleneck, limiting efficient scaling of long reasoning chains.

Pain Point 1: Efficiency

FLOPs cost of long reasoning chains is too high. At 100K tokens, DeepSeek R1 requires 4× more FLOPs than M1.

Pain Point 2: Context Limit

Existing open-source LRMs have too small context windows (typically 32K-128K), unable to handle ultra-long tasks.

Pain Point 3: RL Training Efficiency

Computational cost and stability issues when scaling RL training; token-level clipping discards critical low-probability tokens.

Figure 1: Inference FLOPs comparison (M1 vs DeepSeek R1)

Core Insight: M1 validates that Lightning Attention + CISPO can significantly reduce inference and RL training costs.

Core Method

1. Lightning Attention Hybrid Architecture

Based on MiniMax-Text-01: every 7 Lightning Attention TransNormer blocks followed by 1 softmax attention Transformer block. At 100K tokens, only requires 25% of DeepSeek R1 FLOPs.

2. CISPO Algorithm

Clipped IS-weight Policy Optimization — clips importance sampling weights rather than token updates, preserving gradient contributions from ALL tokens. Achieves same performance as DAPO with only 50% of training steps.

CISPO Core Formula:\nr̂_{i,t}(θ) = clip(r_{i,t}(θ), 1-ε^{IS}_{low}, 1+ε^{IS}_{high})
3. RL Training Engineering Challenges

Issue 1: LM head activation too large → FP32 LM output head
Issue 2: Gradient span large (1e-18~1e-5) → β1=0.9, β2=0.95, eps=1e-15
Issue 3: Repetition → early stop at prob >0.99 for 3000 consecutive tokens
