Problem & Background

Architecture-Level Leap. M3 是 M2 之后的一次架构级换代：把 frontier coding / agentic tasks、1M context、native multimodality 整合到同一个模型里，核心机制是 MiniMax Sparse Attention (MSA)。M3 的关键不只是「更会写代码」，而是把长上下文压到可承受成本后，让 agent 可以把论文、repo、日志、工具轨迹和截图/视频都放进一个持续工作线程里。

2

Method & Approach

MiniMax Sparse Attention (MSA). M2 系列的 mini-activations 设计在 agent 真实工作流上验证有效。M3 把稀疏注意力推到长上下文：1M 上下文下仍能保持可承受的延迟与成本，使 agent 工作线程可承载 论文 + repo + 日志 + 工具轨迹 + 截图/视频。M3 同时原生支持图像/视频 token，sparse 机制保证多模态不会让上下文预算爆炸。

3

Results & Insights

From Capability to Workflow. 1M context + native multimodality 共同支撑一个判断：模型可以开始以「持续工作线程」的方式面对复杂任务。M3 不只是 benchmark 数字的提升，而是让 agent 把所有上下文信息装进同一个 context window 里持续工作，让真实编程任务、长程 agent 任务成为可工程化的目标。
