Agent deployment lens

  • 不同 effort 下测成功率—成本—延迟 Pareto frontier
  • 记录工具调用、失败恢复和超时，而不只看最终答案
  • 价格必须转成 cost per successful task
  • 多语言 safety 必须单独回归

Flash 的核心不是“便宜的问答”，而是“可规模化的 agent execution”。
