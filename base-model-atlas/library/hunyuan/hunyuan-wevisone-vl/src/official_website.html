One model, every granularity: from points and boxes to binary masks and continuous alpha mattes — and a confident None when the target isn't there. Abstract 
Fine-grained perception, reliably . 
Existing vision-language models remain unreliable for fine-grained visual perception. We present WeVisOne-VL ( We Chat Vis ion all-in- One ), a VLM that unifies object-level and pixel-level
        perception through structured next-token prediction . It supports object detection, referring localization,
        counting, pointing, OCR, segmentation and matting — localizing at any user-specified granularity, from points and
        boxes to masks and alpha mattes. 
A lightweight 9.6M-parameter pixel decoder is plugged into the VLM through a special <OBJ> token to produce instance-level pixel outputs. Trained with a three-stage curriculum SFT followed by mixed-task RL on ~100M images,
        WeVisOne-VL leads 30+ benchmarks across object- and pixel-level tasks while robustly rejecting queries for absent objects. Interactive

A VLM that speaks coordinates — and paints pixels. 
Built on Qwen3-VL. No SAM, no external segmentation backbone — the pixel decoder reuses the VLM's own multi-level ViT features. Click to enlarge 01 
Visual Feature Adapter 
Taps four levels of pre-merge Qwen3-VL ViT features , projects and refines them with depthwise-conv blocks into a shared pixel feature pyramid. 02 
Box-guided Query Decoder 
Each <OBJ> hidden state + a Fourier-encoded box prior becomes an instance query, refined by 6 deformable cross-attention blocks . 03 
Instance-conditioned Dense Head 
Dynamic kernels predict masks, then a coarse-to-fine cascade (S/4 → S/2 → S/1) recovers hair-level, full-resolution alpha mattes.
