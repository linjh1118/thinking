  <!-- ================================================================ abstract -->
  <section id="abstract">
    <h2 class="sec-title">Abstract</h2>
    <div class="measure" style="margin-top:20px">
      <p>Parallel speculative drafting generates multiple candidates in one backbone pass, but independent token selection can produce inconsistent continuations that shorten the accepted prefix. Existing methods mostly leave conditional decoding to a lightweight module after the backbone, which limits the flow of predecessor information to successors. Our analysis of DFlash shows that early positions already form recoverable predictions in shallow layers, and that accurate adjacent predecessors help successors more when they enter earlier.</p>
      <p>We therefore propose DSpine, a drafter with causal conditioning injection throughout the backbone: at every layer, gated adjacent injection writes each predecessor's predicted feature into its successor, so the causal conditioning chain unfolds over network depth while all positions update in parallel. A unified transfer space built from the target model's output embeddings unifies layer-wise injection with predecessor-conditioned decoding, and layer-wise output-embedding supervision promotes the formation of predicted features in shallow layers. Fused kernels and a transition cache execute both efficiently in parallel within SGLang.</p>
      <p>Across seven math, code, and chat benchmarks, DSpine achieves the longest acceptance length at both temperatures on Qwen3-4B and Qwen3-8B. At temperature zero on Qwen3-8B, it raises the seven-benchmark mean from DFlash's 3.77 to 4.82 (+27.8%); in SGLang serving tests, it delivers 23.3% higher throughput than DFlash on average.</p>
    </div>
  </section>

  <!-- ================================================================ method -->
  <section id="method">
    <h2 class="sec-title">Method</h2>
    <p class="sec-lead">One injection carries predecessor information from the first layer to the last write.</p>
    <figure class="in-measure">
      <div class="plate"><img src="assets/overview.jpg" width="4500" height="1644" alt="DSpine overview: (a) injection passes predecessor features to successors at every layer, and transition-cached decoding selects each token conditioned on its selected predecessor; (b) one injection layer with gate, message, and write-back."></div>
      <figcaption>(a) Injection passes predecessor features to successors at every layer (green); after the final layer, transition-cached decoding selects each token conditioned on its selected predecessor (orange). (b) One injection layer: predecessor and successor features jointly gate how much of the predecessor's message enters the successor's residual stream.</figcaption>
    </figure>
    <div class="points">
      <p><b>Unified transfer space.</b> Hidden states mix a predecessor's prediction with its context, so DSpine passes the prediction itself, in a fixed space built from the target LM head's output embeddings. An undecided predecessor sends a predicted feature; a decoded token enters as its embedding. Both take the same form, so one pathway carries either.</p>
      <p><b>Adjacent causal injection.</b> After every layer, each position receives a gated message from its immediate predecessor only. With block-causal attention, the dependency chain unfolds over depth while every layer still updates all positions in parallel.</p>
      <p><b>Predecessor-conditioned decoding.</b> Once a predecessor's token is decoded, its embedding replaces the predicted feature and the last write is redone, with no new module. A transition cache scores all K×K candidate pairs in parallel, so selection becomes a lookup.</p>
      <p><b>Layer-wise output-embedding supervision.</b> Each layer's predicted feature is aligned by cosine with the correct token's embedding, which helps features form in shallow layers and keeps them close to the embeddings used in decoding.</p>
    </div>
  </section>

     pairs (transition cache) and the tokens are then read off by lookup.
   The decode bars are drawn to scale with the measured post-backbone head time per round (paper Fig. 6, Qwen3-8B,

  const showIf = (e, on) => e.setAttribute('opacity', on ? 1 : 0);

  function build(svg, kind) {
    const P = { kind, slabs: [], nodes: [], vl: [], inj: [], heads: [], fills: [], toks: [], cond: [], grids: [], badges: [] };
    [['input', Y_IN], ['layer 1', Y_L[0]], ['layer 2', Y_L[1]], ['layer 3', Y_L[2]], ['layer L', Y_L[3]], ['head', Y_HEAD], ['output', Y_OUT]]
      .forEach(([s, y]) => txt(s, { x: 4, y: y + 3.5, class: 'rowlab' }, svg));
    Y_L.forEach(y => P.slabs.push(el('rect', { x: 62, y: y - 15, width: 244, height: 30, rx: 8, class: 'slab' }, svg)));
    X.forEach((x, c) => {
      const segs = [[Y_IN + 11, Y_L[0] - NH / 2]];
      for (let k = 1; k < NL; k++) segs.push([Y_L[k - 1] + NH / 2, Y_L[k] - NH / 2]);
      if (c > 0) { segs.push([Y_L[NL - 1] + NH / 2, Y_HEAD - 9]); segs.push([Y_HEAD + 9, Y_OUT - 12]); }
      P.vl.push(segs.map(([a, b]) => {
        el('line', { x1: x, y1: a, x2: x, y2: b, class: 'vline' }, svg);
        return { a, b, dot: el('circle', { cx: x, cy: a, r: 2.6, class: 'pulse', opacity: 0 }, svg) };
      }));
    });
    if (kind === 'dspine') {
      Y_L.forEach(y => {
        const row = [];
        for (let c = 1; c < X.length; c++) {
          const x1 = X[c - 1] + NW / 2 + 1, x2 = X[c] - NW / 2 - 1;
          const line = el('line', { x1, y1: y, x2: x2 - 4, y2: y, class: 'inj-line', opacity: .22 }, svg);
          const hd = el('polygon', { points: arrowHead(x1, y, x2, y, 5.5), class: 'inj-head', opacity: .22 }, svg);
          const gate = el('circle', { cx: (x1 + x2) / 2 - 1, cy: y, r: 3.8, class: 'gate' }, svg);
          const dot = el('circle', { cx: x1, cy: y, r: 2.6, class: 'pulse g', opacity: 0 }, svg);
          row.push({ x1, x2, line, hd, gate, dot });
        }
        P.inj.push(row);
      });
    }
    Y_L.forEach(y => P.nodes.push(X.map(x => el('rect', { x: x - NW / 2, y: y - NH / 2, width: NW, height: NH, rx: 5, class: 'node' }, svg))));
    el('rect', { x: X[0] - 20, y: Y_IN - 11, width: 40, height: 22, rx: 11, class: 'anchor' }, svg);
    txt('in', { x: X[0], y: Y_IN + 4, 'text-anchor': 'middle', class: 'anchor-t' }, svg);
    for (let c = 1; c < X.length; c++) {
      el('rect', { x: X[c] - 20, y: Y_IN - 11, width: 40, height: 22, rx: 11, class: 'mask' }, svg);
      txt('[M]', { x: X[c], y: Y_IN + 3.5, 'text-anchor': 'middle', class: 'mask-t' }, svg);
    }
    // conditioning arrows from the decoded token at t-1: into the next head (serial) or onto a row of the cache (DSpine)
    if (kind !== 'none') {
      for (let c = 2; c < X.length; c++) {
        const x1 = X[c - 1] + 16, y1 = Y_OUT - 12;
        const x2 = kind === 'dspine' ? (X[c - 1] + X[c]) / 2 : X[c] - NW / 2 + 2;
        const y2 = kind === 'dspine' ? Y_HEAD + 12 : Y_HEAD + 9;
        const len = Math.hypot(x2 - x1, y2 - y1);
        const g = el('g', { opacity: 0 }, svg);
        const path = el('path', { d: `M${x1},${y1} L${x2},${y2}`, class: 'cond-line', 'stroke-dasharray': len.toFixed(1), 'stroke-dashoffset': len.toFixed(1) }, g);
        const hd = el('polygon', { points: arrowHead(x1, y1, x2, y2, 6), class: 'cond-head', opacity: 0 }, g);
        P.cond.push({ g, path, hd, len });
      }
    }
    // heads (with a fill that shows the head's computation) and output tokens
    for (let c = 1; c < X.length; c++) {
      P.heads.push(el('rect', { x: X[c] - NW / 2, y: Y_HEAD - 9, width: NW, height: 18, rx: 9, class: 'head' }, svg));
      const clip = el('clipPath', { id: `hc-${kind}-${c}` }, svg);
      el('rect', { x: X[c] - NW / 2, y: Y_HEAD - 9, width: NW, height: 18, rx: 9 }, clip);
      P.fills.push(el('rect', { x: X[c] - NW / 2, y: Y_HEAD - 9, width: 0, height: 18, class: 'head-fill', 'clip-path': `url(#hc-${kind}-${c})` }, svg));
      const g = el('g', { opacity: 0 }, svg);
      el('rect', { x: X[c] - 27, y: Y_OUT - 12, width: 54, height: 24, rx: 12, class: 'tok' }, g);
      txt(WORDS[kind][c - 1], { x: X[c], y: Y_OUT + 4, 'text-anchor': 'middle', class: 'tok-t' }, g);
      P.toks.push(g);
      if (kind === 'post') {
        const b = el('g', { opacity: 0 }, svg);
        el('circle', { cx: X[c] + NW / 2 + 1, cy: Y_HEAD - 9, r: 6.5, class: 'badge' }, b);
        txt(String(c), { x: X[c] + NW / 2 + 1, y: Y_HEAD - 5.8, 'text-anchor': 'middle', class: 'badge-t' }, b);
        P.badges.push(b);
      }
    }
    // DSpine: transition cache for the transitions 1->2 and 2->3, on the head row between the heads
    if (kind === 'dspine') {
      [2, 3].forEach(c => {
        const S = 7, gx = (X[c - 1] + X[c]) / 2 - 1.5 * S, gy = Y_HEAD - 1.5 * S, cells = [];
        for (let i = 0; i < 3; i++) for (let j = 0; j < 3; j++) cells.push(el('rect', { x: gx + j * S, y: gy + i * S, width: S - 0.8, height: S - 0.8, rx: 1, class: 'gcell', opacity: 0 }, svg));
        P.grids.push({ cells, sel: c === 2 ? 3 : 7 });   // the cell the lookup lands on
      });
      P.parLabel = txt('all at once', { x: X[1] - NW / 2 - 6, y: Y_HEAD + 3.5, 'text-anchor': 'end', class: 'cap acc', opacity: 0 }, svg);
    }
    if (kind === 'none') P.mismatch = el('rect', { x: X[1] - 31, y: Y_OUT - 16, width: X[2] - X[1] + 62, height: 32, rx: 16, class: 'mismatch', opacity: 0 }, svg);
    const caps = {
      none: ['“Los York”: each likely, together wrong', 'cap bad'],
      post: ['Consistent, but one head pass per position', 'cap'],
      dspine: ['Consistent; K×K scores at once, then lookup', 'cap good'],
    };
    P.cap = txt(caps[kind][0], { x: 184, y: Y_CAP, 'text-anchor': 'middle', class: caps[kind][1], opacity: 0 }, svg);
    // decode bar: head time per round, to scale
    if (kind !== 'none') {
      txt('decode', { x: 4, y: Y_BAR + 3.5, class: 'rowlab' }, svg);
      el('rect', { x: BAR_X, y: Y_BAR - 3, width: BAR_W, height: 6, rx: 3, class: 'dbar-track' }, svg);
      P.dbar = el('rect', { x: BAR_X, y: Y_BAR - 3, width: 0, height: 6, rx: 3, class: kind === 'dspine' ? 'dbar ours' : 'dbar' }, svg);
      P.dbarEnd = kind === 'dspine' ? 0.36 : 0.925;
    }
    return P;
  }

  function moveV(seg, p) {
    showIf(seg.dot, p > 0 && p < 1);
    seg.dot.setAttribute('cy', (seg.a + (seg.b - seg.a) * ease(p)).toFixed(1));
  }

  function render(P, t) {
    for (let k = 0; k < NL; k++) {
      const s = layerStart(k);
      P.slabs[k].classList.toggle('on', t >= s && t < s + LD);
      const arrived = t >= s + 0.42, injected = P.kind === 'dspine' && t >= s + 0.95;
      P.nodes[k].forEach((n, c) => { n.classList.toggle('done', arrived); n.classList.toggle('inj', injected && c > 0); });
      P.vl.forEach(row => moveV(row[k], prog(t, s, s + 0.42)));
      if (P.kind === 'dspine') P.inj[k].forEach(a => {
        const p = prog(t, s + 0.5, s + 0.95);
        showIf(a.dot, p > 0 && p < 1);
        a.dot.setAttribute('cx', (a.x1 + (a.x2 - a.x1) * ease(p)).toFixed(1));
        const lit = t >= s + 0.5;
        a.line.setAttribute('opacity', lit ? 1 : .22);
        a.hd.setAttribute('opacity', lit ? 1 : .22);
        a.gate.classList.toggle('flash', t >= s + 0.66 && t < s + 0.86);
      });
    }
    const tokT = P.kind === 'none' ? [D + 0.6, D + 0.6, D + 0.6] : P.kind === 'post' ? T_POST.tok : T_DSP.tok;
    P.vl.forEach((row, c) => {
      if (c === 0) return;
      moveV(row[NL], prog(t, D, H0));
      moveV(row[NL + 1], prog(t, tokT[c - 1] - 0.2, tokT[c - 1]));
    });
    // heads: DFlash reads its LM head at once; the serial head fills one head after another; DSpine fills all at once
    P.heads.forEach((h, i) => {
      h.classList.toggle('on', t >= H0);
      let p = 0;
      if (P.kind === 'none') p = prog(t, H0, D + 0.6);
      if (P.kind === 'post') p = prog(t, T_POST.head[i][0], T_POST.head[i][1]);
      if (P.kind === 'dspine') p = prog(t, T_DSP.par[0], T_DSP.par[1]);
      P.fills[i].setAttribute('width', (NW * p).toFixed(1));
      P.fills[i].setAttribute('class', 'head-fill' + (P.kind === 'none' ? '' : ' o'));
      h.classList.toggle('cond', P.kind !== 'none' && p > 0 && p < 1);
    });
    P.toks.forEach((g, i) => showIf(g, t >= tokT[i]));
    const timing = P.kind === 'post' ? T_POST : P.kind === 'dspine' ? T_DSP : null;
    P.cond.forEach((a, i) => {
      const [a0, a1] = timing.arrow[i], p = prog(t, a0, a1);
      showIf(a.g, t >= a0);
      a.path.setAttribute('stroke-dashoffset', (a.len * (1 - ease(p))).toFixed(1));
      showIf(a.hd, p >= 1);
    });
    P.badges.forEach((b, i) => showIf(b, t >= T_POST.head[i][0]));
    if (P.kind === 'dspine') {
      const gp = prog(t, T_DSP.par[0], T_DSP.par[1]);
      P.grids.forEach((g, gi) => g.cells.forEach((cell, j) => {
        showIf(cell, gp > j / 9);
        cell.classList.toggle('sel', t >= T_DSP.tok[gi + 1] - 0.05 && j === g.sel);
      }));
      showIf(P.parLabel, t >= T_DSP.par[0] + 0.05);
    }
    if (P.dbar) {
      const end = P.kind === 'dspine' ? DSP_END : POST_END;
      P.dbar.setAttribute('width', (P.dbarEnd * MS_PX * prog(t, H0, end)).toFixed(1));
    }
    if (P.mismatch) showIf(P.mismatch, t >= D + 1.1);
    showIf(P.cap, t >= (P.kind === 'none' ? D + 1.1 : timing.cap));
    if (P.kind === 'post') P.chip.className = 'chip' + (t >= H0 ? ' live-o' : '');
    if (P.kind === 'dspine') P.chip.className = 'chip' + (t >= layerStart(0) + 0.5 ? ' live-g' : '');
  }

  const root = document.getElementById('demo');
  if (!root) return;
  const panels = [...root.querySelectorAll('.panel')].map(p => {
    const P = build(p.querySelector('svg'), p.dataset.kind);
    P.chip = p.querySelector('[data-chip]');
    return P;
  });

  const phaseBox = document.getElementById('demo-phases');
  const phases = [['Input', 0, 'minor'], ['Layer 1', layerStart(0), ''], ['Layer 2', layerStart(1), 'minor'], ['Layer 3', layerStart(2), 'minor'], ['Layer L', layerStart(3), ''], ['Decode', D, '']]
    .map(([name, s, cls]) => {
      const e = document.createElement('span');
      e.textContent = name; e.className = cls;
      e.style.left = `${(s / TMAX) * 100}%`;
      phaseBox.appendChild(e);
      return { e, s };
    });

  const scrub = document.getElementById('demo-scrub');
  const playBtn = document.getElementById('demo-play');
  const playIcon = document.getElementById('demo-play-icon');
  const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  const hasIO = 'IntersectionObserver' in window;
  let t = TMAX, playing = false, last = 0, holdUntil = 0, visible = !hasIO, started = false, userPaused = false;

  function draw() {
    panels.forEach(P => render(P, t));
    scrub.value = String(Math.round((t / TMAX) * 1000));
    phases.forEach((p, i) => p.e.classList.toggle('on', t >= p.s && (i === phases.length - 1 || t < phases[i + 1].s)));
  }
  function setPlaying(v) {
    playing = v;
    playBtn.setAttribute('aria-label', v ? 'Pause' : 'Play');
    playIcon.innerHTML = v
      ? '<rect x="2.5" y="2" width="3" height="10" rx="1" fill="currentColor"/><rect x="8.5" y="2" width="3" height="10" rx="1" fill="currentColor"/>'
      : '<path d="M3.5 2.2v9.6a.6.6 0 0 0 .9.5l7.6-4.8a.6.6 0 0 0 0-1L4.4 1.7a.6.6 0 0 0-.9.5z" fill="currentColor"/>';
    if (v) { last = performance.now(); requestAnimationFrame(tick); }
  }
  function tick(now) {
    if (!playing) return;
    if (!visible) { setPlaying(false); return; }          // resumes when scrolled back into view
    const dt = Math.min(0.1, (now - last) / 1000); last = now;
    if (holdUntil) { if (now >= holdUntil) { holdUntil = 0; t = 0; } }
    else { t += dt; if (t >= TMAX) { t = TMAX; holdUntil = now + HOLD * 1000; } }
    draw();
    requestAnimationFrame(tick);
  }
  playBtn.addEventListener('click', () => {
    if (playing) { userPaused = true; setPlaying(false); return; }
    userPaused = false; visible = true;
    if (t >= TMAX) { t = 0; holdUntil = 0; }
    setPlaying(true);
  });
  document.getElementById('demo-replay').addEventListener('click', () => {
    t = 0; holdUntil = 0; userPaused = false; visible = true; draw();
    if (!playing) setPlaying(true);
  });
  scrub.addEventListener('input', () => {
    t = (Number(scrub.value) / 1000) * TMAX; holdUntil = 0;
    if (playing) setPlaying(false);
    userPaused = true; draw();
  });

  draw();                                    // complete at rest: the page opens on the finished comparison
  if (hasIO) {
    new IntersectionObserver(entries => entries.forEach(e => {
      visible = e.isIntersecting;
      if (!visible || reduce || userPaused || playing) return;
      if (!started) { started = true; t = 0; holdUntil = 0; draw(); }
      setPlaying(true);
    }), { threshold: 0.3 }).observe(root);
  }
})();
</script>
