HyFF 0.2.0 model weights 
Weights of the five HyFF models (package: AI4Science/hyff in this repository). The hyff package downloads them into its cache on first use ( $HYFF_HOME/checkpoints , default ~/.cache/hyff/checkpoints ); hyff download all fetches all of them ahead of time. Every file is checked against the sha256 in hyff-manifest.json , which is the checkpoint index shipped with the package. To install from another location set HYFF_MIRROR to a URL or directory that holds these files under the same names.
