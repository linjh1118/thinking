騰訊混元Hy3正式發布：Agent能力顯著提升，產品深度融合 2026年07月06日 
騰訊混元Hy3今日正式發布。相比preview版本，該模型智能水平顯著強於同尺寸模型，且比肩參數規模2—5倍的旗艦模型，總體穩定性和成本效益方面亦有大幅提升。 
Hy3已廣泛接入騰訊WorkBuddy/CodeBuddy、元寶、Marvis、ima等多項業務中，其API已在騰訊雲TokenHub上線，並將在多個海外API平台陸續接入。 
Hy3 是一個快慢思考融合的模型，採用混合專家（MoE）架構，總參數達2,950億、激活參數210億，支持256K上下文長度。4月23日發布的Hy3 preview為混元重建後首個版本，在複雜推理、指令遵循、上下文學習、代碼生成與智能體能力上相較於Hy2實現質變。 
Hy3延續了清晰陡峭的能力增長曲線，通過進一步提升後訓練的算力規模以及數據質量和多樣性，在各類任務上較Hy3 preview再次躍升，以較小尺寸首次比肩大尺寸旗艦模型的效果。Hy3 在軟件開發、辦公生產、金融建模、前端設計、遊戲製作等生產力任務上的進步尤其顯著，可以成為高性價比的可靠選擇。 
真實場景海量反饋打磨，顯著提升用戶體驗 
Hy3 在全球開發者的使用以及騰訊海量真實業務中歷練，從preview上線以來日均詞元（token）消耗量增加了20倍，體現了高性價比實用模型的定位開始受市場認可。 
作為國內最受歡迎的AI辦公智能體，WorkBuddy擁有自動化腳本生成、工作流程編排等真實且複雜的場景需求，為混元模型能力迭代提供了高價值的方向。自發佈以來，WorkBuddy上自主選擇Hy3 preview的用戶數增長了6倍。 
基於 Hy3 大幅提升的 Agent 能力，元寶也上線了 Agent 功能 。用戶在日常對話中輸入需求，元寶即可直接執行複雜任務並交付PPT、Word、Excel、PDF、HTML等文件，滿足日常辦公需求，且全部免費。 
Hy3 也增強了 ima 的知識庫問答能力，推理更系統、資訊覆蓋更全面，長文寫作與方案生成的結構完整度與可用性明顯提升。在 Agent 場景中，Hy3 的任務規劃與工具調度能力也進一步提升。 
Hy3提升了Marvis Agent的文件編輯與生成、文件管理、電腦診斷與操作等核心能力，並支持更可靠的多 Agent 協作，在速度、穩定性與成本方面帶來實質性提升。 
混元也在持續支持微信和遊戲的各種業務。在微信公眾號的客服場景中，由 Hy3 驅動的 AI 客服助手能更好地理解用戶意圖，面對不完整的表達也能結合賬號定位與上下文合理判斷，不腦補過度或機械套模板。 
在遊戲場景中，WeGame平台近期上線的《流放之路：降臨》 AI遊戲助手接入Hy3後，輸出準確度顯著提升，玩家體驗也得到優化。 
堅持高性價比開放路線，普惠更多用戶和行業 
在開源方面，Hy3 採用商業友好度高的Apache2.0開源協議，全球開發者均可下載和免費商用。為進一步方便全球開發者使用，Hy3將陸續在多個海外平台上線，覆蓋OpenRouter、Hermes、Kilo、Cline、OpenClaw、OpenCode、Cherry Studio等，且同時「day 0」接入開源模型社區Huggingface、Modelscope魔搭平台。 
從2026年1月底的基礎設施重建，到4月Hy3 preview的發布，再到今天Hy3的進步，混元僅用了不到半年的時間跑通了底層重構到產品反哺的完整模型研發鏈路。未來，騰訊混元將持續加速技術迭代，不斷探索模型智能上限，並重點打造真實場景的應用落地能力，將領先的大模型能力轉化為千行百業的普惠生產力。 分享
