定位与证据边界

输入蛋白质序列，输出残基/整蛋白表征或MLM logits。Hyra 2.0从头研发；科学模型专项，不等于混元通用聊天正代。

表征与突变评分不是药效结论

encode输出[L,1280]或mean pooling[1280]；logits用于masked marginal。分数差不是实验适应度差。

README、config与官方图已读；独立报告仅PDF链接。训练数据去污染、各任务划分、统计检验与消融仍不能完整审核。

序列预处理

自动大写、去空白、J转X；非法字符报错。单条最多8190残基，不是batch_tokens32768。

表示编码

返回CPU FP32 tensors，去首尾special tokens；层16可读，mean pooling保持[1280]。

预测接口

MLM logits[L,33]；第三残基用masks=[2]。词表顺序由tokenizer读取，不猜氨基酸编号。

机制与执行协议

32层Transformer、hidden1280、20heads、词表33。FP32权重约2.6GB，服务默认INT8；发布精度、推理精度、训练精度不能混写。

图2：手绘研读；三类模型任务不同，不构成因果链。
高效引擎不等于更强训练目标

padding-free packing、Triton融合、INT8矩阵乘法和FlashAttention改变执行；不能直接归因模型新能力。

数据与计算不是一回事

博客训练726B tokens，为ESM-2 650M的0.73倍、E1/ESM C的1/5–1/8。不能推成同去重语料、同质量或同GPU时长。

研读记号 · 不补造训练目标
ΔℓT3V=log⁡p(V∣x∖3)−log⁡p(T∣x∖3)

README masked-marginal示例的研读记号；不是实测突变效应。

精度选择

INT8默认约130k残基/s；BF16约90k。近变体监督回归建议BF16，避免扰动压过约1%表征差。

复现记录

固定revision、精度、layer、pooling、打包预算、数据划分与硬件；多GPU每卡一个worker。
