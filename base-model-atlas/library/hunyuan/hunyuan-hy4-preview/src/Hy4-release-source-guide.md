# Hy4 正式版一手来源

- [腾讯混元正式发布文（2026-11-04）](https://hunyuan.tencent.com/research/hy4?langVersion=zh)提供视觉、桌面、开发、办公、科研案例和评测附录。
- [腾讯云 TokenHub](https://console.cloud.tencent.com/tokenhub/models/detail?modelId=hy4)与 [OpenRouter](https://openrouter.ai/tencent/hy4)是正文给出的托管渠道。
- [OpenRouter 端点元数据](https://openrouter.ai/api/v1/models/tencent/hy4/endpoints)列出正式服务名称、1,048,576 上下文、65,536 最大输出 token 及文本／图片输入。
- [8 月 Preview HF 模型卡](https://huggingface.co/tencent/Hy4-preview)给出 Preview 的权重和架构。正式版系统卡、完整报告与权重仍待核。
