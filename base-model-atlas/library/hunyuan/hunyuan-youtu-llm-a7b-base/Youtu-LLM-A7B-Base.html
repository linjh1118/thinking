Youtu-LLM-A7B-Base：混合注意力的稀疏视觉语言基座

我的判断
这是约120B总参数、每token约7B激活的预训练视觉语言MoE基座，不是7B总参数聊天模型。3层KDA线性注意力交错1层GatedMLA，结合细粒度专家和模态感知路由；它适合研究后训练起点，不能凭提供chat template就认为已经完成SFT/RL或工具使用对齐。
日期、图片与资料深度均有缺口
本轮于2026-10-21首次观察到该官方仓库，原卡没有明确首发日，也没有确认首发月；目录中的2610只是归档月份线索，不认证首发月份。没有找到本版独立Tech Report或官方配图，不能达到完整技术报告精读深度。本文两图均为依据原卡与配置绘制的研读示意，非官方图、模型输出或本地复测。旧2B模型的2512.24618报告不冒充本A7B报告。

身份与证据链

主证据为🤗 HF Model Card，已保存原始MD、config.json、configuration_youtu_vl_moe.py、LICENSE.txt和仓库元数据。取得时revision为a4fe6c899679a4c66da0d6e52cdbfd2f1814b0fb，实际URL和SHA256在src/retrieval_manifest.json。

仓库createdAt为1月5日、lastModified为10月21日，两者都不证明首次公开发布日。本轮将它作为日期待核的Youtu支线收录，不放进精确日期的近30天发布表。它不是Hunyuan聊天主线的新正代，也不是文档解析Youtu-Parsing-Omni的参数SKU。

10 月 27 日模型卡补充：反向的多模态预训练起点

官方卡新增说明：与常见 MLLM 使用已训练语言骨干再连接视觉模块的路线相比，本模型将随机初始化 LLM 连接到预训练 ViT，按 4K→32K→128K→256K 上下文分阶段预训练。这里“反向”是官方对训练起点的描述，不意味着各注意力模块反向执行，也不是新增 checkpoint 或新首发日。

这使 11.5T 多模态 tokens 与语言骨干从头学习的关系更清楚，但卡没有给出每阶段 token 配比、冻结/解冻策略和可控消融。不能据此断言随机语言初始化一定优于成熟 LLM 起点。对 Agent Training，更有价值的实验是固定数据和算力，比较先验语言能力与视觉对齐的取舍，并单列长上下文扩展的收益；本轮只更新文档证据，没有运行这项实验。

Base意味着什么

原卡推荐raw text continuation：给少样本格式后续写，而不是默认多轮助手。示例提供chat_template.jinja，但没有公布SFT、偏好训练或RL配方。元数据标签里的conversational、模板里的工具语法也不能当作已验证的Agent能力。

图像需通过processor传入，并与<|vision_start|><|image_pad|><|vision_end|>占位符对应。配置有video token不等于本卡已验证视频能力；原卡明确的是text+image，本文不扩大输入范围。

服务契约和安全边界

原卡固定Transformers5.12.1，要求trust_remote_code=True，这会执行仓库代码；本轮只保存和阅读源码，没有加载、安装、执行或推理。SGLang0.5.17要用仓库自带adapter，不能照搬通用launch命令；8GPU推荐TP4/DP2/EP4仅为官方例程，不是本地资源申请。

Overlap scheduler默认关闭；仅文本服务可开以提高吞吐，高并发图像会在event_loop_overlap挂住。原卡没有同硬件latency/throughput表，因此不虚构实时速度或成本领先。许可证卡片字段是other/youtu-llm，具体条文保留在原始LICENSE，不仅凭标签判断使用边界。

对Agent Training的启发
这个基座的长上下文、视觉定位与稀疏路由值得作为后训练起点，但Agent实验应固定raw/base、SFT、RL三个阶段，不能拿模板支持冒充学习收益。视觉grounding、任务规划、工具调用、最终状态验证分层评估；保留跨模态负载、图像高并发挂起及失败轨迹。真正重要的是同预算下完成率和每成功任务成本，而非只看7B激活标签。
