问题与模型定位

这是预训练Base，不是默认聊天助手。48层混合注意力和细粒度MoE连接文本、图像。模型卡未给首发日：10月仅为归档线索，不进入精确日期近30天表。

总参数与激活量分开

HF约118.387B张量统计；BF16权重约236GB，不是7B显存即可装下。

产品谱系保持独立

归腾讯Youtu支线；不是Hunyuan聊天新正代，也不是Youtu-Parsing的尺寸SKU。

混合注意力

[KDA,KDA,KDA,MLA]重复12次；线性注意力与GatedMLA交错，不能凭结构断言因果增益。

细粒度MoE

256 routed专家、top8、1 shared；首层dense设置，模态感知bias与quantile balancing。

视觉与上下文

ViT深27、hidden1152；262144 tokens是容量，不是长文任意位置可靠率保证。
