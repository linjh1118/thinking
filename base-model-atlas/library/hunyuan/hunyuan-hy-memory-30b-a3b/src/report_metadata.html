Title: Hy-Memory-30B-A3B: Attributed Reinforcement Learning for Long-Term Memory Writing Authors: Tianxiang Fei , Jiazheng Kang , Mao Zheng , Xingyan He , Xiang Yu View a PDF of the paper titled Hy-Memory-30B-A3B: Attributed Reinforcement Learning for Long-Term Memory Writing, by Tianxiang Fei and 4 other authors View PDF HTML (experimental) Abstract: External-memory systems extend language-model applications beyond a context window, but their quality depends critically on the model executing the write path: deciding what to retain, how precisely to represent it, and how new evidence should update persistent state. Existing frameworks typically place a general-purpose large language model behind framework-specific prompts. This raises serving cost, and a writer specialized for one protocol does not transfer directly to another; a unified model that can operate across established memory frameworks remains largely unexplored. We present Hy-Memory-30B-A3B, a compact long-term-memory writer trained across Mem0, MemOS, and Hy-Memory. Memory On-Policy Distillation teaches framework-specific write protocols on student-generated states; Memory RL then optimizes downstream answerability using dense per-chunk probes, attributed cross-chunk rewards, over-storage controls, and chunk-level GRPO. Carrying policy-written banks across windows keeps training aligned with deployment. On fixed 20% benchmark subsamples, Hy-Memory-30B-A3B ranks first on all four evaluated harnesses, including held-out EverMemOS, with a 55.49% macro average versus 54.62% for Claude Opus 5.
