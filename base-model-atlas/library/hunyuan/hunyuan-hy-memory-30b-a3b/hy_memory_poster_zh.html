问题与定位：看清family与证据

writer改变持久bank，retriever和reader无法找回未存证据；全存又导致干扰。模型是Hy3派生专项，不是新通用正代。

三层同名，贡献别混

writer模型、Hy-Memory框架、MemHub应用分开；框架榜不是模型writer榜。

OPD跟随学生状态

学生自己写bank，冻结Hy3旗舰给top50反向KL；不是教师理想bank的静态模仿。

真实harness执行

Mem0、MemOS、Hy-Memory三场景，共3family/5配置；chunk约10轮且不跨session。

同父bank独立分叉

每窗口最多5chunks，8候选各持独立bank；先写完再检索→answer→judge。
