不要把 1017 当新架构

公开配置仍为 deepseek_v41；新卡未披露独立架构变动。配置一致不是权重与训练不变的证明。

报告与图的范围

1017 原卡指向 9 月共享 Tech Report。下方官方图来自首发，不能当成 1017 新测评或新训练机制。

CED：降低长输入代价

552B backbone；20 层 encoder + 20 层 decoder，prefill / decode 激活约 8B / 16B。

CSA2 + FP4 KV

共享稀疏索引与 KV；global KV 890 bytes/token，约 V4-Flash 的四分之一。

Bounded replay

重放最近 SWA window，减少长轨迹状态常驻压力；属于首发报告结论。

官方首发图：共享 family 的 KV 经济性，不是 1017 新消融
研究判断

部署、验收与未知项

官方称执行更快、输出更短，API 价格不变；没有成本与时延降幅，不能补造百分比。网页 / App / API 均升级，别名仍为 deepseek-flash。

固定 checkpoint，而非别名

记录权重 revision、harness commit、工具、parser、effort；以相同终态 verifier 比较成功。

把失败成本算进去

记录全部 token、工具费用、总运行时间，报告每个严格成功任务的成本与 P50/P95。

建议验收量 · 非官方训练目标
$$\begin{gathered}C_{\rm success}=\frac{\sum_i C_i}{\sum_i\mathbf{1}[S_i]}\\T_{\rm success}=\frac{\sum_i T_i}{\sum_i\mathbf{1}[S_i]}\end{gathered}$$

失败样本进分子；成功数为零不计算比值。

资料不足：1017 未达完整报告级深度

因为原始资料较少，1017 无独立训练报告、数据 / 奖励配方、消融、成本降幅或安全评测，无法达到 GLM-5.3-Flash / Kimi-K3 完整训练报告级精读深度。共享报告不能填补这些新增机制空白。
