Token Plan 是阿里云百炼的 AI 模型订阅服务，以 Credits 统一计量，支持在兼容的 AI 工具中交互式使用。 
快速接入 1. 购买套餐 个人版 
选择套餐档位， 订阅个人版 ，支持包月、包季、包年订阅。 团队版 
选择座席档位和数量， 订阅团队版 ，支持包月、包季、包年订阅。 2. 获取 API Key 个人版 
生成 套餐专属 API Key ，请复制并保存，之后 无法再次查看 。 团队版 
分配座席并生成 套餐专属 API Key ，请复制并保存，之后 无法再次查看 。 3. 快速接入 AI 工具 
复制下面的内容，发送给可用的 AI 工具，让它安装阿里云百炼 CLI 并完成配置。 请阅读 https://bailian.aliyun.com/cli/install.md 并按照说明为我安装阿里云百炼 CLI，然后运行 bl auth login --config token-plan --api-key 登录我的 Token Plan API Key，再运行 bl config show --config token-plan 获取配置，帮我把 Token Plan 接入当前 AI 工具。 没有可用的 AI 工具？请 手动接入 。 
接入 AI 工具 
选择你使用的工具，按接入指南中的 Token Plan 个人版或团队版配置操作。 Qoder 面向真实软件开发的 Agentic 编码平台 Claude Code AI 终端编码助手，支持自然语言编程 Codex OpenAI 推出的命令行编程工具 Qwen Code 开源命令行 AI 编码工具 OpenClaw 开源、自托管个人 AI 助手 Hermes Agent 开源 AI 代理框架，内置自学习循环 OpenCode 开源 AI 编程代理工具 千问办公 绑定 Token Plan，在千问办公中使用 Credits Trae 自定义模型接入，无需安装插件 DeepSeek Harness 开源插件化 Agent 框架，Web UI 与命令行双模式 WorkBuddy 桌面 AI Agent 工作台 通用接入指南 其他编程工具 
接入其他模型 
AI 工具原生只处理文本协议，图像、视频、语音等能力需要通过扩展机制接入，详见 接入概览 。 接入决策模型 按置信度自动放行、隐藏或转人工。 接入图像生成模型 根据文字描述生成图片。 接入视频生成模型 提交异步任务并下载视频。 接入语音合成模型 将文本转为音频。 接入语音识别模型 将音频转为转写文本。 接入实时语音对话模型 创建并运行实时语音客户端。 
接入 Harness

请按照以下步骤配置 Harness 服务给本地 AI 工具使用。

### 前置依赖安装与检查
1. 检查是否安装百炼 CLI，如没有安装请参照如下文档进行安装：https://bailian.aliyun.com/cli/install.md
2. 使用百炼 CLI 完成登录：bl auth login --console
3. 执行如下命令：bl config show，拿到 config_file 文件路径，并读取文件内部api_key。
