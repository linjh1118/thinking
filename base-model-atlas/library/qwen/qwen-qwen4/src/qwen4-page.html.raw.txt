<div lang="zh" class="icms-help-docs-content"><p data-tag="shortdesc" class="shortdesc">了解 Qwen4-Max-Preview 的多模态理解、深度思考、工具调用能力与 Token Plan 接入方式</p><p>Qwen4-Max-Preview 是通义千问新一代旗舰多模态模型，融合文本生成、图片与视频理解及深度思考能力，适用于编程开发、办公、前端设计与复杂智能体任务。模型支持联网搜索、工具调用和结构化输出，兼容 OpenAI 与 Anthropic API，帮助开发者构建具备多模态理解与任务执行能力的智能应用。</p>
<p>Model ID：<code>qwen4-max-preview</code></p>
<div class="note note-note"><div class="note-icon-wrapper"></div><div class="note-content"><p><strong>说明</strong>Qwen4-Max-Preview 当前为预览版，仅支持 Token Plan，不支持按量计费。预览期为 2026 年 11 月 11 日 10:00 至 11 月 25 日 24:00（UTC+8），期间不做变更，预览结束后下线。</p></div></div>

<h2 id="使用注意事项">使用注意事项</h2>
<div class="note note-note"><div class="note-icon-wrapper"></div><div class="note-content"><p><strong>说明</strong><strong>输出预算变化（OpenAI Chat Completions）</strong>：自 <code>qwen4-max-preview</code> 起，<code>max_tokens</code> 与 <code>max_completion_tokens</code> 等价，均限制思考内容与最终回答的 Token 总量。开启思考时，思考内容会占用同一预算；迁移时沿用仅为回答预留的上限，可能导致输出提前截断，请为思考与回答共同预留额度。此前已上线的 Qwen 模型行为不变。详见 <a href="/zh/model-studio/api-compatibility-upgrade-notice">API 兼容性升级说明</a>。</p></div></div>
<ul>
<li><strong>思考模式</strong>：默认开启，可选择 <code>low</code>、<code>medium</code> 或 <code>xhigh</code>（默认）。<code>reasoning_effort</code> 和 <code>thinking_budget</code> 不能同时设置。详见 <a href="/zh/model-studio/deep-thinking">深度思考</a>。</li>
<li><strong>多轮对话</strong>：Chat Completions 的 <code>preserve_thinking</code> 默认开启，需在历史 assistant 消息的 <code>reasoning_content</code> 字段中完整回传思考内容，不支持拼接到 <code>content</code> 字段。</li>
<li><strong>多模态与工具调用</strong>：图片和视频输入见 <a href="/zh/model-studio/vision">图像与视频理解</a>；工具定义与调用流程见 <a href="/zh/model-studio/qwen-function-calling">函数调用</a>；输出格式见 <a href="/zh/model-studio/qwen-structured-output">结构化输出</a>。</li>
