Qwen4-Max-Preview 是通义千问新一代旗舰多模态模型，融合文本生成、图片与视频理解及深度思考能力，适用于编程开发、办公、前端设计与复杂智能体任务。模型支持联网搜索、工具调用和结构化输出，兼容 OpenAI 与 Anthropic API，帮助开发者构建具备多模态理解与任务执行能力的智能应用。
Model ID：
qwen4-max-preview
说明
Qwen4-Max-Preview 当前为预览版，仅支持 Token Plan，不支持按量计费。预览期为 2026 年 11 月 11 日 10:00 至 11 月 25 日 24:00（UTC+8），期间不做变更，预览结束后下线。

：自
qwen4-max-preview
起，
max_tokens
与
max_completion_tokens
等价，均限制思考内容与最终回答的 Token 总量。开启思考时，思考内容会占用同一预算；迁移时沿用仅为回答预留的上限，可能导致输出提前截断，请为思考与回答共同预留额度。此前已上线的 Qwen 模型行为不变。详见
API 兼容性升级说明
