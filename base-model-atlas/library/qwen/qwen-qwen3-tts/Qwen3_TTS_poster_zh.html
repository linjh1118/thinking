问题与动机

核心挑战

现代 TTS 系统必须在四个维度同时做到最优：

稳定性、可控性、自然度、低延迟

Qwen3-TTS 目标

构建同时满足上述要求的统一多语言 TTS 模型，基于 Qwen3 LM 骨干

关键能力

3 秒语音克隆：参考音频快速克隆

Voice Design：自然语言描述创建声音

10+ 语言：跨语言一致性生成

10+ 分钟：长语音流畅合成

✦ 双码率架构

25Hz: 单码本 + chunk-wise DiT

12Hz: RVQ 多码本 + MTP 模块

核心方法

预训练三阶段

S1 通用阶段：5M+ 小时多语言语音

S2 高质量阶段：精选数据缓解幻觉

S3 长上下文阶段：8K→32K token

后训练

DPO：人类反馈偏好对齐

GSPO：规则奖励信号

Speaker Fine-tuning：声音克隆定制

✦ 技术创新

MTP (Multi-Codebook Prediction)：多码本预测实现流式输出

双轨表示：文本+声学 token 沿通道轴拼接

Code2Wav：流式波形解码
