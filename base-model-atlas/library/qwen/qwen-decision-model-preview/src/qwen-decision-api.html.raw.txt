<meta property="og:title" content="决策模型 API"><div lang="zh" class="icms-help-docs-content"><p data-tag="shortdesc" class="shortdesc">调用 POST /compatible-mode/v1/systemone 接口使用百炼决策模型（decision-model / decision-model-preview），一次前向返回分类、评分、是非判断及其概率分布与置信度，不生成文本。适用于工单分流、内容审核、智能体路由与结果校验等高频结构化决策场景。</p>
<h2 id="前提条件">前提条件 <span id="dm-010"></span></h2>
<p>已创建 API Key 并配置为环境变量 <code>DASHSCOPE_API_KEY</code>。配置方法请参见<a href="/zh/model-studio/configure-api-key-through-environment-variables">配置 API Key 到环境变量</a>。</p>
<div class="note note-important"><div class="note-icon-wrapper"></div><div class="note-content"><p><strong>重要</strong><strong>预览版在线体验</strong>：在编写代码前，可先通过 <a href="https://bailian.console.aliyun.com/systemone_playground">Playground</a> 在线体验决策模型。选择预设场景（客服对话判断、Agent 完成度核验、工单分流、内容审核、Agent 任务路由、医疗导诊辅助），输入业务内容并运行模型，查看判断结果、概率分布与 Token 用量，再修改条件观察结果变化。</p></div></div>
<h2 id="请求说明">请求说明 <span id="dm-020"></span></h2>
<p><strong>协议</strong>：TypeSafe System One（<code>POST /compatible-mode/v1/systemone</code>）</p>
<p>一次请求携带业务 <code>state</code> 与若干 typed 问题（<code>choice</code> / <code>noul</code> / <code>score</code>），模型一次前向返回每个问题的判定结果与概率分布，其中 <code>choice</code> 与 <code>score</code> 额外返回置信度，<strong>不生成文本</strong>，因此延迟与成本与输出长度无关。</p>
<strong>请求地址</strong>
<p>调用时请将 <code>{WorkspaceId}</code> 替换为业务空间 ID，详见<a href="/zh/model-studio/regions#h2_migrate_domain">地域与域名</a>。</p>

<table bordertype="no-border"><colgroup><col style="width:50%"><col style="width:50%"></colgroup><tbody><tr><td><h2 id="请求参数">请求参数 <span id="dm-100"></span></h2><p><strong>Content-Type</strong> · <code>String</code> · Header · 必选</p><p>请求类型：<code>application/json</code>。</p><p><strong>Authorization</strong> · <code>String</code> · Header · 必选</p><p>API-Key，格式：<code>Bearer $DASHSCOPE_API_KEY</code>。</p><p><strong>model</strong> · <code>String</code> · Body · 必选</p><p>模型名，取值：</p><ul>
<li><code>decision-model</code>：正式版。<a href="/zh/model-studio/decision-model-stable">模型详情</a>。</li>
<li><code>decision-model-preview</code>：预览版。</li>
</ul><p><strong>state</strong> · <code>String / Object / Array</code> · Body · 必选</p><p>待决策的业务状态：工单文本、对话或结构化对象（对象会被序列化后送模型）。</p><p><strong>questions</strong> · <code>Object</code> · Body · 必选</p><p>问题表。key 为调用方自定义的问题 id；value 为问题对象，字段如下。</p><section class="collapse" id="accordion-问题对象属性"><p>问题对象属性</p><div><p><strong>type</strong> · <code>String</code> · 必选</p><p>问题类型，取值：</p><ul>
<li><code>choice</code>：多选一</li>
<li><code>noul</code>：是否判断</li>
<li><code>score</code>：有序量表</li>

<li><code>noul</code>：可选 <code>{"true":…, "false":…}</code> 描述。</li>
<li><code>score</code>：从低到高的等级描述数组（2–255 级，建议 3–7 级且每级可清晰区分）。</li>
</ul></div></section><strong>接口限制与建议</strong><ul>
<li>问题数上限 16（延迟随问题数近线性增长）。</li>
<li><code>choice</code> 选项 ≤ 255。</li>
<li><code>score</code> 等级 2–255（建议 3–7 级）。</li>
<li>上下文上限 65536 token，超长 <code>state</code> 会被拒绝。</li>
</ul></td><td><h2 id="请求示例">请求示例 <span id="dm-400"></span></h2><p>DashScope SDK 已支持决策模型（兼容 TypeSafe System One 协议）：</p><ul>
