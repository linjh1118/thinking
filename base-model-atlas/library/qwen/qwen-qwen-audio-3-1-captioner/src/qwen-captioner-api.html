提交录音文件，异步获取按时间标注的语音、音效和背景声，以及整段录音的场景描述。 
说明 示例使用华北 2（北京）地域。将 WORKSPACE_ID 设为 业务空间 ID ，将 DASHSCOPE_API_KEY 设为该地域的 API Key 。 
提交任务 
提交一个音频或视频文件，创建异步标注任务。 POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/asr/transcription 
请求头 Authorization string 必填 
Bearer $DASHSCOPE_API_KEY 。 Content-Type string 必填 
application/json X-DashScope-Async string 必填 
固定为 enable ，以异步方式处理文件。 
请求体 model string 必填 
音频标注模型 ID，例如 qwen-audio-3.1-captioner 。 input object 必填 file_url string 必填 
单个音频或视频文件的 HTTP(S) 下载地址。 parameters object 可选 channel_id array[integer] 可选 
要处理的声道编号，从 0 开始。单声道文件可传 [0] ；处理多声道时传入多个编号。 
返回参数 output object task_id string 
服务端生成的任务 ID。保存此值，用于查询任务。 task_status string 
任务状态。 request_id string 
本次请求的 ID，用于排查错误。 curl --request POST "https://${WORKSPACE_ID}.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/asr/transcription" \
  --header "Authorization: Bearer $DASHSCOPE_API_KEY" \
  --header "Content-Type: application/json" \

查询任务 
根据任务 ID 查询处理状态。任务成功后，响应中包含标注结果的下载地址。 GET https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/tasks/{task_id} 
路径参数 task_id string 必填 
提交时返回的任务 ID。 
返回参数 request_id string 
本次请求的 ID，用于排查错误。 output object task_id string 
服务端生成的任务 ID。保存此值，用于查询任务。 task_status string 
任务状态： 
PENDING ：排队中，稍后再查询。 
RUNNING ：处理中，稍后再查询。 
SUCCEEDED ：任务成功，检查文件状态并下载结果。 
FAILED ：任务失败。 
CANCELED ：任务已取消。 submit_time string 
提交任务的时间。 scheduled_time string 
任务开始调度的时间。 end_time string 
任务结束的时间。 file_url string 
提交的文件地址。 subtask_status string 
文件处理状态。 SUCCEEDED 表示该文件已生成标注结果。 transcription_url string 
成功后返回的结果文件下载地址，有效期为 24 小时。使用完整 URL 下载，包括查询字符串。 curl "https://${WORKSPACE_ID}.cn-beijing.maas.aliyuncs.com/api/v1/tasks/${TASK_ID}" \

下载并解析结果 
任务成功后，可下载各声道的标注结果文件。文件包含原始音频属性、分段标注和 Token 用量。 
结果文件 file_url string 
输入文件的地址。 properties object 
输入音频的属性。 audio_format string 
音频编码格式，例如 pcm_s16le 。 channels array[integer] 
声道编号列表。 original_sampling_rate integer 
原始音频采样率，单位为 Hz。 original_duration_in_milliseconds integer 
原始音频时长，单位为毫秒。 transcripts array[object] 
每个元素对应一个声道。 channel_id integer 
声道编号。 content_duration_in_milliseconds integer 
该声道的标注时长，单位为毫秒。 text string 
包含该声道标注结果的 JSON 字符串。 sentences array[object] 
该声道的分段标注。 begin_time integer 
片段起始位置，单位为毫秒。 end_time integer 
片段结束位置，单位为毫秒。 text string 
该片段的标注文本。 speaker_id integer 
说话人编号（如返回）。 usage object 
本次任务的 Token 用量。 input_tokens integer 
输入 Token 数。 output_tokens integer 
输出 Token 数。 total_tokens integer 
输入和输出 Token 总数。
