# Qwen3.8 - 千问平台文档

官方文本模型总览把 `qwen3.8-max`、`qwen3.8-flash` 和 `qwen3.8-2.4t-a95b` 列入 Qwen3.8 家族。三者均提供 1M context、128K 级最大输出、thinking、函数调用、内置工具和结构化输出；Max / Flash 还支持批量接口。

发布记录另列出 Qwen3.8-27B，定位为原生视觉语言 Dense 模型，重点提升文本与视觉条件下的编程和办公能力。
