问题与动机

现有具身智能的碎片化问题
现有研究使用专用模型处理单一任务（操作或导航），导致能力碎片化和跨任务、跨环境、跨机器人形态的泛化受限。
Qwen-VLA 的研究问题
能否将异构的具身决策问题统一在单一视觉-语言-动作模型中？
2

架构设计

核心架构
基于 Qwen3-VL 扩展 DiT-based action decoder，将 VLM 从感知、理解、推理扩展到连续动作和轨迹生成。
Embodiment-Aware Prompt
前置机器人特定的文本提示，描述当前平台、机械臂配置和控制约定：

"The robot is {robot_tag} with {single/dual arms}. The control frequency is {FPS} Hz."
统一动作-轨迹框架
将操作、导航和轨迹预测统一为单一动作-轨迹预测任务，实现跨机器人形态的可迁移视觉定位、空间推理和连续动作生成。
3

三阶段训练

①
T2A 预训练：仅语言+动作，无视觉，建立语言-动作先验
②
CPT：视觉条件化预训练，引入视觉 grounding
③
SFT：监督微调，多任务联合优化
4

关键设计

Flow-Matching Action Loss
使用条件流匹配目标学习动作分布。T2A 阶段采用 Sigmoid-Normal 时间步采样分布，充分利用无视觉条件下的中间时间步信号。
T2A 消融关键发现
• 全序列预测优于分块预测
• T2A 中不应包含图像 Token
• 20% 合成 + 80% 真实数据最佳
• 2,000 步后趋于饱和
训练数据来源
• 机器人操作轨迹
• 人类第一人称演示
• 合成模拟数据
• VLN 数据
• 辅助 VL 数据
