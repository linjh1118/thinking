核心问题与文字渲染能力

现有文生图模型在文字渲染方面存在显著缺陷：拼写错误、字符遗漏、字体扭曲。Qwen-Image 首次在开源模型中实现中英文段落级文字渲染，并在图像编辑中保持语义一致性。

核心挑战：文字渲染的三个层次

(1) 单词级：简单标签、单词牌匾
(2) 多行段落级：PDF、幻灯片、海报中的大段文字
(3) 空间布局敏感：多物体场景中文字与几何位置对齐

方法与训练架构

Qwen-Image 基于双条件 MMDiT 架构，融合 Qwen-VL 语义特征与 VAE 重建特征，采用课程学习策略实现多层次文字渲染能力。

图 2：双条件 MMDiT 架构（Qwen-VL 语义 + VAE 重建特征）
阶段一：数据工程

大规模收集、标注、过滤、合成增强、类别平衡。构建覆盖中英文、多场景的文字渲染数据集。

阶段二：课程学习

从基础文字渲染 → 段落级 → 布局敏感描述。三阶段由简入难，逐步解锁复杂文字渲染能力。

阶段三：RL 微调

基于 GenEval 反馈的强化学习微调，Qwen-Image-RL 在 Position (+0.11) 和 Attribute (+0.06) 上显著提升。

Producer-Consumer 分布式训练

使用 TensorPipe + Megatron 框架实现高效的分布式预训练，支撑大规模数据吞吐量。

RL 微调的关键突破

Qwen-Image-RL 在 GenEval Position 维度从 0.76 提升至 0.87（+0.11），Attribute 从 0.77 提升至 0.83（+0.06），证明 RL 是解锁细粒度可控生成的关键。

核心贡献 1

最强文字渲染：支持中英文多行文字、段落级渲染、局部文字插入，GenEval 0.91 首个破 0.9 开源模型。

核心贡献 2

一致性图像编辑：GEdit 双语 leaderboard 第一（EN: 7.56, CN: 7.52），超越 GPT Image 1。

核心贡献 3

开源第一：AI Arena 开源模型排名第一，总榜第三，仅次于 Imagen 4 和 Seedream 3.0。
