Thinker-Talker 架构

统一处理文本、图像、音频、视频四类模态，通过 解耦的 Thinker-Talker 实现边想边说的流式交互能力。

图 1：Qwen3-Omni 整体架构（Thinker 处理多模态理解，Talker 生成流式语音）
Thinker — 多模态理解器

接收文本/图像/音频/视频输入，输出文本 token 和高层多模态表示。30B MoE（235B 总参，22B 激活），与单模态 Qwen3 文本/VL 模型性能持平。

Talker — 流式语音生成器

接收 Thinker 输出的多模态特征，通过 Multi-Codebook Codec 生成流式语音 token，端到端延迟低至 234ms。

TM-RoPE — 时间对齐位置编码

时间对齐的多模态旋转位置编码，支持任意时长的流式输入，实现文本、视觉、音频时间戳的联合对齐。

异步并行：Chunked Prefilling

Thinker 和 Talker 并行工作，Talker 不再等待 Thinker 的完整输出，实现真正的流式交互。

MTP 模块：Multi-Token Prediction

多 token 预测生成残差码本（rvq.c），增强语音生成质量。

五大核心升级

相比 Qwen2.5-Omni，Qwen3-Omni 在架构、训练、推理三个层面完成全面升级。

升级一：Thinker + Talker 均升级为 MoE

30B MoE 总架构，235B 总参，22B 激活参数量，兼顾性能与效率。

升级二：AuT Audio Transformer 编码器

从头训练的 Audio Transformer 编码器替代 Whisper，12.5Hz 音频码率，20M 小时监督数据训练。

升级三：多码本语音表示（Multi-Codebook）

RVQ codec 支持 12.5Hz 即时语音合成，单帧延迟极低。

升级四：MTP 残差码本建模

Multi-Token Prediction 模块生成残差码本，提升高保真语音合成质量。

升级五：12.5 Hz 音频码率

音频 token 率从更高降至 12.5Hz，显著降低端到端延迟（最低 234ms）。

核心创新

Thinker-Talker 解耦架构实现边想边说的流式交互，234ms 端到端延迟达到实时语音水平。

模态不降智

文本/视觉性能与单模态模型持平，加入音频后文本能力反而提升，22B 激活参数超越更大模型。

开源 SOTA

32/36 benchmarks 达到开源第一，22/36 达到全部 SOTA，覆盖文本/语音/视觉/视频。

多语言覆盖

支持 119 种文本语言、19 种语音理解、10 种语音生成语言。
