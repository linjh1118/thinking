核心问题与架构设计

Qwen3Guard 是一个面向 Qwen3 的多语言安全护栏系统，解决现有安全分类模型的两大核心问题。

问题一：安全策略不一致

不同 guard 模型采用不同安全策略，在多样化部署场景中难以适应。Qwen3Guard 提出三分类体系：safe / controversial / unsafe，引入"争议"标签处理策略模糊地带。

问题二：流式输出不兼容

现有开源模型只能评估完整响应，无法在生成过程中实时检测安全问题。StreamGuard 通过辅助 token 级分类头实现实时流式安全检测。

双模型架构

GenGuard（生成式）：将安全分类重构为指令跟随任务，适用生成式模型，支持 safe/controversial/unsafe 三分类。

StreamGuard：添加辅助 token 级分类头，支持实时流式安全检测，在生成过程中进行 token 级评估。

三种规模

0.6B / 4B / 8B 三种模型规模，0.6B 参数量即可媲美 10x 参数更大模型的效果。

119 种语言

覆盖 119 种语言的安全分类能力，支持全球主要语言的高质量安全审核。

SafeRL 与 CARE 框架

Qwen3Guard 集成到 SafeRL 训练流程和 CARE 流式推理框架，显著提升模型安全性同时保持或提升能力。

SafeRL 训练

将 Qwen3Guard 作为安全反馈信号，训练时整合安全约束，同时保持模型 helpfulness。Guard-only 模式仅使用安全信号；Hybrid 模式结合安全与能力信号。

SafeRL (Hybrid) 在提升安全性的同时保持或提升模型能力，实现了安全与能力的双赢。
