问题与动机

核心挑战

传统 ASR 系统难以处理：长语音、强噪声、多语言/方言、时间戳预测精度等问题

LALM 范式优势

利用 LLM 的语言建模能力和世界知识，更自然地解决传统 ASR 的瓶颈问题

模型系列

Qwen3-ASR-0.6B: Qwen3-0.6B + 180M AuT

Qwen3-ForcedAligner-0.6B: 强制对齐模型

✦ 核心创新

首次将 LLM 引入 Forced Alignment 任务

Slot-filling 范式 + NAR 解码

核心方法

Figure: Qwen3-ASR 架构 — AuT 音频编码器 + Qwen3 LLM
训练流程

AuT 预训练 (~40M 小时伪标签) → Omni 预训练 (3T tokens) → ASR SFT → ASR RL (GSPO)

ForcedAligner 创新

Slot-filling 范式：在 transcript 中插入 [time] token

因果训练：确保时间戳槽位对齐

NAR 解码：非自回归同时预测所有时间戳

流式/离线统一推理

Contextual Biasing 自由形式偏置
