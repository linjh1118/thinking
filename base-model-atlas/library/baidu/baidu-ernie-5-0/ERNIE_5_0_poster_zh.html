问题与动机

Existing Problems
能力跷跷板：晚期融合方法在提升某模态时牺牲其他模态性能
架构碎片化：理解用一套架构，生成用另一套，无法深层跨模态融合
ERNIE 5.0 Goal
从零开始训练统一的原生多模态模型，所有模态在同一 Next-Group-of-Tokens Prediction 目标下共同优化
2

核心架构

Modality-Agnostic MoE
所有模态共享同一个 expert pool，路由决策基于统一 token 表示而非模态 ID。Ultra-sparse 设计：激活率 <3%
Unified Training Objective
文本：Next-Token + Multi-Token Prediction
图像：Next-Frame-and-Scale (NFSP)
视频：Next-Frame (时间维度扩展)
音频：Next-Codec (层级预测)
视觉理解双路径
CNN（局部感知）+ ViT（全局语义）→ Attention-Based Patch Merger 融合，替代简单 MLP
3

Elastic Training

一次预训练，产出多个尺寸子模型，无需后压缩
Elastic Depth
75% 全深度 + 25% 浅层子网 → 激活不同层数
Elastic Width
80% 全部 expert + 20% 子集 → 激活不同 expert 数量
Elastic Sparsity
80% 默认 top-k + 20% 更小 k → 激活不同路由稀疏度
Key Result
ERNIE 5.0-Exp-EA35.8%：
仅用 53.7% 激活参数 + 35.8% 总参数
仍保持接近全模型性能（75.17 vs 75.55 avg）
Efficiency Gain
推理 top-k 降至 25% → >15% 解码加速
弹性深度训练还有正则化效应，验证 loss 略有下降
4

Post-Training: U-RL

U-RB: Unbiased Replay Buffer
解决长尾响应导致 GPU 空闲问题，保持无偏数据分布
MISC + WPSM
避免熵崩溃：token级IS裁剪 + 已掌握样本屏蔽
AHRL: Hint-based RL
极难任务渐进揭示 think skeleton，scaffold 引导探索

核心洞察
Modality-Agnostic Routing 自组织：虽无显式模态区分，专家仍展现模态特定激活模式。理解与生成互强化，非相互制约
Key Innovation 1
Modality-Agnostic Ultra-Sparse MoE
所有模态共享 expert pool，激活率 <3%，无需启发式模态分配
Key Innovation 2
Elastic Training
一次训练产出多尺寸子模型，灵活部署，无需后压缩
Key Innovation 3
Unified NGTP Objective
text/image/video/audio 统一 Next-Group-of-Tokens Prediction
Key Innovation 4
U-RL: Unbiased Multimodal RL
U-RB + MISC + WPSM + AHRL 解决超稀疏 MoE + 多模态 RL 训练挑战
