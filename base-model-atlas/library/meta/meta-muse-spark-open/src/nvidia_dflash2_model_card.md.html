Model Overview

Description:

The NVIDIA Muse-Spark-Open-816B-A42B-DFlash2 model is the DFlash 2 draft checkpoint for Muse-Spark-Open-816B-A42B, a multimodal mixture-of-experts causal language model that produces text and supports long-context, tool-enabled workflows. The NVIDIA Muse-Spark-Open-816B-A42B-DFlash2 model incorporates DFlash 2 speculative decoding with Model Optimizer. DFlash 2 adds a two-tap in-block convolution around every sublayer and a pairwise path selector that walks one coherent path through each position’s top-k candidates.

This model is ready for commercial or non-commercial use.

Training and Evaluation Datasets:

Training Dataset:

Link: Nemotron-Post-Training-Dataset-v2, only prompts from the datasets were used for data synthesis (the original responses from GPT were not used), which is then used to train the DFlash modules. Data Modality: Text Text Training Data Size: 1 Billion to 10 Trillion Tokens Data Collection Method by dataset: Hybrid: Automated, Synthetic Labeling Method by dataset: Hybrid: Automated, Synthetic Properties: About 3.48 million multilingual text samples featuring prompts spanning math, code, STEM, and conversational topics. Each sample includes a synthetic response generated by the target model; the corpus mixes responses generated at five reasoning-effort levels, each including its reasoning trace.

Testing Dataset:

Link: SPEED-Bench, MT-Bench Data Collection Method by dataset: Hybrid: Automated, Manually-Collected, Synthetic Labeling Method by dataset: Hybrid: Automated, Manually-Labeled, Synthetic Properties: The SPEED-Bench qualitative split (880 text prompts in 11 task categories, mostly English), the 32k-token bucket of the SPEED-Bench throughput split (first 100 prompts of each of its three categories), and MT-Bench (80 English two-turn text questions in 8 categories) were used during development to measure acceptance length and select checkpoints.

Evaluation Dataset:

The model is evaluated on the SPEED-Bench and MT-Bench datasets for speculative decoding benchmarking.

Data Collection Method by dataset: Hybrid: Automated, Manually-Collected, Synthetic Labeling Method by dataset: Hybrid: Automated, Manually-Labeled, Synthetic Properties: All prompts are text and mostly in English. The SPEED-Bench qualitative split has 880 prompts in 11 task categories (such as coding, math, reasoning, and writing, plus a multilingual category covering 23 languages); MT-Bench has 80 two-turn questions in 8 categories. Acceptance length over the target model's responses measures the quality of the draft model.

Inference:

Acceleration Engine: vLLM

Test Hardware: NVIDIA Blackwell GB300

DFlash 2 Speculative Decoding

This model is ready for inference in DFlash 2 speculative decoding mode. DFlash 2 drafts a block of candidate tokens in a single non-causal forward pass, then uses a pairwise path selector over each position’s top-k candidates. The target model verifies the proposed path so that more than one token can be accepted per generation step. The mean number of tokens emitted per step is the acceptance length.

Model Limitations:

The base model was trained on data that contains toxic language and societal biases originally crawled from the internet. Therefore, the model may amplify those biases and return toxic responses especially when prompted with toxic prompts. The model may generate answers that may be inaccurate, omit key information, or include irrelevant or redundant text producing socially unacceptable or undesirable text, even if the prompt itself does not include anything explicitly offensive.
