🤫😀 NVIDIA NemotronLabs RE-USE-laughter: Multilingual Universal Speech Enhancement

Model Overview

Description:

NVIDIA NemotronLabs RE-USE-laughter is a 9.6-million-parameter multilingual universal speech enhancement (USE) model designed to restore speech quality across a wide range of real-world degradations while preserving speech fidelity. It has the following desirable properties:

  • This model better preserves laughter while restoring the quality of the input speech.
  • Robustness to diverse degradations, including additive noise, reverberation, clipping, bandwidth limitation, codec artifacts, packet loss and low-quality mics.
  • Support for multiple input sampling rates, including 8, 16, 22.05, 24, 32, 44.1, and 48 kHz.
  • Strong language-agnostic capability, enabling effective performance across different languages.

(Note: For overlapping speech, this model is trained to preserve the main speaker while suppressing other speakers.)

NVIDIA NemotronLabs RE-USE-laughter was developed by NVIDIA as a part of RE-USE.

This model is ready for commercial use.

Usage

Directly try our **Gradio Interactive Demo** by uploading your noisy audio/video !!

Environment Setup

  1. (For Mamba setup)Pre-built Docker environments can be downloaded here to simplify Mamba setup.
  1. If you need bandwidth extension:
bash
pip install resampy
  1. Download and navigate to the HuggingFace repository:
code
huggingface-cli download nvidia/NVIDIA-NemotronLabs-RE-USE-laughter  --local-dir ./NemotronLabs_REUSE_laughter --local-dir-use-symlinks False
cd ./NemotronLabs_REUSE_laughter

Inference

Follow the simple steps below to generate enhanced speech using our model:

  1. Place your noisy speech files in the folder noisy_audio/
  2. Run the following command:
bash
sh inference.sh
  1. The enhanced speech files will be saved in enhanced_audio/.

That's all !

Note:

a. You can enable bandwidth extension by setting the target bandwidth using the BWE argument in the script.

---

If your noisy speech files are long (e.g., >30s, compared to our training data, which consists of clips < 10s) or cause GPU out-of-memory (OOM) errors, please use the following procedure instead:

  1. Place your long noisy speech files in the folder long_noisy_audio/
  2. Run the following command:
bash
sh inference_chunk.sh
  1. The enhanced speech files will be saved in Long_enhanced_audio/.

Note:

a. You can also configure the chunk_size_in_seconds and hop_length_portion directly in the script.

Use Case:

Researchers and general users can use this model to enhance the quality of speech recordings across a wide range of applications. For example, content creators can use it to improve the speech quality of their recordings, while researchers can use it to enhance speech datasets for training speech generation models, such as text-to-speech (TTS) and speech large language models (Speech LLMs).

Training Dataset:

Audio Training Data Size: ~2500 hours Data Collection Method by dataset: Synthetic Labeling Method by dataset: Synthetic Properties (Quantity, Dataset Descriptions, Sensor(s)): The size of the speech data is roughly 2500 hours. Single channel, single speaker, 8kHz - 48kHz sampled data.
