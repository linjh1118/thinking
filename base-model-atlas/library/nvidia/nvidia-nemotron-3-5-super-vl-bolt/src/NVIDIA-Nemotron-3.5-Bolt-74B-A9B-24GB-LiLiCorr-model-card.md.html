NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB-LiLiCorr

Description

NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB-LiLiCorr is the LiLiCorr speculative-decoding checkpoint for the NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB. The compatible target is a hybrid LatentMoE vision-language model for reasoning, chat, and agent workflows. For more information, see the NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB target card.

This checkpoint supports LiLiCorr-assisted serving of the compatible NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB target.

This checkpoint is not a standalone language model. It proposes draft token candidates that the compatible 24GB target verifies; the target produces the user-visible text.

This model is ready for commercial or non-commercial use.

Model Architecture

Architecture Type: Dense GQA (Dense MLP + GQA Attention)

Network Architecture: Five dense feed-forward layers use grouped-query attention (GQA). Draft attention is bidirectional within the draft block. All five layers use a 1024-token per-head sliding window and attention sinks, with a grouped dynamic convolution around each attention and MLP sublayer. A separate two-layer LiLiCorr head correlates the drafter's top-8 candidates at each draft slot.

Number of Model Parameters: 1.113B draft parameters, excluding shared target embeddings and the LM head. The two-layer LiLiCorr head accounts for 37M of them.

Target Model Architecture: Hybrid LatentMoE vision-language model with 74B total parameters and 9B active parameters.

Input

The inputs below describe the target-model serving interface. LiLiCorr drafts tokens using representations from the target model.

Input Type(s): Text Input Format(s): Text: String Input Parameters: Text: One-Dimensional (1D) Other Properties Related to Input: The target model supports up to 256K tokens of context. Supported languages include English, French, Spanish, Italian, German, Japanese, Hindi, Korean, Brazilian Portuguese, and Chinese.

Output

  • Output Type(s): Text
  • Output Format: String
  • Output Parameters: One-Dimensional (1D): Sequences
  • Other Properties Related to Output: Maximum context length up to 256K tokens. Supports JSON output format, reasoning output with chain-of-thought, and tool calling.

Other Properties Related to Output: Outputs can include responses, reasoning traces, tool-use content, and structured data. The chat template and application configuration determine the output form.

Training and Evaluation Datasets

Training Dataset

For target training details, see the NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB target card.

Link: Nemotron-Post-Training-Dataset-v2, Nemotron-RL-Super-Training-Blends, Nemotron-Post-Training-v3, Nemotron-Instruction-Following-Chat-v1, and Nemotron-Science-v1. Only dataset prompts and conversation context were used for data synthesis. The original responses were not training targets. Every training response was generated by Nemotron-3.5-Bolt at temperature 1.0. The draft was first trained on responses from a Nemotron-3.5-Bolt post-training checkpoint, then fine-tuned on responses from the released checkpoint.

Data Modality: Text

Training Data Size: 1 Billion to 10 Trillion Tokens

Data Collection Method by dataset: Hybrid: Automated, manually-collected, synthetic.

Labeling Method by dataset: Hybrid: Automated, manually-labelled, synthetic.

Properties: This model was trained exclusively on a post-training corpus includes synthetic data for reasoning, code, science, tool use, instruction following, structured outputs, and multilingual tasks.

Evaluation Dataset

The model is evaluated on SPEED-Bench for speculative decoding.

Data Collection Method by dataset: Hybrid: Automated, manually-collected, synthetic.

Labeling Method by dataset: Hybrid: Automated, manually-labelled, synthetic.

Properties: This corpus comprises a mix of high-quality standard benchmarks and test suites for LLMs. These benchmarks prompt the underlying model on a diverse set of tasks such as coding, math, writing, translation, etc., and the acceptance rates achieved from speculative decoding over the responses are measured in order to evaluate the quality of the speculation model.

Inference

Acceleration Engine: vLLM

Test Hardware: NVIDIA DGX Spark (GB10)

LiLiCorr Speculative Decoding

This release provides the LiLiCorr draft for the compatible Nemotron-3.5-Bolt-74B-A9B-24GB target. LiLiCorr proposes token blocks that the target verifies during generation.

This model supports a speculative decoding path with LiLiCorr for DGX Spark and low-concurrency data center workflows. This release is the LiLiCorr speculative decoding checkpoint intended to be paired with the NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB target model. LiLiCorr is designed to improve accepted length while preserving the latency benefits of block drafting on compact Blackwell systems such as DGX Spark.

Model Limitations

This checkpoint is not a standalone language model and cannot produce user-visible output without the compatible 24GB target. The draft checkpoint provides no independent safety controls; retain the target model's safeguards and application guardrails.

The target model may generate inaccurate, incomplete, or otherwise undesirable responses, even when prompts are benign. It may reflect biases or content artifacts present in its training data, and output quality can vary by domain, language, reasoning depth, and context length. Developers should add application-specific safeguards and evaluate the system in the intended deployment environment before production use.
