Nemotron-Labs-Unified-ASR-0.6b: Unified ASR model for offline and streaming multilingual inference

Nemotron-Labs-Unified-ASR-0.6b is the multilingual version of Parakeet-unified-en-0.6b — a unified automatic speech recognition (ASR) model that combines offline and streaming inference (with a minimum algorithmic latency of 160ms) in a single model [1]. It extends the English-only unified model to 25 European languages, and is trained primarily on the Granary dataset [5], [6] using the same training data composition as parakeet-tdt-0.6b-v3. The model transcribes speech with punctuation and capitalization support, and uses language-ID prompt conditioning on the encoder to select the target language at inference time.

In our evaluation setup, the new unified model outperforms parakeet-tdt-0.6b-v3 in offline mode and nemotron-3.5-asr-streaming-0.6b in most streaming scenarios with algorithmic latency down to 160ms (see Comparison with already released models).

The new unified model also serves as a strong ASR front end for cascaded streaming speech translation (see Streaming Speech Translation).

Key capabilities:

  • One multilingual checkpoint for both tasks: a single unified model covers both offline and streaming inference with a minimum latency of 160ms across 25 European languages.
  • Language-ID prompting: the target language is passed to the encoder as a prompt, which stabilizes language selection in low-latency streaming. An automatic language mode (target_lang=auto) is also supported.
  • Streaming chunk size flexibility: the streaming latency (chunk + right context) is configurable from 2080ms down to 160ms in steps of 80ms, without re-training.
  • Punctuation & Capitalization: built-in support for punctuation and capitalization in the output text.
  • Speech translation front end: the right context lets the current chunk use upcoming audio before the transcript is committed, which gives the LLM of a cascaded speech translation system a more accurate source transcript.

Model Architecture:

Architecture Type: Unified-FastConformer-RNNT with language-ID prompt [1], [2] — an optimized version of the Conformer model [4] with 8x depthwise-separable convolutional downsampling and RNNT loss.

Network Architecture:

  • Encoder: Unified FastConformer with 24 layers
  • Decoder: RNNT (Recurrent Neural Network Transducer)
  • Language conditioning: language-ID prompt fused into the encoder output
  • Parameters: 600M

Model Initialization

The encoder was initialized from the parakeet-tdt-0.6b-v3 model to give the unified model strong multilingual acoustic representations from the beginning of training.

Unified offline/streaming training

The model was trained jointly in offline and streaming modes. In the offline mode we use standard offline training with full-context self-attention and non-causal convolutions. In the streaming mode we apply chunked self-attention masks (left, middle/chunk and right context) together with Dynamic Chunked Convolutions inside each FastConformer layer [3] to adapt the model to both decoding scenarios. We also use a mode-consistency regularization (MCR) loss [1] to further reduce the gap between offline and streaming performance. All model parameters are shared between offline and streaming modes (encoder, predictor, and joint networks), including the initial x8 subsampling with non-causal convolutions.

Language-ID prompting

The model uses language-ID prompt conditioning on the encoder, following the approach used in nemotron-3.5-asr-streaming-0.6b. The language prompt is fused with the acoustic representation as follows:

  • The FastConformer encoder processes audio into an acoustic embedding of shape (D, T).
  • The language encoding expands a one-hot language vector across the time axis → (K, T), broadcasting the language identity to every frame.
  • Concatenation along the feature axis produces a fused tensor (D + K, T).
  • A projection layer maps the fused features to the RNNT decoder.

Why the prompt is needed. The model uses a single shared SentencePiece tokenizer built from the combined transcripts of all 25 languages, so the tokenizer itself carries no language information and the output token space is shared across languages. In low-latency streaming configurations (latency ≈ chunk + right context ≤ 560ms), the first chunks do not contain enough speech for the model to reliably infer the spoken language, so it can begin emitting tokens belonging to a different language. The model typically self-corrects once enough audio has been accumulated, but the initial tokens are already emitted and cannot be revised. Passing the language ID as a prompt removes this ambiguity from the first chunk onward and makes the transcription language deterministic. In offline mode and at higher streaming latencies the effect is much smaller, since the model has sufficient acoustic context to identify the language on its own.

Automatic language mode. When the spoken language is not known in advance, pass target_lang=auto (the language-agnostic prompt) for a language-agnostic inference. For low-latency streaming we recommend passing the language explicitly, for the reason above. All results in this card are obtained with the explicit language prompt.

Setting up Streaming Configuration

Algorithmic latency is defined as the sum of the chunk size (middle part) and the right context. For the left context we use 5.6s by default (5.6s was used during model training), but other values can be explored for a better accuracy/speed trade-off. The model is quite flexible in terms of context sizes: the values above are recommendations, and other combinations of left context, chunk and right context can be chosen depending on the application. We recommend not decreasing the left context below 2s, as accuracy starts to degrade noticeably beyond that point.

Streaming Inference Limitation

The current streaming inference pipeline is buffered, not cache-aware: the left context is recomputed at every chunk step. Standard NVIDIA streaming ASR models use a cache-aware architecture with causal convolutions and no right context, which allows encoder states to be cached and reused across chunks. The unified model instead relies on non-causal convolutions and a right context to reach its offline accuracy, so the left context has to be recomputed at each step in order to keep training and inference conditions matched. Cache-aware decoding is technically possible with this model, but it breaks that match and leads to accuracy degradation. Fine-tuning the model with zero right context would enable cache-aware decoding, at the cost of the state-of-the-art offline performance that is the main advantage of the unified model. As a result, buffered streaming is computationally more expensive than cache-aware streaming at the same latency. To accelerate the streaming inference, one can reduce the left context to about 3-2s with possible accuracy degradation.

How to Use this Model

For now, we provide only inference support for the unified model.

Loading the Model

python
import nemo.collections.asr as nemo_asr
asr_model = nemo_asr.models.ASRModel.from_pretrained(model_name="nvidia/nemotron-labs-unified-asr-0.6b")

Offline Inference

Pass the language of the audio with target_lang (e.g. "de" for German, "bg" for Bulgarian), or target_lang="auto" to let the model identify it:

python
output = asr_model.transcribe([wav_file_path], target_lang="de")
print(output[0].text)

Streaming Inference

For streaming inference you can use the stateful chunked RNN-T decoding script from NeMo - NeMo/examples/asr/asr_chunked_inference/rnnt/speech_to_text_streaming_infer_rnnt.py. The left context, chunk and right context are given in seconds (5.6s / 0.56s / 0.56s for 1.12s latency); att_context_size_as_chunk=true enables the chunked self-attention masks; target_lang is the language ID (e.g. en, bg, or auto):

bash
cd NeMo
python examples/asr/asr_chunked_inference/rnnt/speech_to_text_streaming_infer_rnnt.py \
    model_path=<model_path> \
    dataset_manifest=<dataset_manifest> \
    output_filename=<output_json_file> \
    left_context_secs=5.6 \
    chunk_secs=0.56 \
    right_context_secs=0.56 \
    att_context_size_as_chunk=true \
    target_lang=<language_id> \
    batch_size=<batch_size>

You can also run streaming inference through the pipeline method, which uses NeMo/examples/asr/conf/asr_streaming_inference/buffered_rnnt.yaml configuration file to build end‑to‑end workflows with punctuation and capitalization (PnC), inverse text normalization (ITN), and translation support.

python
from nemo.collections.asr.inference.factory.pipeline_builder import PipelineBuilder
from omegaconf import OmegaConf
# Path to the buffered rnnt config file downloaded from above link
cfg_path = 'buffered_rnnt.yaml'
cfg = OmegaConf.load(cfg_path)
cfg.asr.model_name = "nvidia/nemotron-labs-unified-asr-0.6b"
cfg.lang = "de"  # language ID of the audio
# Pass the paths of all the audio files for inferencing
audios = ['/path/to/your/audio.wav']
# Create the pipeline object and run inference
pipeline = PipelineBuilder.build_pipeline(cfg)
output = pipeline.run(audios)
# Print the output
for entry in output.values():
  print(entry['text'])

Streaming Speech Translation (ASR + LLM Cascade)

The unified model can be used as the ASR front end of a cascaded simultaneous speech translation system. The English-only predecessor Parakeet-unified-en-0.6b of this model was the ASR front end for the English-to-X tracks of NVIDIA's IWSLT 2026 system [8], which ranked first by COMET for English-to-German, English-to-Chinese and English-to-Italian translation in both latency regimes. This multilingual checkpoint extends the same approach to speech in any of its 25 ASR languages, provided that the downstream translation LLM supports the requested language pair.

The following results use Riva-Translate-4B-Instruct-v2 with the longest-common-prefix translation policy (waitk=-1) and 800ms end-of-utterance detection on FLEURS. Running the Cascade

The cascade runs in one process with NeMo/examples/asr/asr_streaming_inference/asr_streaming_infer.py: the unified model transcribes the audio in buffered streaming mode, and every finalized ASR segment is translated by an LLM served with vLLM. vLLM conflicts with the all / cu12 / cu13 extras, so install it into a separate environment of the NeMo Speech checkout:

bash
cd Speech
UV_PROJECT_ENVIRONMENT=.venv-vllm uv sync --locked --python 3.13 --extra asr --extra vllm

The following command translates German speech into English with the setting of the first table row (0.56s chunk and right context, 5.6s left context):

bash
.venv-vllm/bin/python examples/asr/asr_streaming_inference/asr_streaming_infer.py \
    --config-path=../conf/asr_streaming_inference \
    --config-name=buffered_rnnt.yaml \
    audio_file= \
    output_filename=<output_json_file> \
    asr.model_name=nvidia/nemotron-labs-unified-asr-0.6b \
    lang=de \
    streaming.left_padding_size=5.6 \
    streaming.chunk_size=0.56 \
    streaming.right_padding_size=0.56 \
    asr_output_granularity=segment \
    enable_itn=False \
    endpointing.stop_history_eou=800 \
    enable_nmt=True \
    nmt.model_name=nvidia/Riva-Translate-4B-Instruct-v2 \
    nmt.source_language=German \
    nmt.target_language=English \
    nmt.waitk=-1 \
    nmt.device_id=1
  • lang is the language ID of the speech, i.e. the source language of the translation pair; it selects the ASR

language prompt.

  • nmt.source_language and nmt.target_language are language names, not IDs. For Riva-Translate-4B-Instruct-v2,

use Latin American Spanish and Brazilian Portuguese for the FLEURS Spanish and Portuguese data.

  • nmt.waitk=-1 commits the longest common prefix of the current and previous translations; a positive value

instead limits how many words the translation may lag behind the transcript. endpointing.stop_history_eou is the end-of-utterance window in milliseconds.

  • The translation LLM runs on GPU nmt.device_id. To run both models on a single GPU, set nmt.device_id=0 and

lower nmt.llm_params.gpu_memory_utilization (e.g. 0.6).

For English-to-X translation, set lang=en, nmt.source_language=English and the target language name.
