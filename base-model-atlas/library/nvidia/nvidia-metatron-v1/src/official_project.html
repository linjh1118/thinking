Metatron coordinates how to move. 01 / An interface for skill code 
Set the goals. Let the body respond. 
A coding agent can work with positions, orientations, velocities, and arrival times. Metatron turns those goals into coordinated whole-body motion. What & where 
Specify the task. 
Give approximate targets for a hand, foot, torso, or travel velocity and heading. Refine them when the task needs more precision. When 
Give it timing. 
Arrival times can be approximate too. Skill code can sequence goals and update their timing as the task progresses. What stays free 
Leave room to move. 
Constrain only what matters. Metatron generates the remaining motion instead of requiring a complete pose at every instant. Explore the goal interface ↗

Change the goals, not the policy.

Run, slide, climb. Change the goals. 
Velocity and heading goals build speed. For the slide, a low pelvis target and a forward foot target guide the body down with one leg extended ahead. For the climb, a pelvis-position target above the ledge and a heading goal guide the body upward, leaving hand and foot placement to the policy. 02 / Agent-assisted skill development 
Refine the goals. Not the policy. 
Describe a task. A coding agent writes goal-setting code, tests it in simulation, and refines it from the results. Metatron stays frozen. Human Specify the task Coding agent + motion examples Write and refine skill code Simulation + frozen Metatron Evaluate and diagnose 
The LLM develops the skill offline . At runtime, ordinary skill code supplies goals—not an LLM in the robot’s control loop. A human decides whether to deploy it. Hardware example / Agent-assisted steering

Two feet. Half a cycle apart. 
Speed sets the step frequency and swing amplitude. Each foot follows a cosine swing and lifts during half the cycle. The skill evaluates this rule at future arrival times and adds the resulting foot goals to the velocity and heading prompt. 
The stance widens for sideways travel, and the swing axis follows the travel direction with reduced lateral motion. Metatron supplies the whole-body response. 
Moving-gait pseudocode based on the C++ deployment. Standing holds and turning corrections are omitted. View simplified skill code # speed in m/s; frequency in Hz; distances in m frequency = min(2.0, 0.83 + 0.93 * speed)
amplitude = 0.13 + 0.065 * speed
phase += 2 * pi * frequency * dt

for time in future_times:
    for foot, shift in [(right, 0), (left, pi)]:
        angle = phase + 2 * pi * frequency * time + shift
        offset = stance_offset(foot, travel_angle)
        offset.xy += amplitude * cos(angle) * swing_axis
        offset.z += 0.08 * max(0, -sin(angle))
