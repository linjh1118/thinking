1

问题、定位与证据

TL;DR：判断谁在何时说话，再与ASR对齐得到带说话人的文字。输出匿名活动概率，不生成实名身份，也不独立产出转写。

官方原图 · Diarization与ASR分别建模
输入与输出

16kHz单声道→[T,8]概率；默认10ms帧，多通道同时活动表示重叠。chunk推理无固定时长上限，但长对话/噪声/远场仍可能退化。

日期和演示边界

9/23模型卡Release Date与博客Published一致。合成Demo中部分八人场景带前置说话人信息，不作为无提示八人基准；本轮未运行Demo。

2

方法、组件与训练

TL;DR：到达顺序稳定通道，AOSC保存较早说话人，FIFO保存近期帧。缓冲长度与实际交互响应必须分开。

官方原图 · 31层RoPE编码器与流式记忆
统一编码与两阶段训练

10ms Mel特征8倍堆叠至80ms编码帧，Conv1D上采样。NEST初始化，先模拟混合离线训练，再真实/模拟流式微调；约1万小时真实与82611小时模拟分列，不能视为互不重叠语料。

Agent训练判断

轨迹保留词、speaker、时间、重叠及缓存状态。分别评估WER/DER/归属正确的行动项和总延迟，按人数/时长报告失败；不奖励“文字正确但说话人归错”的行为。
