G1-Factory-GR00T-1.7: GR00T N1.7 for the Unitree G1 humanoid

Model Overview

Description:

G1-Factory-GR00T-1.7 is a GR00T N1.7 vision-language-action policy fine-tuned for a Unitree G1 humanoid on the nine G1 Factory simulation tasks. From a head-camera image, the robot's upper-body joint state and a language instruction, it predicts chunks of whole-body actions. It was fine-tuned on the G1-Factory-Benchmark demonstrations and runs in the G1 Factory simulation scenes. It can also be used as a base policy for reinforcement-learning post-training.

This model is ready for commercial or non-commercial use.

Developer: NVIDIA.

Use Case:

Robotics researchers and developers use this policy to perform and evaluate the nine G1 Factory tasks in simulation. It also serves as a reference baseline and as a starting point for further fine-tuning or reinforcement-learning post-training.

Model Architecture:

Architecture Type: Transformer.

Network Architecture: GR00T N1.7 (Gr00tN1d7): an nvidia/Cosmos-Reason2-2B vision-language backbone, a 4-layer vision-language self-attention module, and a 32-layer flow-matching action transformer that generates actions in 4 denoising steps. The language backbone is frozen; the vision encoder, projector and action head are fine-tuned.

Number of Model Parameters: 3,144,016,000.

Input(s):

Input Type(s): Image, Tabular, Text.

Input Format(s): One head-camera RGB image (ego_view) as uint8 [480, 640, 3]; a 31-dimensional float32 upper-body joint state (left arm 7, right arm 7, left hand 7, right hand 7, waist 3); one English task instruction per task (for example, PushButton: "Walk to the console and press the red button").

Input Parameters: Image: two-dimensional (2D); state: one-dimensional (1D); text: one-dimensional (1D).

Other Properties Related to Input: The policy expects the native 640 x 480 head-camera frame. Resizing the image before the model's own processor degrades success. State and action normalization come from the checkpoint's saved statistics and processor configuration.

Output(s):

Output Type(s): Tabular.

Output Format(s): Continuous floating-point vectors.

Output Parameters: A chunk of 40 actions, each 35-dimensional.

Other Properties Related to Output: Each action contains left arm (7), right arm (7), left hand (7), right hand (7) and waist (3) joint targets, a base-height command (1) and a navigation command (3). A separate whole-body balance controller turns the last two into leg motion.

Our AI models are designed and/or optimized to run on NVIDIA GPU-accelerated systems. By leveraging NVIDIA’s hardware (e.g. GPU cores) and software frameworks (e.g., CUDA libraries), the model achieves faster training and inference times compared to CPU-only solutions.

Model Version(s):

G1-Factory-GR00T-1.7 v1: GR00T N1.7 fine-tuned for 20,000 steps; per-file SHA-256 checksums in SHA256SUMS.

The checkpoint is a standard GR00T N1.7 checkpoint. It consumes the head-camera image, robot joint state and English task instruction, and returns action chunks using the included processor configuration, normalization statistics and embodiment mapping.

Training, Testing, and Evaluation Datasets:

Training Dataset:

Link: nvidia/G1-Factory-Benchmark

Data Modality: Image, text, other (robot joint states and actions).

Training Data Size: 900 teleoperated demonstrations, 100 per task, in LeRobot format (about 400,000 frames recorded at 50 Hz).

Video Training Data Size: [Less than 10,000 Hours]

Image Training Data Size: [Less than a Million Images]

Text Training Data Size: [Less than a Billion Tokens]

Non-Audio, Image, Text Training Data Size: Robot joint-state and action trajectories accompanying each demonstration.

Data Collection Method by dataset: Manually-Collected

Labeling Method by dataset: Automated

Properties: Nine task-specific teleoperation datasets for a Unitree G1 humanoid in G1 Factory. Each episode contains a 640 x 480 head-camera RGB video, numerical robot states and actions, and an English task instruction. The nine tasks are BoxLift, BoxLiftFloor, BoxTableToShelfPnP, DrillLift, DrillLiftObs, DrillPnP, PickDrillFromHolder, PushButton and PushShelfForward. Fine-tuning ran for 20,000 steps with global batch size 32 on eight GPUs, AdamW at learning rate 1e-4 with a cosine schedule and 5% warm-up, weight decay 1e-5, state dropout 0.2 and seed 42.

Testing Dataset:

Data Collection Method by dataset: Synthetic

Labeling Method by dataset: Automated

Data Modality: Image, Text, Other (numerical robot states, actions and simulator-generated task outcomes).

Properties: The nine-task benchmark contains 900 synthetic simulation episodes in G1 Factory, 100 per task, from G1 Factory's own evaluation. The tasks are BoxLift, BoxLiftFloor, BoxTableToShelfPnP, DrillLift, DrillLiftObs, DrillPnP, PickDrillFromHolder, PushButton and PushShelfForward. The policy consumes head-camera RGB images, numerical robot joint states and English task instructions and generates numerical actions. The simulator labels each episode with its task outcome. Per-task success rates are listed under Results.

Evaluation Dataset:

Data Modality: Other (simulated robot episodes and their task outcomes).

Data Collection Method by dataset: Synthetic

Labeling Method by dataset: Automated

Properties: 100 synthetic simulated episodes of the G1 Factory PushButton task from G1 Factory's own evaluation, containing robot state, actions and task outcomes. The task uses the English instruction "Walk to the console and press the red button". An episode succeeds when the task's success condition fires within the 20-second episode.

Benchmark Score: PushButton success rate 42% in G1 Factory's own evaluation (100 episodes).

Inference:

Acceleration Engine: PyTorch.

Test Hardware Set-Up (GPU Architecture, Model): NVIDIA Ada Lovelace L40 and L40S

One GPU with 48 GB runs the simulator and policy. A 50-episode evaluation with one scene takes about 45 minutes.

Inference requires the checkpoint's normalization statistics, embodiment mapping and processor configuration, all included in the repository.

Usage

Loading requires access to the gated nvidia/Cosmos-Reason2-2B model on Hugging Face (hf auth login or HF_TOKEN). Download the checkpoint:

bash
hf download nvidia/G1-Factory-GR00T-1.7 --local-dir checkpoints/G1-Factory-GR00T-1.7

Load it as a GR00T N1.7 policy with the Isaac-GR00T N1.7 code, using the new_embodiment embodiment tag (the tag the checkpoint was fine-tuned with; see embodiment_id.json and processor_config.json). Each call takes one ego_view head-camera frame, the five state groups left_arm, right_arm, left_hand, right_hand and waist, and the task instruction. It returns 40 future actions for the groups left_arm, right_arm, left_hand, right_hand, waist, base_height_command and navigate_command.
