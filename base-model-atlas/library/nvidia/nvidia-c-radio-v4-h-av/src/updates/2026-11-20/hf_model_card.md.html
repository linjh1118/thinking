Model Overview

Description or Model Summary with Description and License:

C-RADIOv4-H-AV generates embeddings for images and text in a shared space, used for text-to-image and image-to-image retrieval over autonomous vehicle (AV) driving data. C-RADIOv4-H-AV was developed by NVIDIA as a fine-tune of C-RADIOv4-H (SigLIP2-g adaptor), a contrastive CLIP-style model that outputs embeddings and similarity scores; it does not generate images or text. Only the SigLIP2-g adaptor head was trained; the image backbone and the text encoder are unchanged from the base model.

This model is ready for commercial or non-commercial use.

Model Architecture:

Architecture Type: Transformer

Network Architecture: Other: Vision Transformer (ViT-H) image encoder with an MLP adaptor head (SigLIP2-g adaptor) and a text encoder

This model was developed based on C-RADIOv4-H

** Number of model parameters: C-RADIOv4-H (base) 653M. Only the SigLIP2-g adaptor head (8.9M parameters) was trained.

Input(s):

Input Type(s): Image, Text

Input Format(s):

  • Text: String

Input Parameters:

  • Image: Two-Dimensional (2D)
  • Text: One-Dimensional (1D)

Other Properties Related to Input: Images are resized to 384x384 without preserving the aspect ratio.

Output(s)

Output Type(s): Other: Embeddings

Output Format(s): Other: Tensor (embedding vectors)

Output Parameters: One-Dimensional (1D)

Other Properties Related to Output: 512-dimensional vectors (first 512 PCA components of the 1536-dimensional adaptor output). The PCA eigenvalues are near zero beyond about 500 components, so the reduction shows a negligible drop on the AV and generalization benchmarks. Image and text embeddings share one space and are compared with a dot product or cosine similarity. The model outputs embeddings only; it does not generate images or text. A downstream application can use the cosine similarity between a query (text or image) embedding and image embeddings to rank multiple images by relevance.

Usage:

The model is loaded with the RADIO PyTorch code through torch.hub, using the checkpoint downloaded from this repository. The 512-dimensional output is obtained by multiplying the eigenvectors (c-radio_v4-h_half_av-eigenvectors.npy) into the SigLIP2-g adaptor head weights and keeping the first 512 output dimensions. For both images and text, the adaptor returns a vector (summary) of shape (B, 1536) before truncation to (B, 512).

python
import numpy as np
import torch
from huggingface_hub import hf_hub_download
from PIL import Image
from torchvision.transforms.functional import to_tensor

repo = "nvidia/C-RADIOv4-H-AV"

ckpt = hf_hub_download(repo, "c-radio_v4-h_half_av.pth.tar")
eigenvectors = hf_hub_download(repo, "c-radio_v4-h_half_av-eigenvectors.npy")

model = torch.hub.load("NVlabs/RADIO", "radio_model", version=ckpt,
                       adaptor_names=["siglip2-g"], progress=True)

# Absorb the PCA eigenvectors into the image and text heads of the SigLIP2-g adaptor.
E = torch.from_numpy(np.load(eigenvectors).astype(np.float32))
adaptor = model.adaptors["siglip2-g"]
for layer in (adaptor.head_mlp.final[2], adaptor.text_model.head):
    layer.weight.data = (E.T @ layer.weight.data.float()).to(layer.weight.dtype)
    layer.bias.data = (E.T @ layer.bias.data.float()).to(layer.bias.dtype)
model.eval().cuda()

# Image embedding.
image = Image.open("image.jpg").convert("RGB").resize((384, 384), Image.BICUBIC)
x = to_tensor(image).unsqueeze(0).cuda()
with torch.no_grad():
    summary, _ = model(x)["siglip2-g"]
image_embedding = summary[:, :512].float()

# Text embedding.
tokens = adaptor.tokenizer(["a traffic light"]).to("cuda")
with torch.no_grad():
    text_embedding = adaptor.encode_text(tokens)[:, :512].float()

# Cosine similarity can be used to rank images for a text or image query.
score = torch.nn.functional.cosine_similarity(image_embedding, text_embedding)

Evaluation Dataset:

**Benchmark Score

Data Collection Method by dataset:

  • NVImageNet: Automated

Labeling Method by dataset:

  • AVObjects: Synthetic (text queries generated with Kimi K3)
  • NVImageNet: Automated (class label taken from the ImageNet category each image was collected for)

Properties AVObjects has 73,961 gallery images (Intersection 5,466; Road Markings 10,162; Traffic Light 7,209; Traffic Sign 51,124), 843 query images and 93 text queries, all in English; the images are road scenes from a 120° FOV car camera and may contain personal data from real-world driving scenes. NVImageNet (NV-CC-Img-Text-Dataset, default version) is evaluated on 1,000 ImageNet classes with up to 100 images per class; the images are natural photos and the class names are in English. Evaluation covers AVObjects (image-to-image and text-to-image retrieval; Intersection, Road Markings, Traffic Light, Traffic Sign) and NVImageNet (Top-1 and Top-5 accuracy, to check that generalization is retained). The splits share no H3 cell per class with the training data.
