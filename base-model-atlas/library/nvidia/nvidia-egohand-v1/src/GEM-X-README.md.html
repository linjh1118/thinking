🔎 Overview

GEM-X provides Body Pose, Hand Pose, and Body Motion in a shared framework for inference, training, and evaluation. Body and Hand Pose reconstruct 3D geometry from individual images. Body Motion uses temporal context to estimate camera-space and world-space human motion from monocular video. All three models use SOMA geometry.

✨ Key Features

  • Full-body and hand reconstruction — dedicated image models for body pose

and detailed left and right hand geometry.

  • Temporal body motion — person tracking, 2D keypoint observations, and Body

Pose features feed a temporal model that predicts camera-space and world-space motion.

  • Flexible hand inputs — supplied boxes or RT-DETR detection, ego/exo

processing profiles, optional tracking and smoothing, and calibrated camera adapters.

  • Robotics showcase — recovered SOMA motion retargeted to Unitree G1 with SOMA Retargeter; see the application demo.
  • Training and fine-tuning — train Body Pose, Hand Pose, and Body Motion;

fine-tune pretrained weights or resume a complete training checkpoint.

  • Visualization and evaluation — render saved predictions, apply optional

contact/IK correction, and evaluate with native Hand metrics or custom evaluators.

🧩 Models and Inference Modes

There are three models and four inference modes. The command identifies the model family and input type; --task selects body or hand.

CommandTaskPrediction
pose-imagebody, handBody or Hand Pose from one image
pose-videobody, handBody or Hand Pose independently on each video frame
motion-videobodyTemporal Body Motion with automatic video preprocessing
motion-cachebodyTemporal Body Motion from cached features and observations

pose-video runs the image model frame by frame. Hand tracking and smoothing are optional processing stages; learned temporal prediction is provided by Body Motion. See Model Overview for architecture and output conventions.

🚀 Quick Start

1. Install

Use Python 3.10 or newer and install a PyTorch 2.10 build for your device. From this checkout:

bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
# Install the PyTorch build for your CPU or CUDA environment before this step.
python -m pip install -e '.[video,hand]'

Install FFmpeg for video processing. For the rendering commands below, install python -m pip install -e '.[render]' and the rendering dependencies in a Linux x86-64 environment. See Installation for CPU/CUDA setup, Docker, ARM64 inference, and optional dependencies.

2. Prepare weights and assets

GEM installs the SOMA 0.3.3 Python runtime. Download the model and geometry files separately, following the instructions for your task:

  1. Download the model checkpoints

into weights/.

  1. For automatic Body Pose or Body Motion, download and extract the

YOLOX person detector to weights/yolox_humanart.onnx.

  1. Download the SOMA v0.3.3 assets

into assets/soma/. The examples below use that directory.

3. Run inference

Body Pose — image

Detect the main person automatically using weights/yolox_humanart.onnx:

bash
gem-infer pose-image --task body --input image.jpg \
  --release body --checkpoint weights/body_s240000.ckpt \
  --soma-assets assets/soma --device cuda --output body.pt
gem-render --task body --input body.pt --output-dir outputs/body

Use --body-detector PATH for another detector location. For calibrated cameras or multiple people, see camera settings and supplied boxes. The same automatic setup supports framewise Body Pose video.

Hand Pose — video

Use the EgoHand checkpoint and a local RT-DETR Hand Detector:

bash
gem-infer pose-video --task hand --input video.mp4 \
  --release hand --checkpoint weights/egohand_s060000.ckpt \
  --hand-detector weights/hand_detector.onnx \
  --soma-assets assets/soma --device cuda --output hands.pt
gem-render --task hand --input hands.pt --output-dir outputs/hand

The default --hand-view exo processes detections independently per frame. For the camera wearer's hands, add --hand-view ego to enable video tracking, crop stabilization, and parameter smoothing. Supplied boxes and calibrated pinhole/fisheye inputs are covered in the Hand inference guide.

Body Motion — video

Configure the local model paths and 2D keypoint detector identifier in body_video_native77.yaml, then run:

bash
gem-infer motion-video --task body --input video.mp4 \
  --config docs/configs/body_video_native77.yaml --device cuda \
  --postprocess --soma-assets assets/soma --output motion.pt
gem-render --task body --input motion.pt --soma-assets assets/soma \
  --device cuda --output-dir outputs/motion

Body Motion produces camera and world views. This example uses --postprocess for the Contact/IK correction shown in the films; omit it for raw predictions. The Inference guide explains input formats, output fields, cached prediction, camera handling, and postprocessing.

🏋️ Training & Evaluation

Install the training and evaluation dependencies:

bash
python -m pip install -e '.[train,eval]'
ModelTraining commandGuide
Body Posegem-train pose --task body --config training.yamlBody Pose training
Hand Posegem-train pose --task hand --config training.yamlHand Pose training
Body Motiongem-train motion --config training.yamlMotion training

Start with the Training & Evaluation guide for data preparation contracts, example configurations, initialization, and full checkpoint recovery. To fine-tune Hand Pose from egohand_s060000.ckpt, use the Hand fine-tuning recipe.

gem-eval pose evaluates Body or Hand Pose; Body Motion uses gem-train motion --validate. Native SOMA25 Hand metrics are included, and Body Pose and Motion support caller-provided evaluators. See Evaluation for configuration and metric definitions.
