Nemotron 3.5 Parse: Transformers and vLLM

Installation

Use Python 3.12 and a fresh environment.

The reference serving contract is vLLM 0.26.0, Transformers 5.14.1, huggingface-hub 1.24.0, and BF16 on one NVIDIA H100. The package declares the exact core dependencies; its [vllm,client] extras add serving and the HTTP evaluation client. See pyproject.toml for pinned direct dependencies.

Download the repository and install its serving extras:

bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install "huggingface-hub==1.24.0"
hf download nvidia/Nemotron-3.5-Parse --local-dir nemotron-parse
cd nemotron-parse
export MODEL_REPO="$PWD"
python -m pip install ".[vllm,client]"
python -m pip check

One-token MTP and the compatible FA3 scheduler are enabled automatically for this model.

For Transformers-only inference, no Nemotron package is required. Follow the Quick Start to load the model directly from the Hub.

Generation contract

The recommended prompt is identical in Transformers, vLLM, and evaluation:

</s><s><output_markdown>

Use one RGB page per request, temperature 0, top-k 1, repetition penalty 1.1, max_tokens=8744, and skip_special_tokens=False. Preserve the coordinate and class tokens in the raw prediction used by postprocessing and scoring.

Boxes are normalized to the evaluated image content. Scale x by that image's width and y by its height; no legacy center-pad inverse is needed. The image processor accepts dynamically sized pages and applies the exported NaViT preprocessing configuration.

One-token MTP

model.safetensors contains the main model and all four trained MTP tensors. No auxiliary weight sidecar is required. The model has 630,800,496 unique trainable parameters, including 2,099,200 MTP parameters. The decoder embedding and LM head share weights and are counted once. Eight stored scalar buffers are excluded from the parameter count.

Transformers generation uses the normal decoder. vLLM enables the trained one-token proposer automatically; it shares the decoder embedding and output head.

bash
vllm serve "$MODEL_REPO" \
  --served-model-name nemotron-parse \
  --trust-remote-code \
  --dtype bfloat16 \
  --distributed-executor-backend uni \
  --tensor-parallel-size 1 \
  --data-parallel-size 1 \
  --max-model-len 16384 \
  --max-num-seqs 192 \
  --max-num-batched-tokens 16384 \
  --no-enable-prefix-caching \
  --limit-mm-per-prompt '{"image":1}' \
  --attention-config '{"flash_attn_version":3}' \
  --chat-template "$MODEL_REPO/chat_template.jinja" \
  --host 127.0.0.1 \
  --port 8000

This is the reference H100 throughput profile. Reduce --max-num-seqs when using a GPU with less memory. Set NP_VLLM_MTP=0 before startup to run the matched normal-decoding path. Clients use model="nemotron-parse", matching the served model name. Startup must show MTP with one speculative token; vLLM's SpecDecoding metrics report its measured draft acceptance during generation.

Verification and references

The current prepared-batch inference and official scoring records are in the validation receipts. The reference reproduction records retain their pinned model, runtime and page-set contracts. See runtime metadata and package evidence for artifact identities and verification scope.

Set NP_VLLM_MTP=0 before starting vLLM to use normal decoding.

Docker alternative

From the downloaded folder, run the included Compose recipe:

bash
docker compose up --build

Use the OpenAI-compatible client in the Quick Start. Container verification details are in reference/README.md.
