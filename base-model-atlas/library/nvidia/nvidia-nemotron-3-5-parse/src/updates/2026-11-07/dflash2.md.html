DFlash2 for Nemotron 3.5 Parse

An optional 89.3M-parameter drafter that accelerates the target model's decoding. It requires the target model and shares its embeddings and output head.

bash
hf download nvidia/Nemotron-3.5-Parse --local-dir ./parse35
vllm serve ./parse35 \
  --served-model-name nemotron-parse \
  --trust-remote-code \
  --speculative-config '{"method":"dflash","model":"./parse35/dflash2","num_speculative_tokens":32}'

Use vLLM with native Nemotron Parse and DFlash2 support. No model-specific package, worker plugin, selector hook or source modification is required. The usual Parse prompts and postprocessing apply. See serving.

Performance

The curve uses the fastest tested native draft length at each concurrency. Set num_speculative_tokens to the chosen length for your workload; the server keeps that length fixed.

The curve uses one H200, BF16, 2,078 ParseBench pages and three trials per point. See the benchmark protocol and downloadable data. The basic command above does not set every benchmark option. These single-pass measurements are separate from the reference triple-pass quality scores. Verified speculative execution can change greedy outputs because attention execution shapes differ; the curve does not establish exact-output or parsing-quality equivalence.

The drafter supports up to 32 speculative tokens and a 16,384-position context. Its inference weights occupy approximately 179 MB. Use the local ./parse35/dflash2 folder; nvidia/Nemotron-3.5-Parse/dflash2 is not a Hub model ID.
