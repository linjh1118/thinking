                High-quality human motion data is becoming increasingly important for applications in robotics, simulation, and entertainment. 
                Recent generative models offer a potential data source, enabling human motion synthesis through intuitive inputs like text prompts 
                or kinematic constraints on poses. However, the small scale of public mocap datasets has limited the motion quality, control accuracy, 
                and generalization of these models. In this work, we introduce <b>Kimodo</b>, an expressive and controllable <b>ki</b>nematic 
                <b>mo</b>tion <b>d</b>iffusi<b>o</b>n model trained on 700 hours of optical motion capture data. Our model generates high-quality 
                motions while being easily controlled through text 
                and a comprehensive suite of kinematic constraints including full-body keyframes, sparse joint positions/rotations, 2D waypoints, and dense 
                2D paths. This is enabled through a carefully designed motion representation and two-stage denoiser architecture that decomposes root and body 
                prediction to minimize motion artifacts while allowing for flexible constraint conditioning. Experiments on the large-scale mocap dataset 
                justify key design decisions and analyze how the scaling of dataset size and model size affect performance.
            </p>

                <div style="margin: 40px auto; max-width: 1000px;">
                    <p style="font-size: 0.9em; color: var(--text-color); margin: 15px auto; text-align: left; max-width: 950px;">
                        Kimodo is an explicit motion diffusion model that generates 3D human motion by denoising a sequence of skeleton poses. 
                        The model operates on a <b>carefully designed motion representation</b> that enables precise control over generated motion while minimizing 
                        common artifacts, such as floating and foot skating. The motion representation features a smoothed root that 
                        emulates paths drawn in practical animation tools, along with global joint rotations and positions amenable to sparse keyframe constraints. 
                        <br><br>
                        At each step of the denoising process, the model takes in an embedding of the text prompt, a set of kinematic constraints, and 
                        the current noisy motion. Constraints are specified using the same motion representation as the input motion, and are used to overwrite 
                        the corresponding values in the noisy motion. Additionally, a mask indicating which elements are constrained is concatentated to the input motion. 
                        <br><br>
                        Given these inputs, the <b>two-stage transformer denoiser</b> predicts a clean motion that aligns with the text and constraints. 
                        The two-stage denoiser decomposes root and body motion prediction: the root denoiser first predicts global root motion, which is 
                        transformed into a local representation as input to the body denoiser. The final output is the concatenation of the two stages. 
                        <br><br>
                        A key component to effectively train Kimodo is the <a href="https://bones.studio/ai-datasets/">Bones Rigplay dataset</a>, a large studio mocap dataset containing over 700 hours 
                        of production-quality human motion with corresponding text descriptions. 
                        This large dataset also enables the construction of a comprehensive benchmark to evaluate various design decisions 
                        on a wide range of behaviors and scenarios. Please see the paper for more details.
                    </p>
                </div>

<script>
    // Reusable Carousel Class
    class VideoCarousel {
        constructor(config) {
            this.data = config.data;
            this.slidesContainerId = config.slidesContainerId;
            this.dotsContainerId = config.dotsContainerId;
            this.captionContainerId = config.captionContainerId;
            this.currentIndex = 0;
        }

        build() {
            const slidesContainer = document.getElementById(this.slidesContainerId);
            const dotsContainer = document.getElementById(this.dotsContainerId);
            
            if (!slidesContainer || !dotsContainer) return;

            slidesContainer.innerHTML = '';
            dotsContainer.innerHTML = '';

            this.data.forEach((item, index) => {
                const slide = document.createElement('div');
                slide.className = 'scenario-carousel-slide';
                slide.dataset.index = index;
                slide.onclick = () => {
                    if (index !== this.currentIndex) {
                        this.setIndex(index);
                    }
                };
                
                const thumbnailPath = item.src.replace('.mp4', '_thumb.jpg');
                
                slide.innerHTML = `
                    <div class="video-container" style="position: relative; width: 100%; height: auto;">
                        <img class="video-thumbnail" src="${thumbnailPath}" alt="Video thumbnail" 
                             style="width: 100%; height: auto; border-radius: 16px; display: block;">
                        <video loop muted playsinline preload="none" style="width: 100%; height: auto; border-radius: 16px; position: absolute; top: 0; left: 0; opacity: 0; transition: opacity 0.5s ease;">
                            <source data-src="${item.src}" type="video/mp4">
                        </video>
                        <div class="play-overlay" style="position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); 
                             background: rgba(0,0,0,0.7); border-radius: 50%; padding: 20px; cursor: pointer; transition: all 0.3s ease;">
                            <div style="width: 0; height: 0; border-left: 25px solid white; border-top: 15px solid transparent; 
                                 border-bottom: 15px solid transparent; margin-left: 8px;"></div>
                        </div>
                        <div class="video-loading-overlay" style="display: none;">
                            <div class="loading-spinner"></div>
                        </div>
                    </div>
                `;
                slidesContainer.appendChild(slide);

                const dot = document.createElement('button');
                dot.className = 'scenario-dot';
                dot.dataset.index = index;
                dot.onclick = () => this.setIndex(index);
                dotsContainer.appendChild(dot);
            });

            this.setIndex(0);
            this.attachSwipe(slidesContainer.closest('.scenario-carousel-container'));
        }

        attachSwipe(container) {
            if (!container || container.dataset.swipeAttached) return;
            container.dataset.swipeAttached = 'true';

            let startX = 0;
            let startY = 0;
            container.addEventListener('touchstart', (e) => {
                startX = e.touches[0].clientX;
                startY = e.touches[0].clientY;
            }, { passive: true });
            container.addEventListener('touchend', (e) => {
                const dx = e.changedTouches[0].clientX - startX;
                const dy = e.changedTouches[0].clientY - startY;
                if (Math.abs(dx) > 50 && Math.abs(dx) > Math.abs(dy)) {
                    this.navigate(dx < 0 ? 1 : -1);
                }
            }, { passive: true });
        }

        navigate(direction) {
            let newIndex = this.currentIndex + direction;
            if (newIndex < 0) {
                newIndex = this.data.length - 1;
            } else if (newIndex >= this.data.length) {
                newIndex = 0;
            }
            this.setIndex(newIndex);
        }

        setIndex(index) {
            this.currentIndex = index;
            const slidesContainer = document.getElementById(this.slidesContainerId);
            const slides = slidesContainer.querySelectorAll('.scenario-carousel-slide');
            const dots = document.querySelectorAll(`#${this.dotsContainerId} .scenario-dot`);
            const captionContainer = document.getElementById(this.captionContainerId);

            slides.forEach((slide, i) => {
                slide.classList.remove('active', 'prev', 'next', 'hidden');
                const video = slide.querySelector('video');
                const thumbnail = slide.querySelector('.video-thumbnail');
                const playOverlay = slide.querySelector('.play-overlay');

                if (i === this.currentIndex) {
                    slide.classList.add('active');
                    
                    if (playOverlay) {
                        playOverlay.style.opacity = '0';
                        playOverlay.style.pointerEvents = 'none';
                    }
                    
                    const videoLoaded = loadVideo(video, true);
                    if (videoLoaded) {
                        video.addEventListener('loadeddata', () => {
                            if (thumbnail) thumbnail.style.opacity = '0';
                            video.style.opacity = '1';
                            video.play().catch(e => console.warn("Autoplay prevented"));
                        }, { once: true });
                    } else {
                        if (thumbnail) thumbnail.style.opacity = '0';
                        video.style.opacity = '1';
                        video.play().catch(e => console.warn("Autoplay prevented"));
                    }
                    
                    if (captionContainer) {
                        captionContainer.textContent = this.data[i].prompt;
                    }
                    
                    // Preload adjacent videos
                    setTimeout(() => {
                        const prevIndex = (i - 1 + this.data.length) % this.data.length;
                        const nextIndex = (i + 1) % this.data.length;
                        const prevSlide = slides[prevIndex];
                        const nextSlide = slides[nextIndex];
                        if (prevSlide) loadVideo(prevSlide.querySelector('video'));
                        if (nextSlide) loadVideo(nextSlide.querySelector('video'));
                    }, 500);
                    
                } else {
                    if (thumbnail) thumbnail.style.opacity = '1';
                    if (playOverlay) {
                        playOverlay.style.opacity = '1';
                        playOverlay.style.pointerEvents = 'auto';
                    }
                    video.style.opacity = '0';
                    video.pause();
                    
                    if (i === (this.currentIndex - 1 + this.data.length) % this.data.length) {
                        slide.classList.add('prev');
                    } else if (i === (this.currentIndex + 1) % this.data.length) {
                        slide.classList.add('next');
                    } else {
                        slide.classList.add('hidden');
                    }
                }
            });

            dots.forEach((dot, i) => {
                dot.classList.toggle('active', i === this.currentIndex);
            });
        }
    }

    function initializeLazyLoading() {
        // Intersection Observer for lazy loading videos
        const videoObserver = new IntersectionObserver((entries, observer) => {
            entries.forEach(entry => {
                if (entry.isIntersecting) {
                    const video = entry.target;
                    const src = video.dataset.src;
                    if (src && !video.src) {
                        video.src = src;
                        video.load();
                        video.play().catch(e => console.warn("Autoplay prevented"));
                    }
                    observer.unobserve(video);
                }
            });
        }, {
            rootMargin: '50px 0px',
            threshold: 0.1
        });

        // Observe videos that are not immediately visible
        document.querySelectorAll('video[data-src]').forEach(video => {
            videoObserver.observe(video);
        });
    }

    function initializeAllVideos() {
        document.querySelectorAll('video:not([data-src])').forEach(video => {
            // Only autoplay videos that are in viewport or in active carousel
            const isInCarousel = video.closest('.scenario-carousel-slide');
            const isMainVideo = video.closest('.view-content.active');
            
            if (isInCarousel || isMainVideo) {
            video.play().catch(error => {
                console.warn('Video autoplay prevented for:', video.src);
            });
            }
        });
    }

    function loadVideo(video, showLoader = false) {
        const sources = video.querySelectorAll('source');
        const slide = video.closest('.scenario-carousel-slide');
        const loadingOverlay = slide?.querySelector('.video-loading-overlay');
        let hasLoaded = false;
        
        sources.forEach(source => {
            const dataSrc = source.getAttribute('data-src');
            if (dataSrc && !source.getAttribute('src')) {
                source.setAttribute('src', dataSrc);
                hasLoaded = true;
            }
        });
        
        if (hasLoaded) {
            if (showLoader && loadingOverlay) {
                loadingOverlay.style.display = 'flex';
            }
            
            video.load();
            
            video.addEventListener('loadeddata', () => {
                if (loadingOverlay) {
                    loadingOverlay.style.display = 'none';
                }
            }, { once: true });
        } else if (loadingOverlay) {
            loadingOverlay.style.display = 'none';
        }
        
        return hasLoaded;
    }

    function initializeComparisonSliders() {
        document.querySelectorAll('.comparison-wrapper').forEach(wrapper => {
            const video2 = wrapper.querySelector('.video2');
            const canvas = wrapper.querySelector('.slider-canvas');
            if (!video2 || !canvas) return;

            const context = canvas.getContext('2d');
            let isDown = false;
            let currentPosition = 0.5;

            const drawSlider = () => {
                const width = canvas.width;
                const height = canvas.height;
                context.clearRect(0, 0, width, height);

                const x = currentPosition * width;
                
                context.strokeStyle = "rgba(255, 255, 255, 0.7)";
                context.lineWidth = 2;
                context.beginPath();
                context.moveTo(x, 0);
                context.lineTo(x, height);
                context.stroke();
                
                context.beginPath();
                context.arc(x, height / 2, 15, 0, 2 * Math.PI, false);
                context.fillStyle = 'rgba(255, 255, 255, 0.9)';
                context.fill();

                context.strokeStyle = 'rgba(0,0,0,0.5)';
                context.lineWidth = 1.5;
                context.beginPath();
                context.moveTo(x - 5, height / 2 - 5);
                context.lineTo(x + 5, height / 2 + 5);
                context.moveTo(x + 5, height / 2 - 5);
                context.lineTo(x - 5, height / 2 + 5);
                context.stroke();
            };

            const slide = (xPosition) => {
                const rect = wrapper.getBoundingClientRect();
                let position = (xPosition - rect.left) / rect.width;
                currentPosition = Math.max(0, Math.min(1, position));
                video2.style.clipPath = `polygon(${currentPosition * 100}% 0, 100% 0, 100% 100%, ${currentPosition * 100}% 100%)`;
                drawSlider();
            };

            const resizeHandler = () => {
                canvas.width = wrapper.offsetWidth;
                canvas.height = wrapper.offsetHeight;
                video2.style.clipPath = `polygon(${currentPosition * 100}% 0, 100% 0, 100% 100%, ${currentPosition * 100}% 100%)`;
                drawSlider();
            };

            const img = wrapper.querySelector('.video1');
            if (img.complete) { resizeHandler(); } 
            else { img.onload = resizeHandler; }
            
            window.addEventListener('resize', resizeHandler);

            wrapper.addEventListener('mousedown', () => isDown = true);
            wrapper.addEventListener('mouseup', () => isDown = false);
            wrapper.addEventListener('mouseleave', () => isDown = false);
            wrapper.addEventListener('mousemove', e => { if(isDown) slide(e.pageX); });

            wrapper.addEventListener('touchstart', (e) => { isDown = true; slide(e.touches[0].pageX); });
            wrapper.addEventListener('touchend', () => isDown = false);
            wrapper.addEventListener('touchmove', e => { if(isDown) { e.preventDefault(); slide(e.touches[0].pageX); }});
        });
    }
