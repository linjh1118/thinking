方法、组件与训练

TL;DR：fit保存数据，predict触发实际微调子进程。测试隔离与缓存策略属于算法的一部分。

任务适配

每bag50步、8-bag；lr1e-5，10步warmup、wd0.3；小二分类≤16384行用3e-6。不能把predict时间只算成冻结权重前向。

上限训练 / 预测支持
分类训练16384行
回归训练20480行
预测支持二分类16384；多分类/回归32768
宽表>256列分类dtype+topK；回归SVD
heldout-in-support默认train/val内部切分；不得引入test
概率回归

子模型目标归一化到−0.5至1.5，1000bins边界可能不同。等权混合时按分布CDF求分位数/CRPS，不直接平均相同索引；CRPS低不自动保证校准。
