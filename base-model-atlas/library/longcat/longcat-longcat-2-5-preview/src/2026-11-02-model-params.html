对比 LongCat 各模型的默认参数、可调范围与使用约束。 
模型能力对比 ​

采样与生成参数 ​ 
参数 类型 默认值 范围 / 约束 
temperature number 1.0（开启思考） 0.7（关闭思考） 固定值，传入其他值将被覆盖 
top_p number 0.95 (0, 1] 
top_k integer -1 [-1, 100] 
repetition_penalty number 1 [1, 1.5] 
thinking_budget integer — 最大 262,144 
参数说明 ​ 
temperature ​ 
采样温度，控制输出的随机性：值越高输出越随机多样，值越低输出越确定。 
开启思考时固定为 1.0 ，关闭思考时固定为 0.7 。传入其他值不会报错，将被覆盖为对应状态下的默认值。 
top_p ​ 
核采样（nucleus sampling）的概率阈值：从累积概率达到阈值的最小 Token 集合中采样。值越高候选范围越大，输出越多样。 
top_k ​ 
将采样候选限制为概率最高的 K 个 Token，值越小输出越集中。 -1 表示不启用该限制。 
repetition_penalty ​ 
重复惩罚：降低已出现过的 Token 再次出现的概率，值越大惩罚越强。 1 表示不惩罚。 
max_tokens ​ 
限制单次调用生成的最大 Token 数，只限制输出长度，不含输入。生成达到上限时内容会被截断，此时响应的 finish_reason 为 length 。 
thinking_budget ​ 
思考过程的 Token 预算上限，最大 262144 。 
范围校验 ​ 
top_p 、 top_k 、 repetition_penalty 、 max_tokens 传入超出范围的值将返回 400 错误（ invalid_request_error / invalid_parameter ），错误信息逐条指出越界参数，例如： json { "error" : { "message" : "参数校验失败: \n /top_p: 2 is not less or equal to 1 \n /repetition_penalty: 3 is not less or equal to 1.5 \n " , "type" : "invalid_request_error" , "code" : "invalid_parameter" } }
