动机：从 non-thinking 基座到 reasoning model

LongCat-Flash（560B/27B MoE）提供了硬件友好的高吞吐基座，但有三个被论文明确点名的局限：(1) 长 CoT pattern 稀缺——通用预训练语料里 reasoning trace 极少，直接 SFT+RL 模型只能产生浅层 homogeneous reasoning；(2) 大规模 MoE RL 极难稳定——同步训练被最长输出拖死，异步又有 staleness + numerical gap 双重 drift；(3) mixed-domain RL 的 negative transfer——STEM/Code/Agentic 三域 response length 分布差异巨大（Figure domain_train_length_dis 直接画出），混训 batch 内 distribution shift 剧烈。

图 1：Cold-Start 数据 pipeline（mid-training → reasoning SFT）
Cold-Start Step 1: Mid-Training Reasoning Enhancement

在 Flash 560B 上加大 reasoning-intensive 数据占比。消融显示 AIME-24 pass@1 +27.7%、pass@64/128 显著放大——证明 mid-training 真的"撑开 reasoning boundary"，给后续 RL 留出挖潜空间。

Cold-Start Step 2: Reasoning-Oriented SFT

三条独立流水线：(a) General reasoning rejection sampling；(b) Lean4 ATP expert iteration（MiniF2F 67.6 pass@1 的来源）；(c) Dual-path agentic selection：$v_x = s_{\text{w/. tool}}(x) - s_{\text{w/o. tool}}(x) > \tau$，过滤"假需求" query。

Tool-Necessity Value（Dual-Path Selection）
$$v_x \;=\; s_{\text{w/. tool}}(x) \;-\; s_{\text{w/o. tool}}(x)$$
Step ① Statement Formalization

8B autoformalizer 把自然语言题翻译成 Lean4 statement，两阶段过滤（syntax + semantic）保编译/语义都干净。

Step ② Cold-Start Prover Training

model-based synthesis 给每个 (statement, proof) 补 thinking → (statement, thinking, proof) 三元组 SFT。

Step ③ Expert Iteration

当前 prover 攻击未解 statement → 新成功证明入 dataset → 同步合成 thinking → 重训 prover，固定轮次自改进。

Domain-Parallel RL + DORA 异步系统

混合域 RL 在 MoE async 场景下尤其不稳——batch 内 distribution shift 叠加 policy staleness。这篇论文的核心方法创新是「分域训 → 融合 → 通用 RL」三步，再加上 DORA 异步 rollout 系统，让 560B MoE 跑得起近 20% pre-training compute 的 RL 投入。

Domain-Parallel：三域独立 RL

STEM (64K, curriculum) / Code (48K→56K→64K 渐进) / Agentic (48K, 结构化 tool-call format reward) 三个 expert 独立训；每个域独立 query curation（STEM 排 multi-part，Code 标准化 test case，Agentic 聚焦"必须工具"题）。

Model Fusion：TIES + DARE + SCE

对每个 expert 算 task vector $\tau_i = \theta^i_{\text{RL}} - \theta_{\text{SFT}}$，三步融合：(1) Normalization 平衡三域贡献；(2) DARE dropout prune redundant 参数；(3) SCE erase 擦除 minority-direction 更新。最终单模型接近 Pareto-optimal。

General RL：防通用能力退化

fusion 后再做一轮 creative writing / instruction following / safety 数据的通用 RL，防止融合后通用能力 / 安全性坍塌。

图 2：融合模型在三 expert 各域 benchmark 上的结果
DORA：Dynamic ORchestration for Asynchronous rollout

两组设备（Standalone Generator + Elastic Role）+ Streaming Rollout + 多版本 actor（staleness=2 demo）+ Elastic Colocation + PD disaggregation。同步训练 >3× speedup，rollout 加速 1.5×（host-side kernel launch 优化）。最终在数万张卡上跑 RL，compute 投入占 pre-training 20%。

① Domain-Parallel

STEM / Code / Agentic 三域独立 RL，避免 mixed-domain 的 negative transfer。融合后单模型接近 Pareto-optimal，训 N 个 expert 部署 1 个。

② DORA Async

Streaming Rollout + 多版本 actor + Elastic Colocation。3× 加速 vs. 同步训练，跑在数万张卡上，RL 投入占 pre-training 20%。

③ Cold-Start Key

Mid-training reasoning enhance（AIME-24 pass@1 +27.7%）+ Lean4 ATP expert iteration（MiniF2F +18pp）+ dual-path agent selection。cold-start 决定 RL 上限。

④ Token-Efficient CoT

Agentic system 不一定要靠"模型自己想得更长"。把推理 offload 到工具反而更省——AIME-25 token −64.5%，精度不降。
