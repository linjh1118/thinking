Architecture Overview + Zero-Comp Experts

LongCat-Flash is a 28-layer MoE base with 512 FFN experts + 256 zero-computation experts, TopK=12 per token, average activation 27B (range 18.6B – 31.3B). Paired with MLA, ScMoE, Variance Alignment, Hidden z-loss, and Adam ε=1e-16 — a full stability suite. Mid-training pushes STEM+code share to 70%, preparing for downstream agent post-training.

Fig 1: LongCat-Flash inference architecture (MLA + ScMoE + SBO 4-stage pipeline)
Zero-Comp Experts: dynamic compute budget

Beyond 512 FFN experts, add 256 identity experts — input returns directly, zero compute cost. Router does TopK=12 over all 768 experts, actual FFN count varies with token context importance. Function words / digits / punctuation → zero experts; deep-layer tokens → allocated by difficulty.

PID controller keeps budget on target

A PID controller on expert bias regulates global average activation, converging to the target budget. After ~20B training tokens the average stays stable (fluctuation < 1%) but std holds at ~3 — proving the model really does "decide per-token".

MLA + ScMoE + Training Stability

MLA (Multi-Latent Attention) follows DeepSeek-V2's low-rank KV compression; ScMoE extends the team's ICCV'24 work; the Variance Alignment suite fixes the "small-scale design breaks at large scale" problem. This combined stack converges 560B stably in 30 days over 20T tokens.

Fig 2: ScMoE cross-layer shortcut — dense FFN and all-to-all fully overlap
ScMoE: cross-layer shortcut for longer overlap

Pull a shortcut from the previous layer's dense FFN output directly into the current MoE layer, so dense FFN compute fully overlaps with the current layer's all-to-all dispatch/combine. Stronger than shared-expert: shared-expert can only use a small window for overlap, ScMoE uses the entire dense FFN compute window.

Evidence: comm 25.3% → 8.4%

Loss curves at 2.4B / 3B / 15B nearly coincide (quality-neutral) while comm time share drops from 25.3% to 8.4%. Combined with inference-side SBO 4-stage pipeline (MLA / Dense FFN / MoE GEMM / all-to-all overlap), TPOT vs. DS-V3 TBO drops ~50%.

MLA Scale-Correction
$$\alpha_q = \sqrt{\frac{d_{\text{model}}}{d_q}}, \quad \alpha_{kv} = \sqrt{\frac{d_{\text{model}}}{d_{kv}}}$$
Fig 3: MLA variance correction across model scales
Variance Alignment: $\alpha_q,\alpha_{kv}$

Multiply $c_t^Q$ and $c_t^{KV}$ by $\sqrt{d_{\text{model}}/d_q}$ and $\sqrt{d_{\text{model}}/d_{kv}}$ to compensate MLA low-rank decomposition's variance mismatch.

Fine-grained expert: $\gamma=m$

Fine-grained segmentation scales variance down by $m^2$ (gating + hidden-dim reduction), so multiply expert output by $\gamma=m$ to restore variance.

Adam ε = 1e-16

Conventional 1e-5 dominates the gradient second moment under large model + small init + large batch — training collapses. 1e-16 is the on-switch for stability.

Experiments: On Par with DS-V3 / Kimi-K2

① Zero-Comp Experts

512 FFN + 256 identity experts, PID controller pins avg activation = 27B. Easy tokens auto-route to zero experts — dynamic compute budget.

② ScMoE cross-layer shortcut

Shortcut from dense FFN into current MoE lets comm fully overlap with dense FFN. Comm drops 25.3% → 8.4%.

③ MLA efficient attention

Low-rank KV + scale-correction ($\alpha_q,\alpha_{kv}$) compensates variance mismatch. MLA remains quality-neutral at 560B scale.

④ Variance Alignment stability

Variance Alignment + Hidden z-loss + Adam ε=1e-16 + Model Growth (14→28 layer stack). Each trick has a clear failure-mode diagnosis.
