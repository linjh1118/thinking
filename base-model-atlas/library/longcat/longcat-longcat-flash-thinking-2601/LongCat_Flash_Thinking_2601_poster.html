Motivation: From "Can It Think" to "Can It Agent"

The 2509 version solved "teaching the base model to think", with the main battlefield being math + tool-augmented reasoning. Running that in production revealed three real-world gaps: (1) no off-the-shelf environments for agentic tasks — traditional reasoning is environment-free, but agentic search/tool use requires the model to decide when and how to interact; (2) trained agents aren't robust — models that score 88 on clean benchmarks drop to <60 on real user traffic (ambiguous instructions, flaky tools); (3) single-pass thinking hits a ceiling — once intrinsic reasoning approaches its limit, longer CoT yields diminishing returns; test-time scaling must grow depth and width simultaneously.

Core Framing: Intrinsic Reasoning → Environment Interaction

The paper defines agentic reasoning as "solving complex problems via adaptive interaction with external environments" — explicitly shifting the breakthrough direction from "longer thinking traces" to "environment interaction". This is the 2026 agentic-pivot framing.

Three Pieces of Infrastructure (The Real Contributions)

The model itself (560B / 27B activated) is unchanged from 2509; benchmark gains come from Environment Scaling + Robust RL with noise + Heavy Thinking Mode — confirming that once base scale is large enough, agent capabilities' marginal gains come from environment diversity × RL stability × inference parallelism.

G1: Automated Environment-Graph Expansion

Domain spec → 60+ tool auto-synthesis → BFS dependency check → executable tool chain → fallback ensures ≥20 tools. Successfully expanded to 20+ domains and 10K+ environments.

G2: Robust RL with Noise Injection

Explicit decomposition of instruction noise + tool noise, then curriculum-injected — training with noise barely drops clean-benchmark scores (sometimes slightly raises them) while gaining +5~7 on noisy benchmarks.

G3: Heavy Thinking Mode

Parallel reasoning (width expansion) + summary-model reflection (depth expansion) + context memory module + dedicated RL stage for the summary phase. AIME-25 heavy mode reaches a clean 100.

Environment Scaling + Robust RL

Environment Scaling is the most critical engineering breakthrough — it turns the "tool graph" into an automated expansion-and-verification closed loop. "Just add more tools" sounds easy, but uncontrolled expansion breaks cross-tool database consistency: correct trajectories get marked wrong, injecting biased negative rewards — strictly worse than no reward. BFS dependency check + ≥20-tool fallback is what makes the pipeline scale to 32K environments.

Figure 2: Environment Scaling Pipeline (domain → tool graph → BFS expansion)
Domain → Tool Graph → Executable Chain

For each domain (airline / retail / telecom), LLM synthesizes 60+ tools + schema + implementation; unit tests + debugging agent validate with >95% success. Build a tool-dependency graph; BFS-expansion samples executable chain $s_1$; whether to add $s_2$ is governed by $p = f(c, g, |\mathcal{D}_n|)$.

Three-Way Hybrid Data Synthesis (Mid-Training)

Text-driven (mine workflows from tutorials) / environment-grounded (Python env, reverse-synthesize user simulator) / planning-oriented (decomposition + multi-candidate decision steps). 32K→128K→256K staged, 500B + 40B tokens. Pass@k on τ²-Bench with "Enhanced" recipe significantly exceeds baseline at high k.

Heavy Mode + 1M Context + Experimental Results

Heavy Thinking Mode scales depth and width in parallel: thinking model generates N candidate trajectories (width) → summary model reflects and aggregates (depth). Key insight: "generating multiple candidates" and "reflecting to choose among candidates" are separable capabilities — train the summary stage with its own RL stage. AIME-25 heavy reaches 100; BrowseComp-ZH 77.7 ranks open-source #1.

① Env Scaling Parallel

Domain → tool graph → BFS dependency-checked expansion. 20+ domains, 10K+ environments, 32K concurrency. Verifiability-preserving expansion is what makes scaling work.

② Robust w/ Noise

Explicit decomposition of instruction noise + tool noise, curriculum-injected. Clean benchmarks barely drop; noisy benchmarks gain +5~7 (VitaBench-Noise +7.2, τ²-Noise +4.9).

③ Heavy Mode Deeper

Parallel reasoning (width) + summary-model reflection (depth) + dedicated RL stage. AIME-25 hits 100; BrowseComp-ZH 77.7 ranks open-source #1.

④ ZigZag for 1M

Mid-training 50% layers swapped to SSA (Sliding Sparse Attention), 1.5× inference speedup, performance preserved, supports 1M-token context.
