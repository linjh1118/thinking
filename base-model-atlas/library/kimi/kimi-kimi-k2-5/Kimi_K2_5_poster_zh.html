问题与动机

传统多模态方法在 LLM 训练后期以高 vision ratio（50%+）引入视觉 tokens，导致视觉-语言对齐不足，模态间存在冲突，且高 vision ratio 浪费 token 预算。

核心挑战：多模态联合优化

sequential agent execution 依赖按序执行 reasoning step 和 tool call，latency 随任务复杂度线性增长，限制可处理任务复杂度上限。

Agent Swarm 并行瓶颈

多 agent 系统中，credit assignment ambiguity 和 training instability 使得 end-to-end co-optimization 极其困难。

训练效率问题

Pipeline Parallelism 下，视觉 encoder 和文本 embedding co-locate 导致 multimodal input size 变化时 compute load 和 memory usage 剧烈波动。

2

方法基础：Native Multimodal

Early Fusion + Low Vision Ratio

在固定 token 预算下，早期持续低 ratio 混合让模型在更长训练窗口内自然发展 balanced multimodal representations，实现更深度的跨模态联合优化。

MoonViT-3D 架构

从 SigLIP-SO-400M 初始化，NaViT patch packing 实现 variable-resolution 输入。3D packing：4 个连续帧视为 spatiotemporal volume，共享参数，4× 时间压缩。

Zero-Vision SFT

纯文本 SFT 数据中通过 IPython 程序化操作代理（像素级操作、目标尺寸估计、binarization counting 等）激活视觉推理行为。

3

视觉 RL 与跨模态迁移

Outcome-Based Visual RL 三类任务：visual grounding and counting、chart and document understanding、vision-critical STEM problems。

关键发现：视觉 RL 提升文本性能

视觉 RL 增强了结构化信息提取相关的校准能力，减少了类似于视觉 grounded reasoning 相关查询的不确定性。

Agent Swarm + PARL

PARL 架构

Trainable Orchestrator：可学习主 agent，负责动态任务分解、子 agent 实例化、并行调度。
Frozen Subagents：从固定中间策略 checkpoint 实例化，执行轨迹不参与优化。

PARL Reward
$$r_{\text{PARL}}(x, y) = \lambda_1 \cdot r_{\text{parallel}} + \lambda_2 \cdot r_{\text{finish}} + r_{\text{perf}}(x, y)$$
$r_{\text{parallel}}$ — Instantiation Reward

防止 serial collapse，鼓励探索并发调度空间。

$r_{\text{finish}}$ — Sub-agent Finish Rate

防止 spurious parallelism，防止通过大量创建无意义子 agent 来刷指标。

Critical Steps as Resource Constraint

将 parallel agent 执行中的时间成本类比为计算图中的 critical path，显式激励有效并行化。

核心创新

Early Low-Ratio Fusion 在固定 token 预算下，early fusion + lower vision ratio 优于 late fusion + high ratio。

训练洞察

Zero-Vision SFT 纯文本数据即可激活强视觉推理，joint pretraining 已建立强 vision-text alignment。

跨模态迁移

Vision RL 提升文本 视觉 RL 增强了结构化信息提取校准能力，减少视觉 grounded reasoning 不确定性。

Agent 革新

PARL + Agent Swarm 通过 RL 学习动态子 agent 并行调度，将 BrowseComp 复杂度从线性转为并行，效率提升 3~4.5×。
