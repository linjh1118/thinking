Problem & Background
GLM-4.5 vs closed-source frontier models on ARC tasks

Core Challenge

Frontier LLMs (o3, Claude Opus 4, Gemini 2.5 Pro) show strong ARC capabilities but are closed-source with high inference cost.

Core question: how to achieve equivalent Agentic / Reasoning / Coding with far fewer parameters (355B vs 671B+)?

Core Innovation
Deeper MoE (increase depth, reduce width) outperforms wider models on reasoning benchmarks; self-distillation unifies multi-Expert capabilities into one hybrid model
Architecture
MoE → Sigmoid Gates → Loss-free Balance → QK-Norm → MTP Layer

Pretraining 23T tokens: Web (Nemotron-CC quality buckets) + Multilingual (Fineweb-2) + Code (FIM) + Math & Science

Core Methods
Post-Training multi-stage pipeline

Post-Training: Expert Model Iteration

Stage 1: Expert Training
Three independent Expert Models (Reasoning / Agent / General chat), each with SFT cold-start + RL
Stage 2: Unified Training
Self-distillation merges multi-Expert capabilities into a single hybrid model, supporting both thinking and direct response modes
Two-stage difficulty curriculum design

Reasoning RL

Difficulty Curriculum
Stage 2 directly switches to extreme difficulty (pass@8=0, pass@512>0), continuous improvement rather than gradual increase
Token-weighted Mean Loss
Converges faster than sequence-mean loss for code RL; suppresses base-case repetition
64K Output Single-Stage RL
Direct 64K training is better — introducing shorter stages makes the model "unlearn" long-context ability

Agentic RL

BrowseComp + SWE
KG multi-hop reasoning + GitHub PR/issue distributed sandbox testing
Iterative Self-distillation
RL improve → self-distillation → RL again, stage-by-stage improvement
