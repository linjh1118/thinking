<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="glm54-plans">1. Which plans include GLM-5.4?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">GLM-5.4 is available to <strong class="font-medium text-foreground">all GLM Coding Plan users</strong>: Lite, Pro, Max, and Team. It isn&#x27;t exclusive to ZCode; other coding tools that support the Coding Plan can switch to it too.</p>
<ul class="mb-4 list-disc list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Start Plan</strong>: the trial plan for new users also includes GLM-5.4 quota; see <a class="text-primary underline decoration-primary/80 transition-colors hover:decoration-primary" href="/en/docs/configuration#bigmodel-trial">Connect Models → Start Plan</a>.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Legacy V1 plans</strong>: can use GLM-5.4 with their existing benefits unchanged, but are not part of the 1.5× quota described next.</li>
</ul>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="glm54-quota">2. What does the “1.5× quota” in the announcement mean? Is ZCode’s extra 1.5× still there?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<ul class="mb-4 list-disc list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">1.5×</strong>: on the same plan quota, you can use 1.5 times as many tokens with GLM-5.4 as with GLM-5.3. This applies to the current GLM Coding Plan and Team plans; legacy V1 plans are not included.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">ZCode’s extra 1.5×</strong>: that was a limited-time promotion, and it has ended. ZCode now has the same quota as other tools that support the Coding Plan, and the old 1.5× badge no longer appears in the app.</li>
</ul>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="glm54-switch">3. How do I switch to GLM-5.4? What if it isn’t in the model list?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">Click the model name at the bottom right of the composer and choose <strong class="font-medium text-foreground">GLM-5.4</strong>. If it isn&#x27;t listed yet, try these in order:</p>
<ol class="mb-4 list-decimal list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50">Update ZCode to the latest version.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50">Open <strong class="font-medium text-foreground">Settings → Model settings</strong> and click <strong class="font-medium text-foreground">Refresh</strong> in the top-right corner.</li>
</ol>
<p class="text-base leading-relaxed mb-4 last:mb-0">When using the Coding Plan in other tools, set the model name to <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">glm-5.4</code>; in Claude Code, use <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">glm-5.4[1m]</code>.</p>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="glm54-thinking">4. GLM-5.4 thinks for a long time and uses quota quickly. What can I do?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">GLM-5.4 uses the highest thinking level by default, so it reasons thoroughly at every step. For simple questions and clear, small edits, drop it a level: click the model name at the bottom right of the composer and adjust the <strong class="font-medium text-foreground">Effort</strong> slider, or press <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">Ctrl + T</code> (<code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">Control + T</code> on macOS) to cycle through levels.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0">Lower levels respond faster and usually use fewer tokens. Switch back to the highest level for architecture design, hard bugs, and long tasks. See <a class="text-primary underline decoration-primary/80 transition-colors hover:decoration-primary" href="/en/docs/agents#thought-level">Reasoning Effort</a> for what each level is for.</p>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="glm54-flash">5. Is there a GLM-5.4 Flash? Can I still use GLM-5.3?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>

<p class="text-base leading-relaxed mb-4 last:mb-0">ZCode is a new <strong class="font-medium text-foreground">Agentic Development Environment (ADE)</strong>. <ul class="mb-4 list-disc list-outside pl-5 text-sm">

<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Full-context awareness</strong>: Agents can understand project structure, file content, and UI visuals without requiring you to memorize complex command-line flags</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Current focus</strong>: strengthening long-task execution and stability around the self-developed ZCode Agent, connecting workspace context, tools, models, permissions, and Review into one continuous development flow</li>
</ul>

<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="context-window">14. Context capacity looks smaller than the model&#x27;s real window. How do I set it for a custom model?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">Every model entry carries a <strong class="font-medium text-foreground">context window</strong> value, and ZCode computes capacity from it:</p>
<ul class="mb-4 list-disc list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50">For models that match a built-in rule, Smart configuration fills in the window automatically.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Models that match no built-in rule (for example, a model you just added to a custom provider) default to 1M (1000000).</strong> If the model&#x27;s real window is smaller, change it to the actual value.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50">A value you enter takes priority over the recommended one.</li>
</ul>
<p class="text-base leading-relaxed mb-4 last:mb-0"><strong class="font-medium text-foreground">GLM-5.4 has a 1M context window.</strong> If it shows a noticeably smaller capacity, update ZCode to the latest version and click <strong class="font-medium text-foreground">Refresh</strong> in <strong class="font-medium text-foreground">Settings → Model settings</strong>, or set it to <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">1000000</code> manually as described below.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0">To change it, open <strong class="font-medium text-foreground">Settings → Model settings</strong>, click the <strong class="font-medium text-foreground">Edit</strong> icon to the right of the model in the model list, and change <strong class="font-medium text-foreground">Context window</strong> in the <strong class="font-medium text-foreground">Edit model settings</strong> dialog. Models in custom providers, presets, and plans can all be edited; see <a class="text-primary underline decoration-primary/80 transition-colors hover:decoration-primary" href="/en/docs/configuration#context-window">Connect Models → Changing the Context Window</a>.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0">The capacity shown for a session comes from the model <strong class="font-medium text-foreground">currently selected in that session</strong>, so different sessions in the same project can legitimately show different numbers — an older session keeps the model it was created with.</p>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="auto-compact">15. Why does auto-compaction kick in long before the window is full?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">Compaction doesn&#x27;t wait for the window to fill up — it reserves output space and a safety buffer in advance:</p>
<p class="text-base leading-relaxed mb-4 last:mb-0"><strong class="font-medium text-foreground">Trigger point = context window − output reserve (capped at 21,000) − a safety buffer of about 13,000</strong></p>
<ul class="mb-4 list-disc list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50">The output reserve is the smaller of &quot;Max output tokens&quot; and 21,000, so the combined deduction is normally a fixed <strong class="font-medium text-foreground">~34K tokens</strong>.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50">In practice: a 128K window compacts around <strong class="font-medium text-foreground">94K</strong> tokens (~73%), 200K around 166K, 1M around 966K. The smaller the window, the lower the trigger point as a percentage — this is expected.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50">The trigger count includes a live estimate of this turn&#x27;s tool results, so it runs slightly ahead of the meter above the input box — which is why compaction can appear to fire &quot;before the line&quot;.</li>
</ul>
<p class="text-base leading-relaxed mb-4 last:mb-0">If the window value you entered doesn&#x27;t match the model&#x27;s real window (see the previous entry), the compaction timing shifts with it — fix the window value first, then re-check the timing. There is currently no user-facing switch or threshold for automatic compaction.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0"><strong class="font-medium text-foreground">Frequent compaction through a third-party relay</strong>: ZCode decides when to compact from the <strong class="font-medium text-foreground">token usage the model API returns</strong>. Some relay or proxy services report inflated usage, so ZCode thinks the context is nearly full and compacts again and again. Compare against the official endpoint first; once you confirm the relay reports usage incorrectly, contact that service.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0">Compaction uses the model the conversation is currently using.</p>

<p class="text-base leading-relaxed mb-4 last:mb-0">Click the <strong class="font-medium text-foreground">Help</strong> icon (the question mark) in the top-right corner → <strong class="font-medium text-foreground">About ZCode</strong>; on macOS you can also use the menu bar <strong class="font-medium text-foreground">ZCode → About ZCode</strong>. The dialog shows the current version, and update-check toasts include it too. There is currently no version entry in Settings.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0">New versions roll out in stages, so the app may offer an update while the download page still shows the previous release; just update from inside the app. To get new versions earlier, turn on <strong class="font-medium text-foreground">Receive preview updates early</strong> in <strong class="font-medium text-foreground">Settings → General</strong>; <strong class="font-medium text-foreground">Automatically download and install updates</strong> on the same page saves you the manual download.</p>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="network-drive">23. My project is on a network drive or NAS, and new sessions or messages hang?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">Older versions could not reliably watch for file changes on network shares (SMB shares, NAS, mapped network drives), so creating a session or sending a message could hang and eventually time out. Update ZCode to the latest version first.</p>
<p class="text-base leading-relaxed mb-4 last:mb-0">For very large projects, reads and writes on a network drive are still slower than local ones, so we recommend keeping the working folder on a local disk.</p>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="remote-update">24. Updating ZCode on the server is slow every time I use SSH remote development?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">There are two ways to update the remote side, and you can choose when connecting or updating:</p>
<ul class="mb-4 list-disc list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Download locally, then upload</strong>: downloads over your computer&#x27;s network and uploads to the server, so speed depends on your connection and upload bandwidth.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Download on remote server</strong>: the server downloads directly, skipping the upload. The server must be able to reach the ZCode CDN and have download, extraction, and checksum tools.</li>
</ul>
<p class="text-base leading-relaxed mb-4 last:mb-0">If the server&#x27;s internet access is faster, the second option usually saves time; see <a class="text-primary underline decoration-primary/80 transition-colors hover:decoration-primary" href="/en/docs/remote-development#remote-download">When should I choose &quot;Download on remote server&quot;?</a>.</p>
<h3 class="group min-w-0 text-2xl font-medium mt-8 mb-3 text-foreground" id="linux-wsl-faq">25. ZCode won&#x27;t start on Linux / WSL, login doesn&#x27;t return to the app, or the input method doesn&#x27;t work?<span class="relative inline-block w-0 align-middle"><button type="button" aria-label="Copy link" title="Copy link" class="absolute left-3 top-1/2 -translate-y-1/2 inline-flex size-8 items-center justify-center rounded-md border border-transparent text-muted-foreground/60 transition hover:text-foreground hover:bg-muted/40 hover:border-border opacity-0 group-hover:opacity-100 focus-visible:opacity-100 cursor-pointer"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-link2 lucide-link-2 size-4" aria-hidden="true"><path d="M9 17H7A5 5 0 0 1 7 7h2"></path><path d="M15 7h2a5 5 0 1 1 0 10h-2"></path><line x1="8" x2="16" y1="12" y2="12"></line></svg></button></span></h3>
<p class="text-base leading-relaxed mb-4 last:mb-0">On Linux desktops and Windows WSLg, these are the three most common issues, and most cases can be narrowed down quickly:</p>
<ul class="mb-4 list-disc list-outside pl-5 text-sm">
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">AppImage fails to start</strong>: usually a missing <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">libfuse2</code> (on Ubuntu / Debian run <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">sudo apt install libfuse2</code>); if nothing happens when clicking the icon, launch it once from a terminal to see the error; for GPU-related errors, add software-rendering flags such as <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">--disable-gpu</code>.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Browser login completes but never returns to ZCode</strong>: the system handler for <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">zcode://</code> is usually misconfigured — common causes are launching with <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">sudo</code>, moving the AppImage around login, or installing both the deb package and the AppImage. Check with <code class="rounded-md bg-muted text-foreground border border-border px-1.5 py-0.5 font-mono text-sm">xdg-mime query default x-scheme-handler/zcode</code>, keep the AppImage at a fixed path, and restart it.</li>
<li class="ps-1 mb-2 marker:text-muted-foreground/50"><strong class="font-medium text-foreground">Only English input works / input method broken</strong>: this relates to the IBus / Fcitx5 environment variables of the current session — launch ZCode from a shell where the input method is already configured. The first CJK character not appearing under WSLg is a known compatibility issue; type a placeholder character and delete it as a workaround.</li>
</ul>
<p class="text-base leading-relaxed mb-4 last:mb-0">For the full commands, launcher script examples, and the diagnostic info to collect when reporting, see the <a class="text-primary underline decoration-primary/80 transition-colors hover:decoration-primary" href="/en/docs/linux-wsl">Linux / WSL Troubleshooting Guide</a>.</p>
