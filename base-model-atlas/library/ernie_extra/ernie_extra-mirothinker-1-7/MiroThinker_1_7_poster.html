Problem: Challenges of Heavy-Duty Research Agents

Complex long-horizon reasoning faces three challenges: step reliability (errors cascade), overall coherence (needs evidence chain), and heavy-duty capability requirements (open-web research, scientific reasoning, financial analysis).

Core Innovation: Verification-Embedded Reasoning

Unlike merely extending reasoning chains, Verification Agent embeds verification into the reasoning process — Local Verification for intermediate steps, Global Verification for overall trajectory.

MiroThinker-1.7: Agentic Mid-Training

Emphasizes three core capabilities: Structured Planning, Contextual Reasoning, Tool Interaction.

Fig 2: Agentic Mid-Training Pipeline
Structured Planning

Decompose complex tasks into executable sub-steps with clear execution paths and dependencies.

Contextual Reasoning

Maintain reasoning coherence in long contexts, effectively utilize intermediate results and external information.

Tool Interaction

Proficiently use search, code execution, file operations, supporting 300 tool calls/task.

Effective Interaction Scaling

Should extend effective interaction, not interaction count. Every step requires strong atomic capability: planning, reasoning, tool execution.

Key Finding

Core Insight

Research Agent's key is not more search, but embedding verification into the reasoning process. Verification is the bridge between planning and execution.

Key Finding 1

Verification-Centric: Embed verification into reasoning, not just checking results at the end.

Key Finding 2

Local + Global: Hierarchical verification architecture for both intermediate steps and overall trajectory.

Key Finding 3

Heavy-Duty Research: Support 300 tool calls/task, handling complex real-world research workflows.

Key Finding 4

Effective Interaction: Extend effective interaction, not count. Every step requires strong atomic capability.
