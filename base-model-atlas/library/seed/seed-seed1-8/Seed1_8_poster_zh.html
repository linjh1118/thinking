设计理念：通用真实世界 Agent

Seed1.8 面向 generalized real-world agency，不仅保持 LLM/VLM 能力，还扩展到多步交互和任务执行。将搜索、代码执行、GUI 交互统一在 agentic interface 中。

四大设计考量

1. Strong Base Capabilities：保持 LLM/VLM 竞争性性能
2. Unified Agentic Interface：Search + Code + GUI 统一
3. Latency/Cost-Aware Inference：4 种 thinking modes
4. Practical Evaluation：公共 benchmark + 内部高价值领域
