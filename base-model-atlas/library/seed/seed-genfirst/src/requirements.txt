# pip-only alternative to environment.yml, for an existing Python 3.10 env.
#
# Install torch FIRST, matched to your CUDA runtime, because the pins below
# assume it is already present. These results used torch 2.3.1 / CUDA 12.1:
#
#   pip install torch==2.3.1 torchvision==0.18.1 \
#       --index-url https://download.pytorch.org/whl/cu121
#   pip install -r requirements.txt
#
# The text-to-image benchmarks have their own heavy dependencies (see docs/T2I.md)
# and are intentionally not listed here.
#
# Several packages are pinned ABOVE the versions the published results were
# produced with, because the original pins carry known CVEs: click, diffusers,
# pillow, pyarrow, requests and transformers. None of the upgrades touch an API
# this repository uses -- the CLIP and T5 text encoders were checked to produce
# bit-identical outputs before and after. environment.yml keeps the exact
# original set for anyone reproducing bit-for-bit; see docs/SECURITY_NOTES.md.
#
# transformers 5.9.0 pulls huggingface-hub, tokenizers, regex and safetensors up
# with it; those four are pinned to match and are not independent choices.
