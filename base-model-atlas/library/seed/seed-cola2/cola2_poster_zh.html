压缩、生成、解码

模型先压缩输入，再逐块生成潜变量并逐段写出 token。每次提交文本后，重新编码实际输出，供下一块生成使用。

动态切分
相邻 1–8 个 token 合成一个 span，平均压缩率目标 0.5。负反馈调节阈值，潜向量保留 64 维。
训练信号
token 预测梯度更新编码器。DiT 的 Flow Matching 损失对编码器停止梯度，单独拟合潜变量分布。
推理预设
8 个潜位置一块，8 步 Euler 去噪。解码按 span 提交，使用已提交的文字刷新潜历史。

两种实验回答两个问题

约 210B 的受控实验中，未压缩 Cola-MDM 整体最好。压缩版本收敛更慢，约 150B 后持续缩小与 LLaDA 的差距。
