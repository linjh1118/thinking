Problem & Background

Agent Foundation Model vs General Foundation Model

Dimension General Foundation Model Agent Foundation Model
Training Goal Dialogue, Q&A, Summarization Tool use, Multi-step reasoning, Env interaction
Pre-training Data Web, Books, Code Agent trajectories, Environment feedback
Eval Focus MMLU, HumanEval GAIA, SWE-bench, GUI tasks
Downstream Adaptation SFT/RM/RLHF Less fine-tuning for agents

Research Motivation

Seed2.0 positions itself as a base model for Agent scenarios (similar to how LLM serves as a base for conversation). The core design emphasizes "Agent-first" — not only having base capabilities but also optimizing for agentic scenarios during pre-training to provide a stronger base for downstream agent tasks.

Design Philosophy

"Agent-first" philosophy: optimizing for agentic scenarios during pre-training, rather than only doing RLHF/SFT in post-training. This may be more efficient than post-training alone.
