预算必须匹配

Best-of-3多三次rollout选择；10轮反馈的6.10不是一次推理成绩。88%真人一致率来自100对分数不同样本与一位expert。

行为摘要不是匿名

表示比完整对话更易匹配同一用户；禁止把推断当稳定人格、真实身份或临床事实，保护授权与敏感信息。

实验设计

交换task与behavior来源，固定simulator/assistant/harness；同时测fidelity、任务终态、多样性、答案泄漏和隐私风险。
