问题与模型定位

Microsoft Research全原子扩散研究模型；多链/配体/核酸输入产生坐标集合。不生成新序列，不输出结合亲和力，非聊天正代。

不能把发现日当首发日

HF只写2026年10月，首发日待核。默认checkpoint为bioemu2-preview，同family不拆两个叶子。

样本频率不等于自由能

原卡明确ensemble未校准；不能把采样频次直接解释为Boltzmann概率或绝对自由能。

结构/平衡采样

多帧是构象候选集合，不天然表示时间先后。静态折叠正确不等于状态权重正确。

未来端点

给定同一起点与lag抽独立端点；不是第一帧演化成第二帧。训练lag主要1–1000ns。

时间rollout

显式逐步推进才有时间顺序；物理性失败样本仍保留，不自动重试或修复。

方法与复现契约

先按系统计算MSA与trunk single/pair表示，再对每个batch反复去噪。固定输入/模型设置可复用trunk；不能把去噪速度当全链耗时。

官方原图：去噪吞吐，排除trunk；完整图例保留
复杂度与瓶颈要分阶段

Trunk约O(RN²+N³)计算，pair表示O(N²)；denoiser每步O(BN²)。少量样本可能由trunk主导，大量样本由去噪主导。

保留性能图的分母

一张B200、200步。吞吐图按每步时间折算samples/s，排除trunk；batch增大到饱和，不等于任意系统线性加速。

研读成本分解；不是未公开训练loss
$$T_{total}=T_{prep}+T_{trunk}+n_b n_s T_{step}$$

机制概括或算术说明，不冒充未披露的论文公式。

精度不是一个开关

bf16-mixed作用trunk；denoising仍float32。TF32改计算而不改tensor存储，显存不因此等比例下降。

原卡/README范围不一致

卡写最小测试80GB A100，README列V100/T4等；小卡能否容纳具体系统须另验，不能无条件保证。
