Abstract
Users increasingly rely on AI systems for extended, multi-turn tasks, yet evidence indicates that LLM-based system performance degrades over prolonged interaction. To evaluate and improve AI assistants in such settings, we need user simulators that faithfully follow complex user intents while exhibiting realistic conversational behavior. Existing approaches manifest a trade-off: prompted assistants can follow complex user intents but lack behavioral fidelity, while specialized user simulators better approximate conversational behavior but struggle to remain faithful to complex intents. In this paper, we propose a reinforcement learning (RL) recipe that jointly rewards task intent adherence and behavioral naturalness. A crucial contribution of the method is operationalizing naturalness with a lightweight discriminator trained in an alternating, adversarial loop with the user simulator. We release the resulting model,
UserLM-2.0
, which produces valid simulated conversations (i.e., meeting both task-faithfulness and naturalness criteria) 46.2% of the time, over three times the rate of the strongest prior user simulator (14.1%).

1
Introduction
Users increasingly expect AI assistants and agents to help them accomplish complex tasks through sustained, multi-turn interaction, rather than provide isolated answers to individual queries
(
Handa et al., 2025
;
Chatterji et al., 2025
)
. Yet prior work has shown that current LLM-based systems severely degrade in performance in such interactive settings
(
Laban et al., 2025
;
Tack et al., 2026
)
.
Understanding and addressing this gap requires evaluations that capture how real users communicate their goals and respond to assistants over multiple turns
(
Chang et al., 2025a
)
. A crucial component of interactive benchmarks is a
user simulator
, which takes as input a high-level
task intent
(such as the one shown in Figure
1
) and generates plausible user utterances through iterative interaction with an assistant
(
Yao et al., 2024
;
Lu et al., 2025
;
Huang et al., 2025
)
.
We focus on two essential properties of user simulators: task fidelity and behavioral naturalness. Task fidelity requires the simulator to convey the information specified in the task intent over the course of the conversation, without omitting or contradicting the specification. Behavioral naturalness requires the simulator to resemble real users in both how it phrases individual messages and how it conducts the interaction across turns. A simulator that omits task requirements can make assistant models appear to fail when the simulator is at fault, making benchmarking unreliable
(
Mehri et al., 2026c
;
Zhou et al., 2026
)
, whereas a simulator that does not adequately capture the interactive behavior of real users may yield conclusions that do not transfer to real interactions
(
Zhou et al., 2026
;
Seshadri et al., 2026
)
.
We show experimentally that current approaches favor one requirement at the expense of the other. Prompting LLM assistants to act as users is the most common method for simulating users
(
Yao et al., 2024
;
Lu et al., 2025
;
Huang et al., 2025
)
. While prompted assistants can stay on task, they lack behavioral naturalness
(
Naous et al., 2026
;
Mehri et al., 2026a
;
Zhou et al., 2026
)
. This is illustrated in the example in Figure
1
, where GPT-5.6-Sol (a strong assistant LLM) accurately enacts the task intent but expresses it through unusually polished and exhaustive messages, unlike the conversational patterns in real user-AI exchanges.
An alternative is to train user simulators by “flipping the dialogue”: supervised finetuning an LLM on user utterances from a corpus of user-assistant interactions
(
Naous et al., 2026
;
Suh et al., 2026
)
. As reported in prior work, such finetuned user simulators exhibit realistic interaction behavior but often struggle to precisely enact the task intent they are given
(
Naous et al., 2026
;
Zhou et al., 2026
)
. In the example in Figure
1
, the SFT-trained UserLM-8B
(
Naous et al., 2026
)
ends the conversation prematurely, before conveying all of the specified task requirements to the assistant.
We propose a post-training recipe that improves task fidelity while preserving behavioral naturalness in user simulators. We first finetune an LLM on user turns from a corpus of user-assistant interactions, then post-train it using multi-turn reinforcement learning.
Our RL training objective jointly rewards task fidelity and behavioral naturalness. Rewards related to task fidelity use LLM-based judges
(
Zheng et al., 2023
)
, for example by evaluating the extent to which a simulated conversation has conveyed the information specified in the task intent. We find that LLM-as-a-judge for behavioral naturalness fails to reliably encourage realistic user behavior. Instead, drawing on adversarial training
(
Goodfellow et al., 2014b
)
and its application to dialogue generation
(
Li et al., 2017
)
, we propose a discriminator-based reward for behavioral naturalness. Specifically, we continually retrain a discriminator to distinguish real user conversations from conversations generated by the user simulator being trained. This choice defines the naturalness reward in terms of how indistinguishable a given simulated conversation is from real user conversations. We update the discriminator as the simulator evolves to keep the naturalness reward responsive to its changing outputs and reduce opportunities to exploit a fixed evaluator
(
Gao et al., 2022
)
.
We train, evaluate, and release the resulting artifact, UserLM-2.0. Among the simulators we evaluated, UserLM-2.0 lies on the Pareto frontier for task fidelity and behavioral naturalness. We count a simulated conversation as valid if it adheres to our quality and termination criteria, achieves at least 80% coverage of the task intent
and
passes our naturalness criterion, assessed using three discriminators including Pangram
(
Glickenhaus et al., 2026
)
. By this definition, UserLM-2.0 yields valid conversations for 46.2% of task intents, more than three times the 14.1% rate of the strongest prior user simulator (SFTUser-14B). This gap grows even further to a factor of 12 at higher task complexities, highlighting the effectiveness of our method.

2.3
GAN-Style Training with Dynamic Discriminators
One limitation of trained naturalness discriminators, especially lightweight ones with fewer parameters, is that a larger user simulator trained against it will quickly learn to reward hack. It will quickly converge on a narrow set of behaviors that reliably fools the specific discriminator but does not learn broader behavioral naturalness. Our initial experiments validated this intuition – user simulators trained against a static discriminator maximized the naturalness reward within 75 steps by greatly increasing average utterance length while reducing conversation turns.
To address this, we propose a GAN-style training recipe that periodically re-trains the discriminator every k steps. This improves discriminator quality by exposing it to synthetic conversations with distinct behavioral patterns and further helps detect and discourage reward hacking behavior.

Experimental Setup
3.1
Dataset Construction
Dataset Processing.
We run our experiments on the non-toxic subset of WildChat-4.8M
(
Zhao et al., 2024
)
.
We build on top of the dataset processing scheme of
Naous et al. (2026)
, additionally removing interactions with only one user turn as our goal is to simulate multi-turn interactions. This reduces the WildChat-4.8M dataset size from 3,199,860 to 199,249 interactions.
We also follow
Naous et al. (2026)
in how we construct train, validation and test sets.
We hold out 10,000 and 1,000 conversations from the train and validation set for RL training, 3,200 and 1,000 conversations from the train and validation set for discriminator training, and use the rest for SFT. Refer to Appendix
A
for more details on dataset construction.
Intent and Subgoal Extraction.
We need to extract both intents (given as input for simulation) and fine-grained sub-goals (used for LLM-based coverage reward). We use Qwen3-30B-A3B-Instruct-2507
(
Yang et al., 2025
)
to extract intents for all 199,249 conversations. For sub-goals, we few-shot prompt the best available GPT models without reasoning. Details are in Appendix
A
.
Test dataset.
We report all results on a 2000 intent test set, constructed such that the number of intents per sub-goal count (ranging from 1 to 7) is balanced. For each user simulator, we sample four conversations per intent
with Qwen3.5-9B as the assistant.

This, coupled with the small parameter count of UserLM-2.0, leads it to be the most cost-effective user simulator, costing $0.11 to generate 100 valid conversations, compared to $205.20 with GPT-5.6-Sol.
A large gap remains between simulated and real human–AI conversations.
The real, held-out human-AI conversations have perfect naturalness and near-perfect coverage, a 28.2% and 8.0% lead over the best user simulator (UserLM-2.0) on the two metrics respectively. This puts our results in perspective: UserLM-2.0 represents a significant step forward in user simulation, but there remains a substantial gap for future work to close. In particular, our RL-based methodology leads to a large improvement in the task fidelity of the initial SFT checkpoint without sacrificing its naturalness. However, improving beyond this initial naturalness to close the gap to real conversations remains an open challenge. Beyond the model artifact we release, we hope our evaluation methodology emphasizing validity of individual interactions can support future research in user simulation.

5
Discussion & Implications
The remaining gap between UserLM-2.0 and real user conversations.
We first note that our existing metrics are imperfect, as human reference conversations do not achieve perfect scores on Quality or Coverage. Nonetheless, the human references still strongly outperform all simulators, including UserLM-2.0, on these metrics, despite our training directly optimizing these metrics. According to our framework, more than 80% of reference conversations are valid in terms of task fidelity and naturalness. This is more than 30% above UserLM-2.0, a gap roughly as large as the gain between the previously best simulator and UserLM-2.0 (14.1% to 46.2%). We believe that further innovation and scaling in the RL recipes could yield further gains on the metrics within our framework, delivering state-of-the-art user simulators. In other words, we believe the gap in metrics that remains in our framework is significant and invite the community to close the gap to develop improved user simulators.
Poorly chosen naturalness rewards can be worse than none at all.
One surprising finding from our alternative reward design experiments (Section
4.4
) is that several formulations of naturalness rewards lead to worse naturalness performance than no naturalness reward at all. More specifically, we found that evaluating naturalness either with an LLM-as-a-judge prompt or using a fixed discriminator trained only once can harm simulator performance by leading to simulations that are more easily distinguishable from real conversations (i.e., less natural). This phenomenon is understandable through the lens of reward hacking: the simulator optimizes for a flawed notion of naturalness, making simulated conversations more easily identifiable and less natural. This finding highlights the importance of the dynamically retrained discriminator of our training framework: we demonstrated empirically that this enables the trained simulators to minimize the gap with a reference corpus of real interactions while preventing reward hacking. We hope this experiment encourages the community to limit the use of LLM-as-a-judge for naturalness evaluation, as we show it is not effective.
UserLM-2.0 is trained and evaluated only on chatbot interactions.
For UserLM-2.0, our training and evaluation intend to simulate conversations from the WildChat-4.8M
(
Zhao et al., 2024
)
dataset. WildChat conversations are pure chatbot interactions, with no environment present (such as a file system or access to a computing environment). As agentic interaction with AI-based systems become more prevalent, being able to simulate users not only in pure chat settings but also in agentic settings that involve tools and environments become more important. This can help evaluate not only how users dynamically reveal their intents, but also how they access files, verify task completions from the agent, and how they choose to delegate tasks within a shared environment. Creating such agentic user simulators faces several key challenges, including a lack of diverse data of agentic user-AI interactions. Initial resources such as SWE-chat
(
Baumann et al., 2026
)
show a promising path forward that can enable the training of user simulators for agentic settings.
Alternative designs for the discriminator.
During training, we made several decisions on the information the naturalness discriminator is conditioned on. Specifically, the discriminator we use sees all user utterances, none of the assistant utterances, and the input task intent for a given simulated conversation. This causes the discriminator to not only assess whether the user utterances are natural in terms of the surface form, but also whether the conversation is a naturalistic enactment of the entire task intent (as real conversations are always full enactments of the task intent). We believe that alternative inputs to the discriminator can define subtly distinct naturalness rewards, which can be combined to produce more robust and well-rounded naturalness rewards for training. For example, one could formulate turn-level or conversation-level discriminators, with or without task intents provided, with or without assistant utterances included. We hope that the community will explore diverse formulations of discriminator conditions, and find effective ways to combine them into robust methods to train natural user simulators.
User simulators for real-world use-cases must take privacy into account.
Naturalness is a question of how well a given user simulator aligns with behavior in a target corpus. UserLM-2.0, for instance, is trained by first performing SFT on WildChat-4.8M to align its initial behavior with that of users in the dataset. In realistic settings, simply doing SFT on user data runs the risk of having models regurgitate private information. The development of user simulators should work in tandem with the design of privacy-aware training strategies or methods for generating synthetic data for training that remains naturalistic.
User simulators should be robust to a variety of assistants.
Our training and evaluation both used Qwen3.5-9B
(
Team, 2026
)
as the assistant model that the simulated user interacts with. For a user simulator to be robust, however, it should provide naturalistic responses to both state-of-the-art assistant models, as well as those that perform poorly or inconsistently in a given task. Devising training and evaluation environments that expose user simulators to a broader range of assistant behaviors is a valuable next step.
User simulators should be evaluated holistically.
Research on user simulators is still nascent, and we currently lack a standardized evaluation methodology. One line of work evaluates simulators by comparing corpus-level statistics of behaviors like turn-counts, turn-lengths, etc. against a corpus of human-AI conversations. These metrics are intuitive and useful for characterizing aggregate behaviors, as shown in our behavioral analysis in Section
4.3
. However, a corpus-level alignment on multiple behaviors independently does not guarantee that individual simulations are usable. For example, consider a simulator that, on aggregate, improves both coverage and naturalness but each generated sample maximizes one at the cost of the other. In this case, no individual sample is usable for downstream use-cases of evaluating or training assistant models. Therefore, in addition to corpus-level metrics, we believe that a simulation-level metric is crucial to establishing simulation readiness. Our validity metric captures this new evaluation principle. In our work, we instantiated it to combine task fidelity and naturalness dimensions, although this exact combination can be altered depending on domain specifications. We hope that future work will evaluate user simulators using both simulation- and corpus-level tests for holistic evaluation.

Related Work
User Simulation:
Early work focused on user simulation as a means to evaluate or train task-oriented dialogue policies
(
Eckert et al., 1997
;
Shi et al., 2019
)
, with methods ranging from rule-based systems
(
Schatzmann et al., 2007
)
to neural architectures
(
Asri et al., 2016
;
Kreyssig et al., 2018
)
. Currently, user simulation is predominantly done using LLM assistants prompted zero-shot to act as users on settings ranging from chatbot interactions
(
Li et al., 2024
;
Wu et al., 2025
)
to agentic tasks
(
Barres et al., 2026
;
Sun et al., 2026
)
. While such simulations benefit from LLMs’ ability to enact specified task intents, they also suffer from poor alignment with human behavior
(
Yoon et al., 2024
;
Ivey et al., 2026
;
Zhou et al., 2026
)
. Prior work has separately explored training models to generate user turns in dialogues. This has most commonly been done through finetuning on human-assistant interactions
(
Sekulic et al., 2024
;
Naous et al., 2026
;
Suh et al., 2026
)
on datasets such as MultiWOZ and WildChat
(
Eric et al., 2020
;
Zhao et al., 2024
)
. The resulting models are naturalistic, but also brittle and poor at task-fidelity
(
Naous et al., 2026
)
. As a result, recent work has placed emphasis on alignment and consistency with user intents via RL
(
Abdulhai et al., 2025
;
Wu et al., 2026
;
Mehri et al., 2026b
)
. We propose training an SFT initialization using RL to maximize both task fidelity and naturalness, operationalized as fooling a dynamically trained discriminator.
Evaluation for User Simulators:
There is currently no consensus on how to evaluate user simulators
(
Pietquin and Hastie, 2013
;
Deriu et al., 2021
)
. One common approach is evaluating similarity to human interactions, which can involve comparisons of user simulator surface-form statistics and stylistic features
(
Schatzmann et al., 2005
;
Pietquin and Hastie, 2013
;
Ivey et al., 2026
;
Zhou et al., 2026
)
or behavioral patterns
(
Zhou et al., 2026
;
Mehri et al., 2026a
)
against human data. Alternatively, similarity can be assessed by how well user simulators approximate assistant performance with real humans
(
Williams, 2008
;
Dou et al., 2025
;
Chang et al., 2025b
)
. Other work relies on human judgement as a measure of simulator naturalness
(
Shi et al., 2019
;
Sekulić et al., 2022
;
Wu et al., 2026
)
. However, this can be expensive and depends on annotators’ ability to detect LLM-generated text
(
Russell et al., 2025
)
. In our work, we use state-of-the-art AI-detection models
(
Glickenhaus et al., 2026
)
for a generic measure of naturalness. We complement this by also reporting dataset-specific performance with discriminators trained on our target corpus
(
Li et al., 2017
)
.
GAN-Style Training for Language Models:
Past work has explored GAN-style adversarial training
(
Goodfellow et al., 2014a
)
within language modeling
(
Fedus et al., 2018
;
de Masson d’Autume et al., 2019
)
. Most relevant work uses adversarial training for response generation in dialogues or for assistant dialogue agents
(
Li et al., 2017
;
Liu and Lane, 2018
)
, where
Li et al. (2017)
also conduct evaluation with trained discriminators. Since the inception of LLMs, however, this GAN-style training has largely been abandoned. While trained discriminators exist for AI detection
(
Thai et al., 2026
;
Glickenhaus et al., 2026
)
, they are not used for model training. When the notion of discriminability is introduced to training, it is through prompted LLM judges
(
Wang et al., 2026
)
, which we show harms naturalness. Our work uses GAN-style adversarial training for user simulation instead.
7
Conclusion
We introduce UserLM-2.0, a user simulator for User-AI interaction trained via RL to optimize both task-fidelity and naturalness. We operationalize naturalness as fooling a lightweight discriminator that is periodically retrained throughout RL on real and model-generated conversations. We compare our model against existing trained user simulators and state-of-the-art assistant models prompted to act as users, and find that UserLM-2.0 produces valid conversations meeting both task-fidelity and naturalness criteria 46.2% of the time, more than three times the rate of the next-best user simulator. This gap widens as task-complexity increases, with 12.6% of UserLM-2.0 conversations being valid at the highest task complexity, while the next-best model is valid only 0.8% of the time.

Appendix A
Dataset Construction
A.1
Dataset Filtering
We build on top of the filtering strategy of
Naous et al. (2026)
for WildChat-1M
(
Zhao et al., 2024
)
to filter conversations in WildChat-4.8M. We restrict our attention to the already filtered non-toxic component of the overall WildChat-4.8M dataset. We firstly filter out conversations that were marked as non-English by WildChat. We then filter out conversations featuring heavily templated language. Specifically, we filter out any conversation whose opening 7-gram occurs at least 50 times in the dataset and whose opening 12-gram similarly occurs at least 15 times. We also filter out conversations whose opening turn is repeated verbatim as the first turn at least 50 times in the dataset.
Going beyond
Naous et al. (2026)
, we separately observe many interactions attempting to circumvent the restrictions of the WildChat API by placing interaction histories or few-shot prompts inside the first user turn in an unconventional manner. We heuristically remove such interactions by checking for “User:”, “Assistant:”, “System:” and “Bot:” strings in the first turn. As our goal is to model multi-turn interactions, we also filter out conversations that feature only one user turn. Finally, we filter out conversations containing toxic strings, including any conversation featuring mention of the Doki Doki Literature Club characters Natsuki, Sayori, Monika and Yuri to remove interactions from one particular, prolific user generating.
A.2
Dataset Splits
In order to construct the train/val/test split, we similarly follow
Naous et al. (2026)
. We use WildChat metadata to group users by country and split the users of each country into train, validation and test splits with a 90/5/5 ratio. Each split then contains interactions associated with users from the respective split. For training and validation sets, we allocate 167625 and 6816 intents for SFT; 10,000 and 1,000 intents for RL; and 3,200 and 1,000 for intents Discriminator training. In practice, the test dataset contains a small number of intents with 1 and 7 sub-goals. As a result, the test set features 202 intents featuring 1 sub-goals, 336 intents featuring 2-5 sub-goals each, 335 intents featuring 6 sub-goals and 119 intents featuring 7 sub-goals.

Prompt Construction
In order to construct the few-shot examples for the quality prompt, we sampled a set of conversations from an SFT-initialized model and then manually labeled each individual example according to what error mode it represents or whether there is no error mode. We then constructed a dataset of 15 examples for each error mode, and for the valid category. We randomly constructed 10 few-shot prompts from this set of examples and evaluated model performance on the remainder. We picked the best performing set, which had an accuracy of 85% with no errors for valid conversations. For coverage, we likewise sampled a set of 100 conversations and annotated the coverage score of each conversation, using GPT-5.3 with reasoning. We then constructed 10 three-shot prompts and evaluated each against the remainder of the 100 conversation pool. We then picked the best-performing selection in terms of MAE against the number of sub-goals in a conversation, at 0.773. We perform evaluation with GPT-5.6-Luna to improve the robustness and reliability of the LLM judge.
Checkpoint Selection.
For checkpoint selection, we select the checkpoint leading to the most natural interactions above a set coverage threshold. Firstly, we find that the Human Reference coverage score on the validation set, as computed by Qwen3.5-9B, is 85.6%. Given this, we set a validation coverage score of 85% as the lower threshold for valid checkpoints. We use the similarity between utterance-length and turn-count histogram distributions of generated conversations and Human Reference conversations as a cheap proxy for naturalness. We use the Jensen-Shannon Divergence as the distance metric and choose the checkpoint receiving the lowest JSD above the 85% coverage threshold. For the No Coverage experiment, there were no such checkpoints. As a result, we chose the checkpoint with the lowest JSD among the two checkpoints that had the highest coverage score.

C.4
Naturalness Metrics
We use the same training hyperparameters and backbone to train discriminators for Naturalness-Specific and Naturalness-General. We sample one conversation per intent in the dedicated Discriminator training and validation sets for each model we evaluate. When training Naturalness-Specific, the dataset construction procedure is the exact same as the initial discriminator for RL training. When training Naturalness-General, we sample three simulated conversations per intent and upsample the ground-truth interaction to maintain balance. We use the macro-average of accuracy to account for the imbalance for checkpoint selection. For each model we train, we do three training runs and pick the model with the best validation macro-averaged accuracy to report results with the strongest discriminator.
C.5
Behavioral Metric Definitions
Our behavioral analysis uses turn-level annotations of which subgoals in the fully specified intent
c
∗
c^{*}
are expressed on each user turn. Each goal is counted at most once per turn and assistant turns are excluded. We define the two repetition and verbosity metrics reported in Table
3
below:
1.
Revisitation:
The percentage of goal mentions where the mentioned goal has already appeared in an earlier user turn. Each distinct goal in each turn constitutes one goal mention.
2.
Repetition-only:
The percentage of all user turns that exclusively features goals that were already covered in prior turns.
3.
Empty:
The percentage of all user turns that cover no task subgoal.
4.
Words/goal:
Total words across all user turns divided by the number of distinct subgoals expressed in the conversation, reported as the median over eligible conversations. We define words as Unicode alphanumeric sequences, retaining internal apostrophes, following Unicode compatibility normalization and lowercasing.
With the exception of Words/goal, we average scores within each intent and then equally across intents, separately for each model. Words/goal instead pools eligible conversation-level ratios across intents before taking the median.
We plot Figure
2
using task intents where the Human Reference spent at most 6 turns. When computing the bar for a given turn, we pool all partial conversations leading up to that turn and compute averages across conversations. The cumulative coverage is the average coverage achieved by the partial conversation at that turn. We compute the proportion of new subgoals by determining the number of newly mentioned subgoals at the given turn, dividing over the total subgoal count and averaging across conversations. We similarly compute the proportion of subgoal revisitation by determining the number of revisited subgoals, dividing over the total subgoal count and averaging.
