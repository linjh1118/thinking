📚 源笔记：AesCode
2026-09 · Visual Code

AesCode

Qwen3-VL 8B/32B上的视觉HTML生成模型，以设计图和七通道reward做GDPO。

3K SFT；7408 RL prompts
32B：520 RL steps
Overall85.89；Style55.99

核心理解

把设计要求转成图，可解析属性由确定性verifier检查，视觉不可解析属性由VLM rubric评估；分通道group normalization减少某个容易优化信号吞掉设计质量。

值得做的实验

使用禁外网的浏览器验收执行、文本、边界、表图、布局、留白、设计。参考图条件化带来收益但Style仍低于60，不能把Overall写成无需人工修订。
