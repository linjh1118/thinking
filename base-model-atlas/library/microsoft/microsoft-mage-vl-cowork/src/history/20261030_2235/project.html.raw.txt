<h3 class="feature-panel-title">Evolve the harness before collecting the corpus</h3>
<p class="feature-panel-text">A strong teacher does not automatically make a strong hybrid agent. We refine the <strong>scaffold, tool interfaces, prompts, and terminal execution environment</strong> before large-scale rollout. Evolution is as much pruning as growth: remove redundant action routes and provide application-level libraries. Specialized <strong>GUI, terminal, and hybrid CUA harnesses</strong> then roll out the same synthesized tasks to collect demonstrations for different training stages. The final student learns channel routing inside a single policy—not an external orchestrator.</p><div aria-label="Complementary action channels" class="cw-channel-grid">
<article><span class="cw-channel-label">GUI CHANNEL</span><h4>Act on what the screen shows.</h4><p>Use screenshot-grounded mouse and keyboard actions for visual layouts, rendered output, and live application state.</p></article>
<article><span class="cw-channel-label">TERMINAL CHANNEL</span><h4>Work directly with structured files.</h4><p>Use code, command-line tools, and application libraries to manipulate documents, spreadsheets, and presentations.</p></article>
</div><p class="cw-routing-line">The same policy chooses the channel at each turn—and switches when the task calls for it.</p>

<p class="feature-panel-cap">Optimize the teacher’s execution upstream; carry better hybrid behavior into every retained demonstration.</p>
