Abstract 
Effective computer-use agents should seamlessly combine visual GUI interaction with code and terminal execution within a single policy. We introduce Mage-VL-Cowork , a 4B hybrid computer-use agent trained from an intermediate Mage-VL checkpoint through an end-to-end, progressive five-stage curriculum across midtraining, SFT, and RL. Mage-CUA-Forge powers this curriculum with reusable, skill-conditioned generation workflows and application-specific preparers, synthesizing 293,806 desktop and web tasks across 6,915 skills while reducing recurring per-task expenditure by 82.6% . Rather than directly distilling a default teacher, we evolve its harness and instantiate specialized GUI, terminal, and hybrid configurations to collect stage-specific supervision, including 318,837 retained hybrid trajectories . The final policy reaches 66.0% on OSWorld-Verified under a 50-step budget, outperforming larger agents including Muse Glimmer-30B and Qwen3.6-27B. Relative to Hybrid SFT, online RL adds 10.16 percentage points while reducing mean model calls by 13.0% and output tokens by 25.4% .

Improve how the teacher acts, scale what it learns from, and teach one policy to use both channels. Evolved Hybrid Harness Workflow-first Env Synthesis Five-Stage Training 
Evolve the harness before collecting the corpus 
A strong teacher does not automatically make a strong hybrid agent. We refine the scaffold, tool interfaces, prompts, and terminal execution environment before large-scale rollout. Evolution is as much pruning as growth: remove redundant action routes and provide application-level libraries. Specialized GUI, terminal, and hybrid CUA harnesses then roll out the same synthesized tasks to collect demonstrations for different training stages. The final student learns channel routing inside a single policy—not an external orchestrator. GUI CHANNEL Act on what the screen shows. 
Use screenshot-grounded mouse and keyboard actions for visual layouts, rendered output, and live application state. TERMINAL CHANNEL Work directly with structured files. 
Use code, command-line tools, and application libraries to manipulate documents, spreadsheets, and presentations. 
The same policy chooses the channel at each turn—and switches when the task calls for it. 
Optimize the teacher’s execution upstream; carry better hybrid behavior into every retained demonstration. More tools are not always better. On the same 672 held-out multi-application tasks, the GUI + coding teacher scores 92.0%, versus 89.6% with an added accessibility channel. The corresponding 4B students score 37.6% and 25.1%—a 12.5 pp gap . See the paired comparison ↓ 
Author a workflow once. Generate many executable tasks. 
Mage-CUA-Forge replaces per-task agent construction with reusable, skill-conditioned workflows. Shared application preparers create files and desktop state; coordinated branches produce an instruction, environment setup script, and evaluation rubric. For web and cross-application tasks, synthesized InfiniteWeb environments and high-fidelity replicas built upon and expanding WebHarbor provide resettable local state. Student feedback expands and refines the skill taxonomy across generation rounds. 
38.24% of tasks span multiple applications.

Build both capabilities before learning to combine them 
Starting from an intermediate 4B Mage-VL checkpoint , the specialize-then-unify curriculum first develops visual grounding, reasoning, structured tool calling, GUI execution, and coding and terminal capabilities. Hybrid CUA SFT then teaches a single policy to combine its channels, followed by online hybrid RL with verifiable rewards. 
GUI-Oriented Midtraining → GUI Agent SFT → Coding & Terminal SFT → Hybrid CUA SFT → Online Hybrid RL 
The model first develops two capable action channels, then learns to select and combine them. A COMPLETE FIVE-STAGE RECIPE 
01 GUI-Oriented Midtraining 
Visual grounding, reasoning, and structured tool calling. 
02 GUI Agent SFT 
Complete workflows through screenshots, mouse, and keyboard. 
03 Coding & Terminal SFT 
Terminal, software engineering, and programmatic desktop manipulation. 
04 Hybrid CUA SFT 
Turn-level routing between GUI interaction and coding or terminal execution. 
05 Online Hybrid RL 
GRPO with asynchronous rollouts and verifiable task rewards.

RL adds 10.16 pp over Hybrid SFT, while mean model calls fall from 21.57 to 18.77 and mean output tokens from 7,374 to 5,499 per task. The result is a stronger policy with shorter interaction sequences and less generated output. Midtraining design · grounding, reasoning, and tool calling 
Stage 1 separates the click-only grounding prompt from the full agent schema and deduplicates repeated target locations within same-screenshot packed sequences. The adopted recipe masks the interior of <think> rationales while supervising the delimiter tags and tool calls, preserving the reasoning format while focusing the loss on tool syntax and grounding. 
Single Step Cowork Bench: 342 representative desktop interaction steps spanning eight GUI action primitives. It jointly checks reasoning/tool-call syntax, action type and arguments, and spatial hit accuracy. Compact working memory · recent screenshots + folded action history 
Each context retains the three most recent screenshots and four complete responses , with older steps compressed into imperative Action: summaries immediately after the system prompt. A response combines a grounded <think> rationale, an Action: summary, and the executed <tool_call> . Step-level rationale synthesis uses task context, before/after screenshots, and the executed tool call to produce this consistent format. RL progression · all 33 recorded evaluations Rollout-as-a-Service · asynchronous desktop RL infrastructure 
Desktop environments, model inference, and policy optimization scale separately. The infrastructure integrates PoLar, Slime, Azure Relay, and Azure VM Scale Sets , with SGLang serving model requests. Asynchronous rollouts let completed tasks advance training without waiting for the longest desktop episodes. 
Reference deployment: 1,120 GUI slots on 70 CPU hosts, with 24 B200 GPUs for training and 8 for inference. The report describes bounded policy lag and truncated importance sampling.

What is Mage-VL-Cowork? 
Mage-VL-Cowork is a 4B hybrid computer-use agent (CUA) from the Microsoft Mage Team. A single vision-language policy combines screenshot-grounded GUI actions with code and terminal execution, and reaches 66.0% on OSWorld-Verified under a 50-step budget. 
What is a hybrid computer-use agent? 
A hybrid agent can act through two channels. The GUI channel uses mouse and keyboard actions for visual layouts, rendered output, and live application state. The terminal channel uses code, command-line tools, and application libraries for documents, spreadsheets, and presentations. Mage-VL-Cowork chooses the channel at each turn inside one policy, without an external orchestrator. 
How does Mage-VL-Cowork compare with larger computer-use models? 
On OSWorld-Verified, the 4B model scores 66.0%, ahead of Muse Glimmer-30B (65.9%) and Qwen3.6-27B (63.9%). It scores 87.5% on operating-system tasks and 62.7% on multi-application workflows. 
What does it mean to evolve the agent harness? 
The agent harness is the scaffold around the model: tool interfaces, prompts, and the execution environment. Before large-scale rollout, the teacher harness is refined and pruned. On 672 held-out multi-application tasks, a GUI + coding teacher scores 92.0% versus 89.6% with an added accessibility channel, and the corresponding 4B students score 37.6% versus 25.1%. 
What is Mage-CUA-Forge? 
Mage-CUA-Forge is a workflow-first environment and task synthesis pipeline. Reusable, skill-conditioned workflows generate the instruction, environment setup script, and evaluation rubric together. It produced 293,806 desktop and web tasks across 6,915 skills, and lowered recurring per-task generation cost by 82.6% ($0.906 to $0.158). 
How is Mage-VL-Cowork trained? 
Training starts from an intermediate Mage-VL checkpoint and follows five stages: GUI-oriented midtraining, GUI agent SFT, coding and terminal SFT, hybrid CUA SFT, and online hybrid reinforcement learning with verifiable rewards. Online RL adds 10.16 percentage points over hybrid SFT while reducing model calls by 13.0% and output tokens by 25.4%.
