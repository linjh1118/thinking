Section 4 — Experiments

When Agents Learn Like Humans: Multi-Perspective Discovery, Lazy Loading, and Evolutionary Refinement of Reusable Skills
MoA-Evo (Mixture-of-Analysts Evolution) EMNLP 2026 Submission GLM-4-Flash + GLM-4.7 ALFWorld 274 + SpreadsheetBench-Verified 200

4.1 Research Questions

  • How does MoA-Evo compare to prior skill systems across the four baseline categories?
  • What is the individual contribution of each component (MAD, LSL, SE)?
  • How does analyst diversity affect skill quality and task performance?
  • What is the effect of lazy loading versus monolithic prefix injection?
  • Does co-evolutionary verification improve skill quality and downstream performance?

4.2 Setup

Benchmarks

SpreadsheetBench-Verified — 200 tasks
自然语言指令理解 + 多 sheet 推理 + Python openpyxl 执行，ground truth 对照 golden workbook 文件验证。
ALFWorld — 274 tasks (140 seen + 134 unseen)
文本环境中的家庭任务，需要序列动作规划、跨房间物体操控和状态追踪。使用官方 AlfredTWEnv wrapper，admissible-command constrained action selection。

Model & Rounds

GLM-4-Flash 用于所有组件（task proposers / aggregator / analyst agents / gatekeeper / skill writer / surrogate verifier）。Temperature 0.3（skill extraction）/ 0.6（task proposal）。所有 baseline 使用同一 backbone。

Rounds：Round 0（冷启动，无 skill memory 建立共享 baseline）→ Round 1（使用从 R0 轨迹蒸馏的 skill library）。每个 baseline 的 R1 使用原论文描述的 skill injection 机制实现。

Analysis (from paper)

Category effects: Category III (failure-driven evolution) methods outperform others on both benchmarks, confirming dynamic skill refinement matters more than initial distillation quality. Category II (MemSkill, MCE) shows smallest gains.

MoA-Evo vs best baseline: Strongest external baseline is CoEvoSkill (+3.28 pp ALF, +1.50 pp SS). MoA-Evo exceeds it by +1.83 pp (ALF) and +1.00 pp (SS), attributed to: (1) 6-analyst MAD produces higher-quality candidates than single-role generator; (2) LSL's stage-specific compilation reduces interference.

Ablation ordering: Removing MAD causes largest single-component drop (−1.46 pp ALF), suggesting skill content quality is more limiting than injection strategy. Removing LSL causes second-largest (−1.19 pp).

4.6 Analysis

TLDR：Analysis 章节有 5 个子节，含技能库增长分布、失败前沿分析、单 vs 多分析师 case study、置信度演化、API 成本。其中**失败前沿分析**是论文最有说服力的质性证据（31% SS / 24% ALF 任务失败签名在轮次间偏移）。

Skill Library Composition (R1)

Skill Library Composition after Round 1

SS 产生更多 FailureGuards（44 entries，API 失败有固定分类），ALF 产生更多 EpisodeCases（52 entries，状态追踪失败高度实例相关）。

Failure-Frontier Shifts

SpreadsheetBench — SS-047
R0 failure: ROW_INDEX_GROUNDING_LOST
R1 shift: FailureGuard 抑制了行索引错误（agent 正确 ground 了行引用），但仍失败于 TYPE_CONVERSION_FAILURE。
→ 技能在结构上改变了执行流程，不是表面记忆。
ALFWorld — ALF-112
R0 failure: PREMATURE_TERMINATION（agent 完成第一个子目标就停止）
R1 shift: PlanTemplate 指导 agent 先枚举所有子目标，两个子目标完成后但失败于 OBJECT_LOCATION_AMNESIA。
→ 失败前沿向任务更深层推进。
31% SS / 24% ALF 的仍失败任务在 R0→R1 间发生了失败签名偏移，证明技能在结构上塑造 agent 行为，而非表面记忆。
