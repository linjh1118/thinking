为什么多数模型亏钱？

① 置信度虚高：所有模型平均自报置信度 0.81–0.87，但在 Crypto 等域全面亏损，过度自信 + 置信度加权仓位 = 放大亏损。

② 把新闻当价格：LLM 用「文本语感」预测价格驱动市场，而价格路径包含文本中没有的信息。

③ 不会弃权：虽然 SKIP 不罚分，但模型普遍几乎每题都出手（value_bet 占比 94–99%），没有选择性地只在优势区间下注。

对我们的三个直接启示

① 别裸调 API 上实盘：5/7 模型亏损说明通用 LLM 直接交易是负期望，必须加校准层+领域过滤。

② 大佬的领域知识是真护城河：模型在文本密集域（政治）赚钱、价格密集域（商品/crypto）亏钱——反过来证明后者需要真实领域模型。

③ 小仓位纪律：论文实测仓位到 $1000 时滑点吃掉全部 alpha，实盘仓位控制是生死线。

评估指标：怎么算「赚不赚钱」

CWR（置信度加权收益）— 核心指标

每笔 BUY 的预算 B = 置信度 c × 基础注额 L（论文 L=$10）。预算打到历史订单簿上，从最优卖价开始逐档吃单（模拟真实滑点），得到实际投入 I 和股数 S。

预测正确: π = S × $1.00 − I   (每股结算 $1)
预测错误: π = −I              (每股结算 $0)

CWR = Σπ / ΣI   （全部 BUY 的净利 ÷ 总投入）

直觉：重仓打在错题上会被重罚，轻仓打在错题上损失有限——同时考察「方向对不对」和「敢不敢该重的时候重」。

辅助指标与纪律约束
  • Accuracy：只在非 SKIP 的主动交易上算方向正确率
  • APY = r × 365/持有天数：年化外推（持有期短导致数值夸张，看方向即可）
  • Sharpe = μ/σ：逐笔收益的均值/标准差，惩罚大起大落
  • 时间误差：模型自估结算日 vs 真实结算日的平均天数差
  • 弃权免责：SKIP 完全不计入指标——模拟真实交易员的纪律性
  • 硬门槛：置信度 < 0.6 的决策在管线层直接丢弃，不进结算

论文五条关键发现

  • ① 隐性元认知存在但不够用：所有模型 CWR 都高于 Non-CWR（给对题的置信度更高），说明「自知之明」有信号，但幅度不足以扭转亏损。
  • ② 领域能力严重不均：政治域（文本可解析）赚钱，Crypto 域（价格驱动）在高置信度下深度亏损——这条对大佬路线是利好证据。
  • ③ 指令遵循是必要非充分：GPT-OSS/Grok 零格式违规照样亏钱；MiMo 唯一同时做到「零违规 + 会赚钱」。
  • ④ 滑点封顶 alpha：仓位 $10→$100 alpha 基本保住；$500 起衰减、$1000 时两家头部模型利润被订单簿深度吃光——实盘仓位天花板实锤。
  • ⑤ 高置信 ≠ 高收益：平均自报置信度全体 0.81–0.87，但 5/7 亏损——通用 LLM 的置信度不可直接当仓位信号用。

它到底是什么（用一个例子讲完）

想象一个「能花钱投票、按对错分钱」的市场。以一个真实市场为例：

例：「What will Gold (GC) hit by end of December?」——黄金 12 月底前触及 $4,500？
  • 1. 买股份：你判断会触及，以 0.99 的现价买入 100 股 "Yes" 股份，花费 $99。
  • 2. 等结算：12 月底到了，官方数据源（COMEX 黄金期货价）确认最高价触及过 $4,500 → Yes 胜。
  • 3. 兑付：每股 Yes 兑 $1，你拿回 $100，净赚 $1（约 1%）。若没触及，$99 全部归零。
  • 反过来读价格：Yes 现价 0.99 ≈ 市场认为「概率 99%」。股价 = 实时概率，这是预测市场最迷人的性质。
  • 不对称收益结构：买便宜的「小概率 Yes」（如 0.10）赢了赚 9 倍、输了归零——天然的高赔率彩票；买贵的「大概率的 Yes/No」接近固定收益。论文里顶级模型的大额单笔收益正是来自低价小概率事件的正确判断。
  • 二元对称：Yes + No 价格恒等于 $1（结算互补），所以「买 No」=「做空 Yes」。任何观点都能双向表达。
  • Event 与 Market：一个 Event（如「黄金 12 月底前触及哪一档？」）下挂多个互斥 Market（$4,000 / $4,100 / $4,200…各一个），只有一个是 Yes——这带来「负风险（Negative Risk）」套利结构，见下文。

交易机制：CLOB（中央限价订单簿）

  • 挂单（maker）：限价单挂在订单簿上等成交，永不收费，还每天参与 Maker Rebates 返佣池分钱——费用模式的受益方。
  • 吃单（taker）：市价单吃掉对手盘，按类别付小额手续费（见下）。
  • 链下撮合 + 链上结算：订单签名后提交到 Polymarket 的 CLOB 服务撮合，成交才上 Polygon 链结算——体验像中心化交易所，资产自托管。
  • 智能钱包：平台代管签名授权，充值后无需每笔手动签链上交易；需要少量 POL 作 gas。
  • 订单簿深度：盘口只有 5 档可见深度可抓（PolyBench 就存 top5）——这就是大仓位滑点的来源。
三个新手必懂的机制
  • Merge（合并）：同一市场同时持有 1 Yes + 1 No → 可合并赎回 $1。当 Yes+No 报价之和 < $1 时，两边都买入再 Merge = 无风险套利（机器人抢得最凶的生意）。
  • Redeem（赎回）：市场结算后，持有胜方股份在这里一键兑回 USDC。
  • Negative Risk（负风险）：多选项 Event 中「只有一个是 Yes」，可以卖出整套输家 No 合约锁定收益——多选项事件的资本效率工具，也是组合套利的基础。

资金进出（入金 / 出金）

  1. 准备 USDC：在任意交易所（Binance/OKX/Coinbase 等）购买 USDC。
  2. 充值：Polymarket 内「Deposit」复制充值地址，务必选 Polygon 网络转 USDC（选错链 = 资产丢失）。平台不收充值费（通道方可能收）。
  3. 交易：选市场 → 买 Yes/No → 签名下单。也可用信用卡/银行卡通过第三方通道直接买（通道方收费更高）。
  4. 结算后赎回：Winning shares → Redeem → USDC 回到余额。
  5. 提现：资产页 Withdraw，USDC 转回交易所或自托管钱包，再场内卖出变现。
中国大陆用户的合规现实（必须正面面对）：① 大陆对加密货币交易与兑换的监管持续从严，交易所出入金通道本身受限；② USDC 入金/出金涉及外汇额度与用途申报问题；③ Polymarket 服务条款排除受限司法辖区，大陆是否属于受限范围需自行阅读最新 ToS 确认；④ 美国用户已被强制分流到受 CFTC 监管的 polymarket.us（KYC），说明平台对合规问题是认真的。结论：这条线作为研究/小额实验可控，作为「赚钱主业」之前必须先解决合规与资金通道问题。

手续费（2026 现行规则，直接影响策略账本）

规则要点（官方 Help Center）
  • 只对 taker 收费，maker 永远免费且参与每日返佣池
  • 费用在撮合时由协议自动计算，下单不含费用字段
  • 费用与价格对称：30¢ 和 70¢ 成交的美元费用相同，公式对称于 50¢
  • 地缘政治/世界事件类市场全免费；充值提现平台不收费
  • 最小计费 $0.00001，精度 5 位小数
  • Taker 还有分级返佣（按 30 天吃单量）——高频主动交易能返一部分

  • 50¢ 处吃单：约 0.75%–1.75% 名义金额
  • 10¢ / 90¢ 处吃单：费用只有平价处的 1/5 左右

结算规则：钱怎么定「对错」

  • 规则字面主义：每个市场页都有「Rules」区块，写死结算数据源（如 COMEX 期货价、官方通讯社）、截止时点、边界定义。是数据源说了算，不是「常识」说了算——PolyBench 提示词第 8 条专门强调这一点，模型栽过跟头。
  • 50-50 条款：部分市场规则写明「若截止日前条件未达成则 50/50 结算」——这类市场有价格下限/上限（0.50），是特殊的定价结构，论文提示词第 9 条专门要求模型识别。
  • 争议裁决：结果争议走 UMA 预言机的 Optimistic Oracle + 争议投票机制，极少数市场会因规则解读分歧重新结算——尾部风险之一。
  • 结算时间不可精确预测：官方确认流程可能延迟数小时到数天，资金占用期的机会成本要算（这就是论文 APY 指标存在的原因）。

大佬优势 → 四个具体打法

打法 ①：中期观点的「离散化期权」变现（主力打法）

逻辑：把期货/宏观观点拆成阈值市场的组合。例如判断「金价 3 个月内冲 $4,500 概率被低估」：买 $4,500 档 Yes；同时若认为「跌破 $3,800 概率被高估」，买 $3,800 档的 No。多档组合逼近自定义收益曲线——比场内期权便宜（无时间衰减结构差异、无 IV 定价黑箱），盈亏封顶清晰。

为什么是优势：定价这些档位需要真实的供需/宏观/持仓结构判断，恰恰是通用 LLM（论文实证）和散户都不擅长的。

打法 ②：数据日事件交易（节奏最快）

逻辑：CPI、FOMC、EIA 原油库存、NFP 等发布日的日内收盘阈值 + Up/Down 市场，盘口在发布前对「意外方向」定价不稳。有数据解读和反应速度优势的团队，可以在发布窗口内修正仓位。

注意：这是和全球低延迟机器人的贴身肉搏，只适合有数据源/速度优势的打法，且单盘容量小——快进快出，别恋战。

打法 ③：尾部定价修正（赔率最高）

逻辑：头部市场常有极端定价，如「Crude Oil 创历史新高」曾报 10% Yes。若大佬的供给冲击模型认为尾部概率显著高于市价（地缘升级、OPEC+ 变盘），这就是便宜的多倍赔率彩票。论文里 MiMo 的最大单笔收益全部来自低价小概率事件的正确判断——尾部是预测市场超额收益的主要来源。

纪律：这类仓位必须是「输光不心疼」的小额组合，靠覆盖数量取胜。

打法 ④：Maker 挂单收返佣（最稳健的辅助线）

逻辑：在流动性最好的黄金/原油月度盘上双向挂单做市：赚价差 + 每日 Maker Rebates（费用池全部分给 maker），方向观点弱化、只赚流动性服务费。

风险：逆向选择——数据日会被趋势单扫损。适合盘口宽、波动平稳的时段，配合大佬对「什么时候该撤单」的判断。

仓位纪律：论文用真金白银验证过的三条红线

红线 ①：单市场仓位 ≤ 盘口深度 5%–10%

头部市场流动性 $40K–840K，理论合理单笔约 $2K–50K。论文实测：仓位过 $500 滑点开始显著吃掉优势，$1000 时头部模型利润被深度抹平。Polymarket 不是期货，没有无限深度——大资金必须拆市场、拆时段。

红线 ②：吃单前先算费

taker 费率平价处约 0.75%–1.75%，且 symmetric 结构下极端价格几乎免费。小概率尾部票（打法③）费用可忽略；50¢ 附近的高频进出（打法②）费用是真成本——优先挂 maker，或把进出安排在极端价格带。

红线 ③：结算规则逐字读

商品市场的结算源（COMEX/现货/平台指定源）、时区、截止时点、「触及」的定义（盘中最高 vs 结算价）每家不同。期货大佬的常识在预测市场里可能差一个小数点——下单前把 Rules 读一遍是强制动作。50-50 条款市场另有定价地板，别按纯二元思维报价。

对手盘清醒剂：Arbitrage bots 已在这个市场赚取数百万美元级利润（Yahoo Finance 2026-01 报道），Merge/跨市场纯套利空间基本被机器人吃干；LLM 分析 8600 万笔交易的研究显示 62% 的表面套利机会实际不赚钱。大佬的可持续优势只在「需要真实商品认知的定价偏差」上，不要和机器人抢速度生意。

题型 ①：日内方向题（Up/Down）

题 1：Gold (XAUUSD) Up or Down on October 7? Up 报 3% $4.2K vol · $11.5K liq

解法（Up=3% 时该做什么）：3% 意味着当日已明显下跌且临近结算、剩余时间波动不足以翻盘——这已经是「确定性票据」。唯一可做的：挂 maker 限价 0.95–0.97 买 Down 收尾巴（97→100 赚 3%，p=0.03 处 taker 费按 min(p,1-p) 对称公式趋近于零，但必须 maker 不 taker）。资金占用半天，年化漂亮但绝对额小。

真实风险：① 结算源时点差——平台规则里的「当日收盘」用的是哪个数据源、哪个时点（部分日内盘按特定窗口均价结算），跟你看的行情软件可能差几分钟；② 尾盘行情突变，3% 的票翻盘虽罕见但非零。翻盘即全损，所以这种票只值得用「输光不心疼」的小额参与。

题 2：WTI Crude Oil (WTI) Up or Down on October 7? Up 报 75% 距结算约 8 小时

解法（先算再动，无 edge 就 SKIP）：剩余 8 小时 ≈ 交易日 1/3，油价日内已实现波动年化 25–35% → 剩余时段 σ ≈ 30%/√(3×252) ≈ 1.1%。若当日已涨 +0.8%（演示假设），收盘转跌概率 ≈ Φ(−0.8%/1.1%) ≈ 23% → 市场报 No=25% 与模型几乎重合 → 无 edge，正确动作是 SKIP。PolyBench 论文的教训就是模型什么都想做；真人的优势是知道何时不做。

edge 什么时候出现：① 数据日（EIA 原油库存周三 10:30 ET、OPEC+ 会议）——有库存预测模型的团队在发布前对比盘口隐含方向；② 盘口报价与实时期价的偏离瞬时放大时（机器人延迟窗口）。日常方向题不值得碰。

题型 ②：日内收盘阈值题（closes above ___ on date）

题 1：WTI closes above ___ on October 7? — $82 档 Yes 报 100% $8.8K vol · $41.4K liq

解法（100% 的盘怎么处理）：现价已远离 $82 且临近收盘 → 该档已是收息票。可做：maker 挂 0.97–0.99 买 Yes，赚最后 1–3%（风险同上：结算源时点）。不可做：taker 按 100% 买——费后为零。这道题的真正价值是复盘问题：为什么没人在它还是 60–70% 的时候买？那需要盘中持续监控「现价距离每个档位的 touch/close 概率」，正是 AI 团队「结算哨兵 + 阈值概率引擎」要自动化的东西（见 AI 团队 Tab 路线③）。

题 2：同事件的相邻档位（$80 / $81 / $83…） 题目真实存在，快照未逐一采集报价

解法（阶梯定价 = 把一个事件变成一张隐含分布图）：同一 "closes above ___" 事件的全部档位 Yes 价，就是市场对「今日收盘价」的隐含 CDF。三步：① 把所有档 Yes 价格列出来，相邻档价差 = 隐含密度；② 与自己的日内模型（现价 + 剩余时间 σ + 期现基差）算出的分布对比；③ 哪档偏离最大买哪档。

套利校验：全部档 Yes 之和必须 ≈ 1（收盘价必落一档）。Σ>1 → 全部卖空（负风险机制）；Σ<1 → 全部买入后 merge 无风险套利。论文里 LLM 挂 arbitrage 标签的交易全线亏损，因为它们不做这道算术——这道算术是纯算术，程序做是稳的。

题型 ③：周度触及题（hit ___ Week of ___）

题 1：What will Silver (XAGUSD) hit Week of Oct 5? — ↓$58 档 No 报 77%（Yes=23%） $32.9K vol · $106K liq

解法（touch 概率公式，技术面的直接变现）："触及"= barrier option，定价用反射原理近似：剩余 T 天内触及距离 d 的轨道概率 ≈ 2·Φ(−d/(σ·√T))（drift≈0 时）。白银周波动 σ≈4–5%（演示假设），快照时周还剩 2 天（T≈0.63 周）。

示例演算：现价 $61（假设）→ d = 3/61 ≈ 4.9%
d/(σ√T) = 4.9% / (4.5%·0.63) ≈ 1.73
P(触及 $58) ≈ 2·Φ(−1.73) ≈ 8.4% → Yes 公允 ≈ 0.08
市场报 Yes 0.23 → 严重高估 → 买 No（0.77→1.0，+30% 空间）
（若实时现价距 $58 更近，结论反转——一切以实时 spot 代入为准）

修正项：① drift 显著时用 drift-adjusted barrier 公式（技术面判断的就是这个 drift）；② 周内有 FOMC/CPI 时 σ 上浮 20–40%；③ 必读规则确认结算源（XAG 现货定盘价 vs 平台指定源）和「触及」的时点定义。

题 2：What will WTI Crude Oil (WTI) hit Week of Oct 5? — ↑$95 档 Yes 报 24% $12.1K vol · $44.3K liq

解法（同一公式，反向样本）：快照时 WTI 在 $85–86 区间（10 月初，演示取 $86），距 $95 达 10.5%，周内剩余 3 天，油价周 σ≈5–6% → d/(σ√T) ≈ 10.5%/(5.5%·0.77) ≈ 2.48 → P(触及) ≈ 2·Φ(−2.48) ≈ 1.3%。市场报 24% ≫ 模型 1.3%。

两种解释，动作完全不同：① 若规则是「周内任意时点触及」且本周初油价曾冲高接近 $95，24% 可能是残留定价未清理 → 买 No 是捡钱（但要确认本周确实未触及过，触及则已结算 100%）；② 若市场知道某个供给冲击催化剂（你不知道），24% 是对的 → 这正是「读新闻 vs 读盘口」的分歧检验点，先查消息面再下手。这个案例完美示范：公式给出怀疑，人做最后判断。

题型 ④：月度/季度触及题（多档 hit，主力打法①的载体）

题 1：What will WTI Crude Oil (WTI) hit in October? — ↓$85 档 「↓$85」报 65% $1M vol · $840K liq（商品区最厚盘口）

解法（容量最大的主战场）：月内触及概率 = 2·Φ(−d/(σ·√T))，T=剩余天数/30，油价月 σ≈8–10%。流动性 $840K 意味着单档可容纳 $40K 级仓位（仍守 ≤5% 盘口深度的红线）。

多档组合打法（离散化期权实例）：把 10 月全部档位（$80/$82/$84/…）的 Yes 列成隐含的「月内高低价分布」。若判断「跌破 $85 概率高但跌破 $80 概率低」→ 买 $85 档 Yes + 买 $80 档 No = 合成自定义区间收益，比场内期权便宜（无 IV 黑箱、无时间价值结构差异）。临近月末未触发的档会快速归零/归一，时间价值衰减是可见的——这也是它与真正期权的差异（二元结构下衰减不连续）。

题 2：What will Gold (GC) hit __ by end of December? — ↑$4,500 档 Yes 报 99% $2M vol · $497K liq（COMEX 期货口径）

解法（99% 的档旁边才有肉）：$4,500 档 99% 说明市场认为「12 月底前金价到过 $4,500」几乎确定（快照时金价已在 $4,300+）。真正的题在 $4,600 / $4,700 档和下行档：示例演算——金价 $4,320、剩 80 天、黄金月 σ≈5% → σ√T ≈ 6.4%，P(触及 $4,600) ≈ 2·Φ(−(280/4320)/6.4%) = 2·Φ(−1.01) ≈ 31%；P(触及 $4,700) ≈ 2·Φ(−1.37) ≈ 17%。若这些档市场报价显著低于你的演算 → 买。

区间票据组合：买 $4,500 Yes + 买 $4,700 No =「12 月底前金价到过 $4,500 但到不了 $4,700」的精准表达。02 月缓存快照里同型盘 "GC hit ↑$5,300 end of Feb" 报 99%——同一模板每月滚动，打法可复用，只需每月重算参数。

题型 ⑤：月末结算价区间题（settle at in ___）

题 1：What will Gold (GC) settle at in February? 真实题目，快照未含报价

解法（settle 与 hit 的建模差异——通用模型必错的地方）：settle 只看月末收盘落点，与路径无关：P(落档) 直接由终点分布给出 ln(S_T/S_0) ~ N((r−q−σ²/2)T, σ²T)，各档概率 = 正态 CDF 区间差。关键：用对应月份的期货合约价算距离——GC 远月对现货有年化 2–4% 升水（contango），拿现价算 2 月档距离会系统性偏移。这是期货大佬的常识、纯文本模型的盲区。

交叉校验（确定性相对价值）：数学上恒有 P(月内触及 $x) ≥ P(月末结算 ≥ $x)（路径包含终点）。若同一 $x 的 hit-Yes 明显低于 above-Yes → 市场定价违反不等式，买 hit 卖 above（负风险对锁）稳赚收敛。

题 2：What will Gold (GC) settle at in June? 真实题目，快照未含报价

解法（长周期的三个增量）：① 期限更长 → 分布更宽，中间档概率密度下降、两端尾档价值上升；② 6 月合约的升贴水要用 GC6（6 月期货）曲线定价；③ 跨季度的宏观变量（美联储路径、央行购金节奏）进入 drift——这正是大佬宏观模型的输入位。执行纪律不变：全档 ΣYes≈1 校验 → 单档 ≤5% liq → maker 优先。

题型 ⑥：月末阈值二元题（above ___ end of ___）

题 1：Gold (GC) above ___ end of February? 真实题目，快照未含报价

解法（单一 digital 的三方对账）：above-Yes 的公允值 = P(S_T > K) = Φ(d2)（Black-Scholes 数字期权）。定价后与两个参照对账：① 同事件的 settle 分档盘（⑤ 的 CDF 直接读出 P(S_T>K)）；② COMEX 期权市场的 digital 复制价（看涨期权价差法：P(S_T>K) ≈ ∂C/∂K）。Polymarket 报价若显著低于两参照 → 买；显著高于 → 卖或绕行。跨市场对账是大佬独有优势：机构有 COMEX 期权链数据，散户没有。

题 2：Gold (GC) above ___ end of June? 真实题目，快照未含报价

解法（尾档彩票的仓位纪律）：深 OTM 的 above 档（如现价 $4,320 时 above $5,000）是数字彩票。规则：全部尾档合计仓位 ≤ 资金 10%，单靠赔率取胜——如公价 8%、市场报 4% 时买入，赢了 24 倍。卖点在于概率估计是「你的模型 vs 市场尾巴」的直接对决，胜负全在模型质量，所以只在自己最有认知的资产上做（黄金/原油），不碰没模型的标的。

题型 ⑦：极端事件题（历史新高 / 供给冲击）

题 1：Crude Oil all time high by...? Yes 报 10% $5M vol · 41 个截止日档位（全站最大原油盘）

解法（人工认知优势最纯粹的题型）：WTI 历史最高 $147.27（2008，期货口径以规则为准），距快照现价 ~70%。对数正态外推（σ 年化 30–35%）：15 个月内 touch ATH 的概率量级仅 1–3%。市场报 10% = 给「恶性供给冲击」（OPEC+ 解体、重大地缘战争升级）留了显著权重。

决策树：你的地缘/供给模型说真实概率 ≤5% → 买 No（0.90→1.0，极端 p 处费用趋零，+11% 低风险空间）；模型说 ≥15%（认为冲突升级概率被低估）→ Yes 是 9 倍赔率彩票，小仓买入。这道题没有公式答案——答案就是大佬的供给冲击模型本身，也是论文实证「人工专家强于 LLM」的题型。

题 2：同事件的其他截止档位（by end of 2026 / by Jun 2027…，共 41 档） 题目真实存在，快照未逐一采集报价

解法（尾部期限结构套利）：同一 ATH 事件的不同截止日 = 同一尾部风险的不同期限彩票。逻辑约束：P(by 长期) ≥ P(by 短期) 恒成立；且一旦冲击发生两个同中。若两档价差过窄（长期没比短期贵多少）→ 买长期卖短期（价差交易，冲击不发生时长期时间价值损耗更慢）。41 个档位的完整期限结构 = 一张市场对「供给冲击时点分布」的定价图——这本身就是给期货头寸的免费情报：就算不下注 Polymarket，这张图也该进大佬的晨会材料。

题型 ⑧：跨资产相对表现题

题 1：Bitcoin vs. Gold vs. S&P 500 in 2026 S&P 500 档报 64% $940K vol · 互斥三选项（负风险结构）

解法（大佬宏观观点的直译载体）：P(某资产年度表现最佳) 用三资产对数收益的相关矩阵做蒙特卡洛（万条路径足够）：σ_btc≈40–60%、σ_gold≈15%、σ_spx≈15–18%，相关性rbtc,spx≈0.3–0.5、rgold,·≈0–0.2（演示参数）。快照时金价年内已大涨，Gold 档仅 ~36% 以下——若判断滞胀/避险行情延续（央行购金+降息+地缘），Gold 档就是被低估的宏观表达。

负风险结构降低成本：互斥多选项下，买入两档 Yes 的成本应 ≈ 1 − 第三档 Yes 价；若合计明显低于 1 − 第三档，直接双买锁定价差。这个结构比在两个独立市场对冲便宜，是 Polymarket 特有的执行优势。

题 2：What will Bitcoin outperform in February? 真实题目，快照未含报价

解法（月度相对题）：同题 1 方法，参数换月度：σ_btc·月 ≈ 12–17% vs σ_gold·月 ≈ 4.5%，相对波动主导 → BTC 不跑输是大概率（所以要找的是「BTC 跑输」档的价值，即市场是否高估 BTC 相对强势）。读规则确认 payout 形态：这类题有的是单选（只有表现最好那档兑付）、有的是多选（跑赢 BTC 的资产各兑付）——两种结构下同一报价的含义完全不同，这是多选项题最常见的踩坑点。

PolyBench 同源真题：政治域（论文点名的 LLM alpha 域）

PolyBench 的 38,666 道题就是 Polymarket 真实市场的时点快照，数据窗口 2026-02-06~12。以下为同站点实时采样（快照 2026-07-18 缓存，同源同题型）。说明：论文数据库的逐题快照版真题需下载 OneDrive 数据库核对（本机网络 503 暂不可达，数据库 ~2GB）；下方为站点同源题，题型分布与数据集一致。论文另有原文示例：Event「Who will win the 2026 World Cup?」/ Market「France will win the 2026 World Cup.」（arXiv §3）。

题 1：Next Prime Minister of Ethiopia? — Abiy Ahmed 档 98% $210M vol · $193K liq · 41 个候选人档

LLM 视角（为什么这是模型的舒适区）：政治人物博弈可从新闻文本直接推理——论文实证 Politics 是 LLM 唯一稳定赚钱的域（文本可解析、舆情数据密集）。但这道题的 alpha 不在方向：现任者 98% 几乎无分歧可赚。模型会怎么错：直接输出「Abiy Ahmed」得 98% 的正确率，却没有产生任何交易价值——PolyBench 的 SKIP 纪律正是考这个：知道答案 ≠ 有 edge。

人工解法：41 档 ΣYes≈1 的算术校验 + 卖深度不足的小候选人档（流动性差的一侧是做市的利润）；或直接跳过。Benchmark 研究价值：这是「校准 vs 正确」分离度最好的题——75% 准确率的 Gemini 与 62% 的 MiMo 在这类题上的差异，本质是弃权纪律的差异（见拆解 Tab 策略表）。

题 2：Iran leader end of 2026? — Mojtaba Khamenei 档 77% 145 个选项档 · $32M vol · $2M liq

LLM 视角：145 个候选的多分类是「指令遵循」酷刑——模型容易输出规则外的候选名（Trinity-Large 103 个格式违规的下场：−9.2% CWR 全场垫底区）。且「健康/继任」类 compound event 的分支结算（继任悬而未决时 50-50 条款）是提示词第 9 条专门防的坑。

人工解法：地缘健康事件的信息优势在情报面不在文本；27% 的「变故」概率含死亡/辞职/流亡多分支，必须逐分支读规则怎么结算（不同分支结算给不同候选人还是 50-50 分摊）。研究价值：145 档 compound event 是师弟选题 C/E（校准与弃权）的绝佳分析样本——这类题模型的置信度虚高最严重。

PolyBench 同源真题：Crypto 域（论文实证的 LLM 亏损域）

快照 2026-08-23 缓存。论文结论：全体模型在 Crypto 域「高置信度 + 深度亏损」——文本语感猜价格的典型灾区。注意这些题的流动性远超商品区（BTC 年度盘 $58M vol / $4M liq）。

题 1：What price will Bitcoin hit in 2026? — ↑$80,000 档 89% $58M vol · $4M liq（全站最大价格盘）

LLM 视角（灾区样本）：与黄金 hit 档完全同构（touch barrier），但模型的错误率高得多——因为训练语料里 BTC 叙事噪音极大，「数字黄金」「减半周期」等文本信号与价格路径几乎无关。论文 Fig 4：模型在 Crypto 平均置信度 ≥0.8 同时深度亏损。方法本身可迁移：barrier 公式 + 已实现波动照算（σ_btc 年化 40–60%，且肥尾要修正——正态近似会低估 touch 概率，实务用期权隐含分布替代），问题是你有没有 BTC 的认知优势——没有就是别人的流动性。

大佬的正确姿势：不交易，但把它当宏观情绪温度计——$58M vol 的 BTC touch 分布是散户风险偏好的实时读数，与黄金档（同窗口的 GC hit 档）对照读，就是「risk-on/off 轮动」的免费高频信号。研究价值：同公式跨域迁移后表现骤降 = 选题 B「领域特征不可省」的最强证据。

题 2：Bitcoin Up or Down — June 21, 2:55AM-3:00AM ET 5 分钟窗口 · 100% Up $96.5K vol · $696K liq

这是什么：5 分钟粒度的方向盘——Polymarket 日内盘的最细粒度，平台上有海量此类滚动小盘（vol 单盘近 $100K）。

人工解法：不碰。5 分钟方向是纯延迟/做市游戏，人工和 LLM 都无优势，是低延迟机器人的地盘（跨平台价差套利 bot 的核心猎场）。LLM 视角：PolyBench 快照为小时级采集，未覆盖 5 分钟盘——这是它作为 benchmark 的粒度边界，也是师弟写 Related Work 时可以指出的数据盲区（LiveTradeBench 的 10 个市场同样没测到这个粒度）。100% Up 的含义：窗口已过大半、方向已定——与商品区日内题一样是「确定性票据」，同样是 maker 收尾的教科书场景。

顺带两个宏观题的信号价值：① "Fed Decision in July?"（No change 95%，$71M vol）——利率路径的实时定价，黄金模型的直接输入变量；② "Strait of Hormuz traffic returns to normal by July 15?"（Yes 0%，$12M vol，地缘域免手续费）——原油供给风险的免费哨兵：0% 与 Crude ATH 10% 之间的张力本身就是供给冲击定价的内部矛盾。这两个题不下单也该进晨会。

通用执行清单（每道题下单前过一遍）

规则逐字读：结算数据源（COMEX 期货 / 现货定盘 / 平台指定）、时区时点、「触及」定义、有无 50-50 条款
定价先行：touch 题用 barrier 公式、settle 题用终点分布、阈值题用 digital——先算公允，再看盘口偏离 ≥ 5 分钱才动手
多档校验：同事件全档 ΣYes ≈ 1；hit ≥ above 的不等式校验——违反即有稳钱交易
仓位红线：单档 ≤ 盘口流动性 5%；全部尾档彩票 ≤ 资金 10%； maker 优先、极端价格带 taker 费趋零
示例演算免责：本 Tab 所有现价/波动率均为演示假设，用于展示方法；实盘前用实时数据代入，结论可能反转
TLDR：AI 团队不该「调个通用 API 就下场交易」（5/7 模型亏损已证明此路不通），而应该做三件有积累价值的事：① 数据基础设施——在 PolyBench 管线基础上加商品价格序列对齐，建成自有数据资产；② 校准训练——用真实结算结果做 SFT/RL，专治「置信度虚高」这个全体模型的通病；③ 信号产品——把模型输出包装成给大佬用的监控提醒。实验成本低到离谱（$2–12/模型/全量），可以高频迭代。

路线 ①：数据基础设施（两周可见成果，一切的地基）

在 PolyBench 基础上扩展什么

  • 补它没有的：PolyBench 快照只有订单簿+新闻，没有价格序列——对商品市场这是致命缺失（价格驱动题 LLM 全线亏损的根源之一）。扩展：对齐 GC/WTI/XAU 的分钟级 OHLCV、期货曲线、CFTC 持仓、库存数据（EIA）与市场快照。
  • 补它没有的域：专门盯商品区四层市场（月度/周度/日内阈值/UpDown），每天定时快照，形成自有时间序列数据库。
  • 工程上直接复用：它的 unified_batch 已解决采集/自愈/结算轮询全套脏活（7 类故障自动恢复），SQLite 单文件够用到百万行级。
为什么值得投入
  • 数据资产私有性：「商品市场 × 价格序列 × 结算结果」的对齐数据集市面上没有现成品——既是论文素材又是产品壁垒
  • 一次建成三线受益：大佬复盘用、师弟实验用、模型训练用
  • 成本极低：公开 API（Gamma/CLOB 免费抓）+ 新闻抓取 + 交易所行情，无 GPU 需求，一台 Mac 即可起步

建议位置：work/ 下新建实验目录，step1 采集 / step2 对齐 / step3 入库，遵循项目 step 命名约定。

五个可执行选题（按与本组资源契合度排序）

选题 A：From One-Shot to Sequential——预测市场 LLM 代理的序列化持仓管理 推荐 · 范式级创新

动机：现有全部 benchmark 让模型在单一快照上做一次决策。真实交易是「建仓 → 加减仓 → 止损 → 移仓」的序列过程，中间还有新信息到达。这个范式空缺是领域级缺口。

做法：扩展 PolyBench 采集器为「逐日/逐小时重复快照同一批市场」，构造 (t₁, t₂, …, tₖ) 决策轨迹；让模型看到自己此前的持仓与浮盈，评测：动态加减仓 vs 一次性的收益差、止损纪律的价值、信息到达后的 belief revision 质量。

数据：自建采集器（与 AI 团队路线①共用）；PolyBench 现有 26,784 个活跃市场是现成标的池。

投稿定位：NeurIPS Datasets & Benchmarks / ICML。故事完整性高，工程量中等。

选题 B：Commodity Copilot——价格序列 + LLM 混合代理在商品预测市场 本组独家优势

动机：PolyBench 实证 LLM 在价格驱动域（Crypto）全面亏损——因为快照里根本没有价格序列，模型只能靠文本语感猜。商品市场（黄金/石油）同理且更极端：定价阈值市场需要波动率、动量、距阈值距离这些量化特征，任何纯文本方法都不可能做好。

做法：构建「商品预测市场子基准」（月度/周度/日内阈值 + UpDown 四层市场 × 对齐的 OHLCV/期货曲线/库存数据）；系统消融：纯 LLM / 纯量化特征 / 混合融合 / 领域路由器，四个 arm 在 CWR 上对比。大佬的领域知识可以直接变成特征工程与 case study（为什么这个档位被错定价——真人专家解读，审稿人最买账的部分）。

独占性：「黄金/石油专家 + 数据管线 + LLM 实验」三要素齐备的组极少，这是本组能在简介里写「unique resources」的选题。

投稿定位：ACL/EMNLP（推理+金融交叉）或 ICAIF（AI 金融会议，气质完全对口）。

选题 C：Know When to Hold——置信度校准与弃权策略的交易价值 低成本快startup

动机：论文发现「全体模型置信度 0.81–0.87 但 5/7 亏损」「CWR > Non-CWR 说明置信度有信号但没用好」——校准这个被所有预测市场 benchmark 忽视的轴，直接连着钱。

做法：在 PolyBench 36,165 条已结算预测上（公开可下载，零 API 成本）：① 后验校准方法横评（温度缩放/Isotonic/分位数回归）；② 校准前后 CWR 差异量化「校准的交易价值」；③ 学习型 Skip 策略（何时不下注）与固定阈值的对比；④ 分域校准（政治 vs 价格域应不同对待）。

优势：纯公开数据 + 分析型论文，2–3 个月可完稿，适合作为师弟的第一篇练手 + 摸清赛道。

选题 D：The Maker's Edge——预测市场 CLOB 上的做市策略 执行维度创新

动机：Polymarket 费制改革后「maker 免费 + 每日返佣、taker 付费」的不对称结构，而 PolyBench 只模拟了 taker 吃单。做市在预测市场的学术研究几乎空白（现有做市文献都在股票/加密现货）。

做法：基于 PolyBench 留存的订单簿快照做模拟报价：不同报价宽度/库存控制策略的收益（价差 + 返佣 − 逆向选择损失）；「数据日」（结算临近、高波动时段）的撤单纪律。若能配合小额实盘验证更佳。

风险：快照只有 top5 档且非全历史，做市模拟保真度受限——需要在论文里诚实处理 limitation，或用自建高频快照补强。

选题 E：Wisdom of the Models——多模型集成与分歧信号 零成本 · 可立即启动

动机：PolyBench 发布了 7 个模型对同一批 5,097 题的预测（36,165 条）——一份现成的「多模型×同题×有结算」平行语料。没人系统研究过：集成能否跑赢最优单模型？模型间分歧度能否当不确定性信号用（分歧大 → 弃权）？

做法：多数投票 / 置信度加权集成 / Stacking 三种集成 vs 最优单模型（MiMo 17.6%）；分歧度-正确率关系曲线；「分歧门控」对 CWR 的提升。加一个「领域分化」分析（政治域集成有效、价格域无效的机理）。

优势：零 API 成本、数据现成、工作量最小；缺点是创新深度有限——适合与选题 C 合并成一篇，或作为选题 B 的前置章节。
