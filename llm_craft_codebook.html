TLDR
Softmax 把任意实数向量变成概率分布（和为 1）。核心技巧：减去最大值防止数值溢出。Online Softmax 用两趟遍历解决流式计算问题。
softmax(xi) = exp(xi) / Σj exp(xj)   →   数值稳定版: softmax(xi) = exp(xi - max(x)) / Σj exp(xj - max(x))
1. 基础 Softmax（有溢出风险）

为什么不能直接 exp?

当输入值很大（如 1000），exp(1000) 会超出 float16 的范围（最大 65504），返回 inf。所有项都是 inf，除以 inf 得到 nan。

softmax_basic.pyEasyOffer
import numpy as np

input = np.array([0, 7, 6, 12, 10], dtype=np.float16)
eInputs = np.exp(input)       # ⚠️ exp(12) 可能溢出!
result = eInputs / np.sum(eInputs)
print(result)
2. 数值稳定版 Softmax（减去最大值）

数学等价性

exp(x - max) / Σ exp(x - max) = exp(x) / exp(max) / Σ (exp(x) / exp(max)) = exp(x) / Σ exp(x)

减去 max 后，最大值为 0，其余为负数，exp 值域在 (0, 1]，不会溢出。

softmax_stable.pyEasyOffer
import numpy as np

input = np.array([0, 7, 6, 12, 10], dtype=np.float16)
max_val = np.max(input)
emInputs = np.exp(input - max_val)  # ✅ 最大项 = exp(0) = 1，其余 ≤ 1
result = emInputs / np.sum(emInputs)
print(result)  # [0.000113, 0.00580, 0.00214, 0.858, 0.134]
3. Online Softmax（两趟遍历，用于 GPU kernel）

为什么需要 Online?

  • Flash Attention 在 SRAM 中逐 block 计算注意力，无法一次看到所有 q·k 值
  • 需要一种增量式的方法，逐步更新 max 和 sum
  • 第一趟遍历：找全局 max；第二趟遍历：用全局 max 算最终概率
softmax_online.pyEasyOffer
import torch

L = 8
inputs = torch.randn(L)
result = torch.zeros(L)

# 第一趟：找到全局最大值 m
m = torch.tensor(float("-inf"))
d = 0
for i in range(L):
    m_new = torch.max(m, inputs[i])
    d = d * (m - m_new).exp() + (inputs[i] - m_new).exp()
    m = m_new

# 第二趟：用全局 max 算概率
for i in range(L):
    result[i] = (inputs[i] - m).exp() / d

print('online softmax:', result)
print(torch.sum(result))  # 1.0 ✅

关键公式推导

更新规则：d_new = d_old × exp(m_old - m_new) + exp(x_i - m_new)

含义：旧 sum 需要乘以一个缩放因子（因为基准 max 从 m_old 变成了 m_new），再加上新元素的贡献。

TLDR
交叉熵衡量模型预测分布与真实分布的差距。KL 散度衡量两个分布的"距离"。两者关系：CE(p,q) = H(p) + KL(p||q)，当 p 是 one-hot 时 CE = -log q(y)。
CE = -Σi p(xi) log q(xi)   |   KL(p||q) = Σi p(xi) log(p(xi) / q(xi))
交叉熵损失函数（手写版）
cross_entropy.pyEasyOffer
import torch

# 模拟数据：batch_size=3, vocab_size=5
logits = torch.randn(3, 5)
labels = torch.tensor([2, 0, 4])

def manual_cross_entropy(logits, labels):
    # Step 1: softmax 得到概率分布
    max_vals = torch.max(logits, dim=1, keepdim=True).values
    exp_logits = torch.exp(logits - max_vals)
    probs = exp_logits / torch.sum(exp_logits, dim=1, keepdim=True)

    # Step 2: 取出正确类别的概率
    # 等价于 one-hot 乘 log_probs 再求和
    log_probs = torch.log(probs)
    loss = -log_probs[torch.arange(len(labels)), labels]
    return loss.mean()

ce_manual = manual_cross_entropy(logits, labels)
ce_torch = torch.nn.functional.cross_entropy(logits, labels)
print(f"手动: {ce_manual:.4f}, PyTorch: {ce_torch:.4f}")  # 两者一致 ✅

为什么分类任务用交叉熵而不是 MSE?

  • 交叉熵对错误分类的惩罚更大：如果正确类别的概率接近 0，-log(ε) → +∞
  • MSE 的梯度在饱和区非常小（sigmoid/tanh 的平坦区），训练慢
  • PyTorch 的 F.cross_entropy 内部做了 log_softmax 融合，比先 softmax 再 log 更稳定
KL 散度
kl_divergence.pyEasyOffer
def KL(logits_p, logits_q):
    eps = 1e-9
    # KL(p || q) = Σ p(x) * [log p(x) - log q(x)]
    kl_div = logits_p * (torch.log(logits_p + eps) - torch.log(logits_q + eps))
    return torch.sum(kl_div, dim=-1)

KL 散度的性质

  • 非对称：KL(p||q) ≠ KL(q||p)，p 是真实分布，q 是近似分布
  • 非负：KL(p||q) ≥ 0，当且仅当 p = q 时为 0（Gibbs 不等式）
  • RLHF 中用 KL 散度约束策略不要偏离参考模型太远：loss = -reward + β × KL(π||π_ref)
TLDR
Self-Attention 是 Transformer 的核心：每个 token 通过 Q/K/V 三组线性变换，计算与其他所有 token 的相关性，加权求和得到新表示。公式：Attention(Q,K,V) = softmax(QK^T / √d_k) V
Attention(Q, K, V) = softmax(QKT / √dk) · V
self_attention.pyEasyOffer
import torch
import torch.nn as nn

class SelfAttention(nn.Module):
    def __init__(self, embed_size, heads):
        super().__init__()
        self.embed_size = embed_size
        self.heads = heads
        self.head_dim = embed_size // heads  # 每个头的维度

        # Q/K/V 各一个线性投影（无 bias）
        self.values = nn.Linear(self.head_dim, self.head_dim, bias=False)
        self.keys   = nn.Linear(self.head_dim, self.head_dim, bias=False)
        self.queries = nn.Linear(self.head_dim, self.head_dim, bias=False)
        self.fc_out  = nn.Linear(heads * self.head_dim, embed_size)

    def forward(self, values, keys, query, mask):
        N = query.shape[0]
        val_len, key_len, query_len = values.shape[1], keys.shape[1], query.shape[1]

        # Step 1: reshape 成多头形状 [batch, seq_len, heads, head_dim]
        values  = values.reshape(N, val_len,   self.heads, self.head_dim)
        keys    = keys.reshape(N, key_len,    self.heads, self.head_dim)
        queries = query.reshape(N, query_len, self.heads, self.head_dim)

        # Step 2: 线性投影
        values  = self.values(values)
        keys    = self.keys(keys)
        queries = self.queries(queries)

        # Step 3: 计算注意力分数 (缩放点积)
        energy = torch.einsum("nqhd,nkhd->nhqk", [queries, keys])  # [batch, heads, q_len, k_len]
        if mask is not None:
            energy = energy.masked_fill(mask == 0, float("-1e20"))

        attention = torch.softmax(energy / (self.embed_size ** (1 / 2)), dim=3)  # 缩放 + softmax

        # Step 4: 加权求和得到输出
        out = torch.einsum("nhql,nlhd->nqhd", [attention, values])
        out = out.reshape(N, query_len, self.heads * self.head_dim)

        # Step 5: 输出投影
        return self.fc_out(out)

逐行解读

  • einsum("nqhd,nkhd->nhqk")：batch 维不变，head 维不变，q 维 × k 维 = 注意力矩阵。等价于 torch.matmul(q, k.transpose(-1,-2))
  • / (embed_size ** 0.5)：缩放因子 √dk。当 dk 大时，点积值也大，softmax 进入梯度极小的饱和区。除以 √d 使方差保持为 1
  • einsum("nhql,nlhd->nqhd")：注意力权重 × V = 加权求和。每行（一个 query）对所有 value 加权
  • 为什么 Q/K/V 各一个 Linear? 这里是为每个 head 单独投影。实际实现中通常用一个大 Linear (d → 3d) 一次算完再 chunk
TLDR
MHA 让每个头学习不同的注意力模式。GQA 让多个 Q 头共享一组 KV 头，大幅减少推理时的 KV Cache 内存。LLaMA2 用 GQA 实现了高效的推理加速。
Multi-Head Attention (MHA)

与上面 SelfAttention 的区别：用一个 Linear 一次投影出 QKV，而不是为每个 head 单独投影。

multi_head_attention.py (Llama 风格)EasyOffer
class LlamaMHA(nn.Module):
    def __init__(self, dim, num_heads, head_dim=None):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = head_dim or dim // num_heads
        self.scale = 1.0 / math.sqrt(self.head_dim)

        # 一个大 Linear 投影出 QKV（无 bias，LLaMA 风格）
        self.q_proj = nn.Linear(dim, num_heads * self.head_dim, bias=False)
        self.k_proj = nn.Linear(dim, num_heads * self.head_dim, bias=False)
        self.v_proj = nn.Linear(dim, num_heads * self.head_dim, bias=False)
        self.o_proj = nn.Linear(num_heads * self.head_dim, dim, bias=False)

    def forward(self, x, attention_mask=None, cache=None):
        bs, seq_len, _ = x.shape

        # 线性投影 + reshape 成多头
        q = self.q_proj(x).view(bs, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.k_proj(x).view(bs, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.v_proj(x).view(bs, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        # q: [batch, heads, seq_len, head_dim]

        # KV Cache（推理加速）
        if cache is not None:
            past_k, past_v = cache
            k = torch.cat([past_k, k], dim=2)
            v = torch.cat([past_v, v], dim=2)
            cache = (k, v)

        # 注意力计算
        attn_scores = torch.matmul(q, k.transpose(-1, -2)) * self.scale
        if attention_mask is not None:
            attn_scores = attn_scores + attention_mask
        attn_weights = F.softmax(attn_scores, dim=-1)

        # 加权求和 + 输出投影
        output = torch.matmul(attn_weights, v)
        output = output.transpose(1, 2).contiguous().view(bs, seq_len, -1)
        return self.o_proj(output)
Grouped-Query Attention (GQA)

GQA 的核心改动只有两行代码：

  • K/V 的投影维度从 num_heads × head_dim 变成 num_kv_heads × head_dim
  • 计算前用 k.repeat_interleave(kv_groups, dim=1) 扩展 KV 以匹配 Q 头数
grouped_query_attention.py（核心差异部分）EasyOffer
class LlamaGQA(nn.Module):
    def __init__(self, dim, num_query_heads, num_kv_heads, head_dim=None):
        super().__init__()
        self.kv_groups = num_query_heads // num_kv_heads  # 每 group 共享一组 KV

        # Q 投影：num_query_heads 个头（完整）
        self.q_proj = nn.Linear(dim, num_query_heads * head_dim, bias=False)
        # K/V 投影：num_kv_heads 个头（更少！）
        self.k_proj = nn.Linear(dim, num_kv_heads * head_dim, bias=False)
        self.v_proj = nn.Linear(dim, num_kv_heads * head_dim, bias=False)
        self.o_proj = nn.Linear(num_query_heads * head_dim, dim, bias=False)

    def forward(self, x, attention_mask=None, cache=None):
        bs, seq_len, _ = x.shape
        q = self.q_proj(x).view(bs, seq_len, self.num_query_heads, self.head_dim).transpose(1, 2)
        k = self.k_proj(x).view(bs, seq_len, self.num_kv_heads, self.head_dim).transpose(1, 2)
        v = self.v_proj(x).view(bs, seq_len, self.num_kv_heads, self.head_dim).transpose(1, 2)

        # ⭐ GQA 核心：将 KV 复制到与 Q 头数匹配
        # 例如：8 个 Q 头, 2 个 KV 头 → 每个 KV 头被 4 个 Q 头共享
        k = k.repeat_interleave(self.kv_groups, dim=1)
        v = v.repeat_interleave(self.kv_groups, dim=1)

        # 后续与 MHA 完全一致...
        attn_scores = torch.matmul(q, k.transpose(-1, -2)) * self.scale

TLDR
RMSNorm 是 LayerNorm 的简化版：不做均值减法，只除以 RMS。计算更快（少一次减法），效果几乎一样。LLaMA/Mistral/MiniMind 都用 RMSNorm。
RMSNorm(x) = (x / √(mean(x²) + ε)) × γ   vs   LayerNorm(x) = (x - μ) / √(σ² + ε) × γ + β
rms_norm.pyEasyOffer
class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))  # 可学习的缩放参数 γ

    def _norm(self, x):
        # 核心：x * rsqrt(mean(x²) + eps)
        # rsqrt = 1/sqrt，比先 sqrt 再求逆更快
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

    def forward(self, x):
        return self.weight * self._norm(x)

LayerNorm vs RMSNorm

  • LayerNorm：减均值 → 除标准差 → 仿射变换 (γx + β)
  • RMSNorm：除 RMS → 缩放 (γx)，没有 β，没有减均值
  • 直觉：当输入已经居中（均值为 0）时，减均值步骤可以省掉
  • 在 Transformer 中，残差连接 + RMSNorm 已经足够保证稳定训练
TLDR
RoPE 通过对 Q 和 K 做旋转来编码位置信息。两个 token 的注意力分数只取决于它们的相对位置（q₁·k₂ 只含 pos₂-pos₁）。LLaMA/MiniMind 都用 RoPE。
q' = q × cos(mθ) + rotate_half(q) × sin(mθ)   |   rotate_half([x₁,x₂,...]) = [-x₂,x₁,-x₄,x₃,...]
rope.pyEasyOffer
class RotaryEmbedding(nn.Module):
    def __init__(self, dim, max_seq_len=2048, base=10000):
        super().__init__()
        # 频率向量: θ_i = 1 / (base^(2i/dim))
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer("inv_freq", inv_freq)

        # 预计算 cos/sin 缓存
        t = torch.arange(max_seq_len).type_as(inv_freq)
        freqs = torch.einsum("i,j->ij", t, inv_freq)  # [seq_len, dim/2]
        emb = torch.cat((freqs, freqs), dim=-1)     # 复制一份变成 [seq_len, dim]
        self.register_buffer("cos_cached", emb.cos())
        self.register_buffer("sin_cached", emb.sin())

def rotate_half(x):
    # [x₁, x₂, x₃, x₄, ...] → [-x₂, x₁, -x₄, x₃, ...]
    x1 = x[..., : x.shape[-1] // 2]
    x2 = x[..., x.shape[-1] // 2:]
    return torch.cat((-x2, x1), dim=-1)

def apply_rotary_pos_emb(q, k, cos, sin, position_ids):
    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)
    return q_embed, k_embed

为什么 RoPE 天然编码相对位置?

假设 token A 在位置 m，token B 在位置 n：

  • q' = q·cos(mθ) + rotate(q)·sin(mθ) — 本质是 q 旋转了 mθ 角度
  • k' = k·cos(nθ) + rotate(k)·sin(nθ) — 本质是 k 旋转了 nθ 角度
  • q'·k' = q·k·cos((n-m)θ) + ... — 角度差 = n-m = 相对位置

所以注意力分数只依赖相对位置 n-m，与绝对位置无关。这就是为什么 RoPE 有很好的长度外推性。

TLDR
FFN 是 Transformer 的"记忆库"：两层线性 + 激活函数。SwiGLU 用门控机制替代 ReLU/GELU，效果更好。公式：SwiGLU(x) = (SiLU(xW₁) ⊗ xW₃) W₂
SwiGLU(x) = (SiLU(xW₁) ⊗ xW₃) W₂   where   SiLU(x) = x · σ(x)   and   ⊗ = element-wise multiply
mlp.py (LLaMA 风格 SwiGLU MLP)EasyOffer
import torch.nn as nn
import torch.nn.functional as F

class LlamaMLP(nn.Module):
    def __init__(self, dim, hidden_dim=None, multiple_of=256):
        super().__init__()
        hidden_dim = hidden_dim or 4 * dim

        # SwiGLU 特殊缩放：2/3 × 4d，然后向上取整到 256 的倍数
        hidden_dim = int(2 * hidden_dim / 3)
        hidden_dim = multiple_of * ((hidden_dim + multiple_of - 1) // multiple_of)

        # 三个投影矩阵（无 bias）
        self.gate_proj = nn.Linear(dim, hidden_dim, bias=False)  # W₁: 门控分支
        self.up_proj   = nn.Linear(dim, hidden_dim, bias=False)  # W₃: 上投影分支
        self.down_proj = nn.Linear(hidden_dim, dim, bias=False) # W₂: 下投影

    def forward(self, x):
        #        SiLU(W₁x)  ⊗  W₃x        然后通过 W₂
        gate = F.silu(self.gate_proj(x))  # 门控：x·sigmoid(x)
        up   = self.up_proj(x)            # 上投影
        return self.down_proj(gate * up)   # 门控 × 上投影 → 下投影

为什么 SwiGLU 比普通 FFN 好?

  • 普通 FFN：ReLU(xW₁)W₂ — 只有一条信息通路
  • SwiGLU：(SiLU(xW₁) ⊗ xW₃)W₂ — 门控机制让网络选择性通过信息
  • SiLU (Swish) = x·sigmoid(x)：当 x < 0 时有非零梯度（ReLU 直接截断），更平滑
  • 为什么 hidden_dim 缩放到 2/3? SwiGLU 有两个 W（W₁ 和 W₃），参数量已经是 2d×h。缩放到 2/3 使总参数量 ≈ d × 4d/3 × 2 ≈ 原始 FFN 的参数量
TLDR
LoRA 冻结原始权重 W，旁路添加低秩分解 ΔW = AB（rank 远小于维度）。只训练 A 和 B，参数量减少 10000x。推理时可合并回原矩阵，零额外延迟。
W' = W + ΔW = W + BA   where   B ∈ Rd×r, A ∈ Rr×k, r ≪ min(d,k)
lora.pyEasyOffer
class LoRALayer(nn.Module):
    def __init__(self, input_dim, output_dim, rank):
        super().__init__()
        self.rank = rank

        # A: [input_dim, rank], B: [rank, output_dim]
        # ΔW = A @ B 的形状 = [input_dim, output_dim] ✅
        self.A = nn.Parameter(torch.randn(input_dim, rank))
        self.B = nn.Parameter(torch.randn(rank, output_dim))

        # 关键初始化：B 初始化为零 → 初始时 ΔW = A×0 = 0
        # → LoRA 注入后不影响原始模型的行为
        nn.init.zeros_(self.B)

    def forward(self, x):
        delta_W = torch.matmul(self.A, self.B)
        return torch.matmul(x, delta_W)

class LoRA(nn.Module):
    def forward(self, x):
        base_output = self.base_model(x)  # 原始模型（冻结）
        for lora_layer in self.lora_layers:
            base_output += lora_layer(x)      # 逐层叠加 LoRA
        return base_output

关键细节

  • B 初始化为零：确保 LoRA 注入时模型行为不变。如果 B 也随机初始化，模型能力会突然变化
  • A 用 Kaiming 初始化：保持方差稳定
  • rank 的选择：通常 r=8 或 r=16。rank 越大表达能力越强但参数越多
  • LoRA 加在哪里? 通常加在 Q/K/V/O 投影上。加在 attention 层效果最好
  • 推理时合并：W_merged = W + BA，合并后 LoRA 不增加任何延迟
TLDR
ReLU 最简单但"死神经元"问题严重。GELU 更平滑。SiLU（Swish）= x·sigmoid(x) 在 x<0 也有梯度。Sigmoid 用于二分类输出。
activation_functions.pyEasyOffer
class ReLU(nn.Module):
    def forward(self, x):
        return torch.maximum(x, torch.tensor(0.0))
        # x > 0: 保留; x ≤ 0: 置零 → "死神经元"

class Sigmoid(nn.Module):
    def forward(self, x):
        return 1 / (1 + torch.exp(-x))
        # 输出 (0, 1)，用于概率/门控

def silu(x):
    return x * torch.sigmoid(x)
    # SiLU = x · σ(x)
    # x > 0: ≈ x (近似线性)
    # x < 0: ≈ 0 (但不是完全置零!)
    # x = 0: = 0
    # 比 ReLU 更平滑，无"死神经元"问题
激活函数公式x<0 时用在哪
ReLUmax(0, x)完全置零早期 Transformer
GELUx·Φ(x)接近零但非零BERT, GPT-2

class SwiGLU_FFN(nn.Module):
    def __init__(self, input_dim, intermediate_dim=None):
        super().__init__()
        intermediate_dim = intermediate_dim or int(input_dim * 4 * 3/2)
        self.gate_proj = nn.Linear(input_dim, intermediate_dim)
        self.act_fn = nn.SiLU()
        self.up_proj = nn.Linear(input_dim, intermediate_dim)
        self.down_proj = nn.Linear(intermediate_dim, input_dim)

    def forward(self, x):
        gate = self.act_fn(self.gate_proj(x))
        return self.down_proj(gate * self.up_proj(x))

class MoE(nn.Module):
    def __init__(self, input_dim, n_expert, ffn_class, expert_hidden_dim=None):
        super().__init__()
        # N 个 expert FFN
        self.experts = nn.ModuleList([
            ffn_class(input_dim, expert_hidden_dim) for _ in range(n_expert)
        ])
        # Router: 为每个 token 生成到每个 expert 的权重
        self.gate = nn.Linear(input_dim, n_expert)

    def forward(self, x):  # x: [batch, seq_len, dim]
        # 1. 所有 expert 并行计算
        experts_out = [expert(x) for expert self.experts]  # 每个: [bs, len, dim]
        experts_out = torch.stack(experts_out, dim=2)            # [bs, len, n_expert, dim]

        # 2. Router 生成门控权重
        gates = F.softmax(self.gate(x), dim=-1)               # [bs, len, n_expert]

        # 3. 加权求和: output = Σ gate_e × expert_e
        output = torch.einsum("b l e, b l e d -> b l d", gates, experts_out)
        return output

MoE 的关键概念

  • Top-K Routing：实际只选权重最大的 K 个 expert（如 K=2），其余不计算，节省算力
  • Auxiliary Loss：加入负载均衡损失，防止所有 token 都选同一个 expert（"专家崩塌"）
  • 实际实现用 scatter/gather而非循环，这里的教学版本用 stack+einsum 更直观

def temperature_sampling(logits, temperature=1.0):
    # Step 1: 除以温度
    logits = logits / temperature
    # Step 2: 得到概率分布
    probs = F.softmax(logits, dim=-1)
    # Step 3: 按概率采样
    return torch.multinomial(probs, num_samples=1).squeeze(-1)

class AbsolutePositionEmbedding(nn.Module):
    def __init__(self, max_length=512, embed_dim=768):
        super().__init__()
        # 频率向量: 10000^(-2i/d), i = 0, 1, ..., d/2-1
        _2i = torch.arange(0, embed_dim, 2)
        inv_freq_vec = 10000 ** (-_2i.float() / embed_dim)

        pos = torch.arange(max_length).float()
        angle = torch.einsum('l,d->ld', pos, inv_freq_vec)  # [max_len, d/2]

        sin_part = torch.sin(angle)
        cos_part = torch.cos(angle)

        # 交错排列: [sin₀, cos₀, sin₁, cos₁, ...]
        pos_emb = rearrange(
            torch.stack([sin_part, cos_part], dim=-1),
            'max_len dim_pair two -> max_len (dim_pair two)'
        )
        self.register_buffer('pos_embedding', pos_emb)

    def forward(self, x):
        # 扩展到 batch 维度并截取到实际 seq_len
        return repeat(self.pos_embedding[:x.size(1)], 'l d -> b l d', b=x.size(0))

为什么频率用 10000^(-2i/d)?

  • 低频（i 小）：编码长距离位置关系，变化慢
  • 高频（i 大）：编码短距离位置关系，变化快
  • 这类似于信号处理中的多分辨率分析（不同频率捕捉不同尺度）

class TransformerEncoderLayer(nn.Module):
    def __init__(self, emb_dim, hid_dim_ffn, n_head, dim_each_head):
        super().__init__()
        self.attention_layer = SelfAttentionLayer(emb_dim, n_head, dim_each_head)
        self.ffn = nn.Sequential(
            nn.Linear(emb_dim, hid_dim_ffn),
            nn.LeakyReLU(),
            nn.Linear(hid_dim_ffn, emb_dim)
        )
        self.layer_norm = nn.LayerNorm(emb_dim)

    def forward(self, x):
        # Post-LN: 先 sublayer，再 LayerNorm
        x_attn = self.attention_layer(x)    # 1. Self-Attention
        x = self.layer_norm(x + x_attn)     # 2. Residual + Norm
        x_ffn = self.ffn(x)                 # 3. FFN
        x = self.layer_norm(x + x_ffn)      # 4. Residual + Norm
        return x

Post-LN vs Pre-LN

  • Post-LN（原论文）：x → sublayer → LN。训练不稳定，需要 warmup
  • Pre-LN（GPT-2/LLaMA）：x → LN → sublayer。训练更稳定，是现代标准
  • LLaMA 的 LlamaLayer 注释："之前的 LN(x+FFN(x)) 变成 x + FFN(LN(x))"

def matrix_dot_vector(a, b):
    # a: [m, n] 矩阵, b: [n] 向量
    # 结果: [m] 向量，每个元素是对应行的点积
    return [sum(x*y for x, y in zip(row, b)) for row in a]

def transpose_matrix(a):
    # Pythonic: zip(*a) 自动解包每行，然后按列重新打包
    return [list(col_tuple) for col_tuple in zip(*a)]

def matrixmul(a, b):
    m, n = len(a), len(a[0])
    if n != len(b): return -1
    p = len(b[0])
    get_col = lambda j: [row[j] for row in b]
    return [[sum(x*y for x,y in zip(a[i], get_col(j)))
             for j in range(p)] for i in range(m)]

# 矩阵乘法 = 全连接层的前向传播本质
# output = input @ W^T + bias
