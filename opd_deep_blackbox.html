🎭 黑盒 OPD — 无教师 Logits（3 篇深度解读）

本节 TLDR

当教师是 API-only（如 GPT-5 / Claude 3.5 Sonnet）无法获取 logits 时，黑盒 OPD 提供三条替代路：对抗判别器（GAD）、口头评分（OVD）、偏好对比（ORPO-Distill）。三者信号粒度依次递减，但都满足 OPD 核心条件 C1（学生 rollout）+ C2（某种形式的教师监督）。

GAD: Generative Adversarial Distillation

黑盒 OPD 种子论文 Microsoft Research2025.11
核心洞察：用判别器代替 logits

GAD 的出发点是：如果我们无法获取 GPT-5 的 logits，但可以调用它的 API 获取输出文本，那么能不能训练一个判别器，区分"这段话像是 GPT-5 写的"还是"像是学生写的"？这个判别器就是教师 logits 的替代品——它提供了"这个输出有多像教师"的信号。

GAN 式训练框架
判别器 D（固定教师风格探测器）：
max_D E_{y~π_T}[log D(y|x)] + E_{y~π_S}[log(1-D(y|x))]
训练 D 区分教师输出（正样本）和学生输出（负样本）

学生 π_S（生成器）：
max_{π_S} E_{y~π_S}[log D(y|x)]  （欺骗判别器）
等价于：最小化 E_{y~π_S}[log(1-D(y|x))]

On-Policy 关键：y 从 π_S 采样（C1 满足），D 在 π_S 的 rollout 上评分（C2 满足）
判别器如何共演化为在策略奖励模型

GAD 的精髓在于：判别器 D 不是固定的，它随着学生进步动态更新。随着学生越来越像教师，D 需要越来越精细的区分能力，自然形成了对学生能力的"前沿测试"。最终 D 成为一个精准的在策略奖励模型（on-policy reward model），比固定奖励模型更能捕捉学生的当前弱点。

实验：Qwen2.5-14B 学生 vs GPT-5-Chat

GAN 训练稳定性技巧
  • 判别器更新频率：每更新学生 1 步，更新判别器 3-5 步（防止学生"崩溃"）
  • 梯度惩罚（WGAN-GP）：对 D 施加梯度范数约束，防止 mode collapse
  • 标签平滑：教师样本标签用 0.9 而非 1.0，学生样本用 0.1 而非 0.0
训练不稳定风险

GAN 训练本质不稳定——判别器太强会导致学生梯度消失（无法改进），判别器太弱会导致学生过度自信（停止学习）。实践中需要仔细调节 D/G 更新频率比。GAD 的官方实现包含了多个稳定技巧，建议直接使用官方代码。

为什么 GAD 比 RLHF 更高效？

RLHF 的奖励模型是离策略的（在人工标注数据上训练），对学生当前行为的区分能力有限。GAD 的判别器是在策略的（持续在学生当前 rollout 上更新），始终针对学生当前弱点——这是信号效率大幅提升的根源。

OVD: On-Policy Verbal Distillation

HKU / Huawei Noah's Ark2026.01
口头评分代替 logit KL

OVD 的方案极其简洁：用教师 API 对学生生成的每条 rollout 打一个口头分数（0-9），然后将这个分数作为序列级奖励信号来训练学生。无需 logits，无需判别器训练，只需 API 调用。

训练目标
Step 1：学生生成 rollout
y ~ π_S(·|x)  （on-policy 满足 C1）

Step 2：教师 API 打分
s = Teacher.score(x, y) ∈ {0,1,...,9}  （满足 C2，信号来自教师在学生样本上）

Step 3：REINFORCE 更新
L = -E_{y~π_S}[(s - b) · log π_S(y|x)]
b = 基线（当前 batch 的平均分），减少方差
评分 prompt 设计（关键）

OVD 的效果很大程度取决于评分 prompt 的质量。论文提出的最佳实践：

请对以下回答打分（0-9分），其中：
- 0-2：完全错误或有害
- 3-5：部分正确，但有明显缺陷
- 6-8：基本正确，质量良好
- 9：接近完美，与顶级模型水平相当

问题：{x}
回答：{y}

直接输出一个整数分数，不要解释。

OVD47.8%（+25.7%↑）8.4
白盒 OPD（GKD）51.3%8.7

OVD 比白盒 GKD 略差（-3.5pp），但完全不需要教师权重——对于闭源教师场景这是极大的实用价值。

实用权衡

OVD 的 API 调用成本需要评估：每条 rollout 需要一次教师 API 调用。如果用 GPT-4o 打分，1000 条 rollout 的成本约 $2-5（取决于长度）。对于 10M 条数据的大规模训练，这不现实，但对于 10K-100K 数据规模的研究实验，OVD 是性价比极高的黑盒方案。

ORPO-Distill: On-Policy Preference Distillation

工业界2025.09 NeurIPS 2025 Workshop
最简黑盒 OPD：只需偏好信号

ORPO-Distill 将黑盒 OPD 简化到极致：学生生成的输出作为负样本，教师 API 的输出作为正样本，用 ORPO（Odds Ratio Preference Optimization）对比损失训练学生。

ORPO 损失回顾
L_ORPO = -log σ(log odds(π_S, y_w) - log odds(π_S, y_l))
其中 log odds(π, y) = log π(y|x) - log(1 - π(y|x))
y_w = 教师输出（正样本，winning response）
y_l = 学生 rollout（负样本，losing response）
On-Policy 的体现

ORPO-Distill 的 on-policy 性质体现在负样本（学生 rollout）是动态生成的——每轮训练重新采样学生当前输出作为负样本，而非用固定的"坏样本"数据集。这确保了 C1 条件（学生自己的分布采样）。

与 GAD/OVD 的比较
维度ORPO-DistillOVDGAD
信号类型二值偏好（±1）连续评分（0-9）判别器分数（连续）
API 调用次数1次/样本（生成正样本）1次/样本（打分）1次/样本（生成正样本）+ 判别器训练
实现复杂度最低（TRL 直接支持）低高
性能一般良好最佳
ORPO-Distill 的局限

二值偏好信号（教师好 vs 学生差）信息量最少，当学生能力接近教师时（相差不大），正负样本区分度下降，训练信号趋于消失。OVD 的连续评分和 GAD 的判别器在这种情况下更稳健。ORPO-Distill 更适合学生与教师差距较大的初期训练阶段。

三种黑盒方案的选型建议

资源受限、快速验证 → ORPO-Distill（TRL 一行代码，无需额外组件）
平衡效果与成本 → OVD（连续评分，实现简单，效果明显）
追求最佳效果、接受训练复杂度 → GAD（判别器共演化，最接近白盒效果）
